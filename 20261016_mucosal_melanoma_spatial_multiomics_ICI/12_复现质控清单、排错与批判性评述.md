## 二、跨模块排错速查表

| 现象 | 可能根因 | 解决 |
|---|---|---|
| 分割出的细胞数比预期少一个数量级 | OME-TIFF 通道顺序错、DAPI 通道选错 | 先打印通道列表与各通道均值；DAPI 常是第一个或最后一个通道 |
| 分割结果整片粘连 | 核扩张过大 / 未做分水岭 | 见 03 号 §④；核扩张前先做距离变换分水岭 |
| 表型注释里出现大量"全阳性"细胞 | arcsinh 的 c 选错或未做批次校正 → 强度压缩 | 画每 marker 的强度直方图；换 c 值（1/5/150）看聚类稳定性 |
| CN 组成向量大量全零 | 窗口内无细胞（稀疏区）或坐标单位错（μm 当 px） | 加 `--min-cells-in-window`；断言坐标范围与切片尺寸一致 |
| K-means 每次结果不同 | 未固定 `random_state`；或 k-means++ 未开 | 固定种子并报惯性值与多次重启的最优解 |
| CN 数目与原文 15 对不上 | k 未设 15 或标准化方式不同（组成向量是否 L1 归一化） | 核对 `--k 15` 与标准化开关；报 k 扫描曲线 |
| 空间上下文图的组合频次天天变 | "最少组合覆盖"的贪心解不唯一 | 用确定性的枚举顺序（按 CN 编号排序）+ 记录并列解 |
| 三角图（重心坐标）大部分点集中在中心 | 未做 ≥80% 过滤或三个 CN 占比普遍低 | 先看三 CN 合计占比的分布，再决定阈值 |
| patch 数量爆炸（几十上百个小 patch） | HDBSCAN `min_cluster_size` 太小；或 patch 通道本身稀疏 | 提高 `min_cluster_size`；合并距离阈值内的 patch；报 patch 大小分布 |
| 环带计数随半径线性增长的假象 | 未按环带面积归一化 | 用密度（count/area）；tools 脚本已同时输出两者 |
| 相互作用检验几乎全部显著 | 伪重复：7×10⁵ 个细胞级样本被当作独立样本 | 改为**患者级/core 级聚合或混合效应模型**（D9）；报效应量 |
| 置换 p 值与 Mann–Whitney p 值相差十几个数量级 | 二者机制不同：置换分辨率 ≤ 1/100；M-W 用大样本近似 | 报告中写明所用检验与分辨率（§四 #4） |
| 相互作用阈值 265 "pixels" 算出的物理距离离谱 | 像素尺寸用错（0.23 μm vs 20 μm） | 用 COMET 的 0.23 μm/px → ≈60.95 μm；并做敏感性扫描 |
| 代谢物 m/z 与基质峰高度重合 | 1,5-DAN 基质簇峰未剔除 | 采集空白基质区（matrix-only）做背景峰黑名单 |
| 代谢物丰度组间差异巨大但方向不稳 | 未做 RMS/TIC 归一化，或切片间基质结晶差异 | 归一化 + 加切片/批次作为协变量 |
| PLS-DA 分类完美（AUC=1） | 特征选择泄漏（先用全部样本挑 82 个代谢物，再做判别）+ 成分数过多 | 嵌套交叉验证；用 Q² 与置换检验评估（D12） |
| 代谢物-标志物相关性很高但不可重复 | 空间自相关导致的伪相关 | 加环面平移/空间置换零模型（11 号 §④） |
| 患者级结论稳健性差，core 级 p 值极小 | core 级当独立样本 | 患者级聚合 + 混合效应（D9）；补功效分析（09 号） |
| 与原文图"看起来不一样" | 替代数据集的面板/疾病不同 | 在图上显式标注"surrogate data"，不做逐像素比较 |

## 四、原文疏漏、矛盾与不可复现点（逐条核对清单）

> 这一节是**复现者必须自己补齐的部分**。预印本未经同行评审，方法学描述比正式期刊文章更粗，以下逐条列出并给出复现决策。

| # | 位置 | 问题 | 影响 | 复现决策 |

| 2 | 全篇统计 | **伪重复**：以 695,444 个细胞（或数十万条距离）为单位做检验，而独立患者仅 26 例 | p 值被极度夸大（2.22e-16 这类量级对患者级结论毫无信息量） | **主分析改为患者级聚合或混合效应模型**（D9）；core 级分析只作描述性 |
| 3 | Methods「Statistical analyses」 | 未报告**效应量**（只报 p） | 无法判断生物学幅度 | 一律补报：中位距离差（μm）、fold enrichment、比例差与 95% CI |

| 5 | Methods「Cell-cell interaction analysis」 | 阈值 **265 pixels** 未说明坐标系；作者未给 μm 换算 | 尺度不可核（0.23 μm/px → 60.95 μm；若误用 MALDI 的 20 μm/px 则完全离谱） | **按 COMET 0.23 μm/px 换算为 ≈60.95 μm**，并在 30–100 μm 做敏感性扫描（D6）。**定量结论（本项目合成数据实测）**：在该细胞密度下平均 Delaunay 边长 ≈12.5 μm（p99 ≈30.2 μm），60.95 μm 阈值约为均值的 **4.9 倍 → 仅过滤约 0.33% 的边，接近空操作**。即：这个阈值对结论几乎不构成约束，**真正的空间信号来自 Delaunay 邻接本身的几何结构**，而非该距离截断 |

### 5.3 三个必须在报告中讲清的"张力"

1. **群组 vs 局部（Simpson 悖论类）**：R 组整体 tryptophan 代谢物降低，但 R 样本内 CD163⁺ 巨噬密集区的 tryptophan score 更高。**两者都对**，但**不能只引用其一**。原文自己指出这点（"spatial enrichment within a core can coexist with overall low pathway abundance"），值得肯定。
2. **CD163⁺ TAM 的双面性**：教科书里 CD163⁺ 巨噬多与免疫抑制/预后差相关；本文发现 R 中 CD163⁺ 巨噬**更多且与肿瘤更近**，同时 IRF4/Arg1 更低。可能的解释：在 ICI 响应者中，CD163⁺ 巨噬处于**促炎/抗原提呈倾向**的功能态（而非 M2 抑制态）。这是一个**可检验的重要假说**，但需要功能实验（而非仅强度分层）支持。
3. **UFA 的方向反转**：主流证据支持 UFA/SCD1 促免疫抑制与 ICI 抵抗，而本文在 **R 的 TME** 观察到 UFA 升高。若该结果稳健，则提示**区室特异**的脂质-免疫关系（甚至可能与 T 细胞脂质需求有关）；若不稳健，则可能是基质结晶/归一化/样本量的假象。**这是一个应当优先独立验证的方向。**

### 5.4 方法学层面的可改进点（复现时可直接补）

1. 所有空间统计加**空间自相关零模型**（环面平移/旋转），并报 Moran's I。
2. 所有组间比较改为**患者级聚合或混合效应 β-二项模型**，附**功效分析**（26 例能检出多大效应？09 号给出了模拟）。
3. 相互作用分析补报**效应量**（距离差 μm、fold enrichment）与 **BH 校正**，并明确置换分辨率。
4. 表型注释从"手工阈值"升级为"无监督聚类 + 一致性验证"，公开阈值与代码。
5. MALDI 增加 **MS/MS 或标准品验证**（至少对色氨酸与 UFA 关键代谢物），并把 MSI 置信度写进结论限定。
6. PLS-DA 改为**嵌套交叉验证 + 置换检验**，报告 Q²/VIP。
7. 蛋白-代谢物耦合改为**同一张切片上的多模态**（若技术允许）或至少用**多尺度网格**做稳健性检验。
8. 公开原始数据与代码（本方案就是为此准备的工程框架）。

### 5.5 值得肯定的地方（保持学术公允）

- **技术整合有真难度**：COMET 40-plex + MALDI-IMS 相邻切片的配准与整合，是空间多组学中较难组合的一类。
- **黑色素漂白**步骤对黑色素瘤是必需且容易被忽略的细节，作者写清楚了。
- **样本层面的稀缺性**：26 例 MuM、97 cores 在罕见瘤种里已属不易（且明确说明了 pre/post 不对称的原因）。
- **Limitations 段落写得诚实**，作者主动列出了五条限制。
- **"组成相似但空间/状态不同"的核心观察**与空间生物学的主流认识一致，且给出了可操作的后续假说。

## 八、结语：本项目应当如何被"交付"

给博士生三条铁律：

1. **把"不可复现"讲清楚，是这个项目最重要的学术产出。** 预印本 + 数据不公开 + 伪重复，这三点说清楚了，比多跑几张图有价值。
2. **A 类做到无懈可击。** 合成数据上的 ARI、功效、FPR、环带误差，是可量化、可比较、可发表的证据；`tools/` 里那三个脚本是**可被别人引用的开源实现**。
3. **批判要给出口。** §五 5.6 的八个方向（尤其"伪重复的规范解法"与"UFA 方向反转的检验"）可以直接作为开题或短文的起点。

> **一句话总结这篇预印本该怎么用**：
> 它是**空间多组学的技术示范 + 一批可检验假说**。它的算法骨架是好的，它的数据是不可得的，它的统计是**必须重做**的。**复现它的方法，质疑它的推断，验证它的假说**——这正是本方案的三层结构。
