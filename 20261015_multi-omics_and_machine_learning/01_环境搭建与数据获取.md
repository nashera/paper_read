# 01 环境搭建与数据获取

> **前置依赖**：无。**产出**：可复现的双语言环境 + `raw/` 下全部原始数据 + 统一元数据表 `metadata_samples.csv`。
> **对应原文**：Methods "Data acquisition and preprocessing"、"Statistical analysis"；Supplementary Table 1–2。

---

## 1. 生物学/工程背景

多组学复现的第一失败源不是算法而是**环境与数据版本**：Seurat 4.x 与 5.x 的默认参数不同（如 `FindClusters` 算法、SCTransform 版本），Harmony 的 R/Python 实现数值不一致，GEO 补充文件随时可能被提交者更新。因此本方案强制：① 版本钉死；② 所有下载记录 checksum；③ 元数据集中管理。

## 5. 数据下载脚本

### 5.1 GEO 单细胞与空间数据

```bash
# code/01_download_geo.sh
mkdir -p raw/scrna raw/spatial raw/bulk
for GSE in GSE289173 GSE212837 GSE202379 GSE189600 GSE189175 GSE166504; do
  mkdir -p raw/scrna/$GSE
  # GEO FTP 批量下载补充文件（10x 的 barcodes/genes/matrix 或 h5）
  rsync -avP --include='*/' --include='*matrix*market*' --include='*.h5' \
        --include='*.gz' --exclude='*' \
        ftp://ftp.ncbi.nlm.nih.gov/geo/series/${GSE:0:6}nnn/$GSE/suppl/ \
        raw/scrna/$GSE/
done
mkdir -p raw/spatial/GSE248077
rsync -avP ftp://ftp.ncbi.nlm.nih.gov/geo/series/GSE248nnn/GSE248077/suppl/ \
      raw/spatial/GSE248077/
```

> Visium 数据需要三类文件：`filtered_feature_bc_matrix/`（或 h5）、`tissue_positions_list.csv`（空间坐标）、`tissue_hires_image.png`（组织图）。若 GEO 未提供图像，可只用坐标做反卷积定量（不影响 RCTD）。

### 5.2 bulk 队列

## 7. 导师提示（常见坑）

1. **GSE 编号与 GSM 的对应**：一个 GSE 可能混有多个供体/技术重复；整合时批次变量用 `dataset`（GSE 级）而非 sample 级，否则 Harmony 会过度校正。
2. **小鼠验证队列不可与人队列合并**：GSE166504 只用于①独立验证②RCTD 参考图谱（原文如此），不要混入发现队列的整合对象。
3. **10x h5 vs mtx**：优先读 h5（含 feature 类型信息），mtx 需自行补 gene annotation。
4. **下载限速**：NCBI FTP 对并发敏感，脚本内加 `sleep` 或用 `rsync --bwlimit`。
