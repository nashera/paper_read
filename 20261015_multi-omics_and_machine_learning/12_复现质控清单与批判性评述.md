## 二、排错手册（高频偏差 → 根因 → 处置）

| 偏差现象 | 可能根因 | 处置 |
|---|---|---|
| 细胞总数差 >5% | MAD 阈值实现差异（双侧 vs 单侧 mt） | 按 02 文档双口径各跑一次，选与原文最接近者并记录 |
| cluster 数 ≠ 7 或 marker 混乱 | resolution / HVG 数 / Harmony dims 不当 | 扫参 0.4–1.2；核对邻域熵；检查双胞（DoubletFinder 敏感性分析） |
| 轨迹方向反了 | 根选错 | 用 CytoTRACE + 静息 marker 双证据重定根 |
| regulon 数偏离 360 较多 | 活跃阈值/motif 库版本/输入细胞集 | 记录三参数；用模块结构稳定性代替绝对数判定 |
| 相关系数差 >0.1 | 探针映射/log 口径/样本过滤 | 固定 symbol 聚合规则；逐队列输出样本数核对 |
| DAR 数差一个量级 | 设计式未加批次协变量 / peak 合并策略 | 加 `~center+disease` 对比；固定宽度重计数 |
| AUC 明显高于 0.839 | 验证集泄漏进特征选择 | 检查 RFE 是否在 CV 内；重跑 |
| AUC 明显低于 | 标签噪声/队列平台差异/特征基因口径 | 核对每队列 MASLD/MASH 标签来源；特征用 05 的 top 基因统一口径 |

## 三、批判性评述（导师/审稿人视角）

### 3.1 优点

1. **多组学闭环设计**：scRNA（发现）→ 空间（共定位）→ bulk（跨队列稳健性）→ ATAC（表观因果佐证）→ ML（转化），每层结论都有独立组学背书，符合转化医学"发现-验证-转化"范式。
2. **机器学习的集成与解释**：113 配置 + 外部 5 队列 + SHAP，避免了单模型过拟合叙事；mean AUC 0.839 相对 RF 单模型（~0.75）与 CK-18（~0.80）有增量。
3. **新亚群的数据驱动发现**：DTNA⁺ Mac 非预设 marker，而是聚类-注释-富集-轨迹-调控五步证据链支撑。

### 3.2 局限与风险（复现者必须心里有数）

1. **参考图谱跨物种**：RCTD 用小鼠 GSE166504 反卷积人 Visium（Methods 明写），同源映射误差未量化；共定位结论对人参考的敏感性未知。
2. **轴的证据等级**：RUNX2–PLG–PARD3 为"共表达相关 + motif 富集 + 通讯推断"，缺蛋白/功能实验（原文自承）；PLG 经典为肝源，巨噬来源 PLG 的定量占比未给出。
3. **113 配置网格不公开**：22+91 的构成规则未在 Methods 细化，复现只能重构（见 11 文档声明）；这是可复现性最大缺口。
4. **组成数据的因果误读风险**：Ro/e 为相对组成；"浸润增多"的绝对量结论依赖空间/小鼠正交证据，解读时勿越级。
5. **eMASH/aMASH 仅一个数据集有分期**（GSE289173，9+10 例），分期相关结论功效有限。
6. **DAR 阈值未报告**：14.6 万上调 DAR 的 padj/FC 口径缺失，复现需自行声明（10 文档）。

### 3.3 可扩展的研究方向（给课题组的选题池）

1. **因果推断升级**：对 RUNX2→PLG 用扰动数据（CRISPRi scRNA / 小鼠 Runx2 条件敲除髓系）+ 因果网络（如因果 SCENIC/DoRothEA 扰动版）验证。
2. **空间多组学**：以人肝 Visium/ Xenium 重做共定位；加入蛋白层（CODEX）验证 PLG–PARD3 空间邻接。
3. **纵向队列 ML**：把 DTNA signature 放到前瞻性队列（如 NASH-CRD 队列）做 at-risk MASH 预测，报校准曲线与决策曲线（DCA），而不只 AUC。
4. **血浆可测性转化**：DTNA/PLG 是否有可溶性形式或外泌体载体，决定"无创"可行性——这是原文临床叙事的关键未证前提。
5. **单细胞多组学**：scATAC+scRNA 配对直接验证 DTNA⁺ Mac 内 RUNX2 motif 可及性-表达耦合。
