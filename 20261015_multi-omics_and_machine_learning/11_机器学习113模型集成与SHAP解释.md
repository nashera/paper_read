## 1. 框架总览与"113"的构成

原文框架两阶段：
1. **特征选择**：Recursive Feature Elimination（RFE）——用某个基学习器（常为 RF/LDA）反复拟合，按重要性递归剔除最弱特征，以 CV AUC 选最优特征子集；
2. **预测建模**：stacked generalization（堆叠泛化）——第一层多个基学习器并行训练，其预测（概率）作为第二层元学习器的输入。

12 个算法族：正则化（Lasso、Ridge、ElasticNet）、广义线性（Stepglm、glmBoost、plsRglm）、集成（RF、GBM、XGBoost）、模式识别（SVM、LDA、NaiveBayes）。

其中最优模型 ElasticNet 的目标函数（逻辑回归损失 + 混合 L1/L2 正则）：

$$\hat{\beta} = \arg\min_{\beta} \; \frac{1}{n}\sum_{i=1}^{n} \ell\left(y_i, \mathbf{x}_i^{\top}\beta\right) \;+\; \lambda\left[\alpha \|\beta\|_1 + \frac{1-\alpha}{2}\|\beta\|_2^2\right]$$

$\alpha$ 即原文的 $\alpha$（sklearn 的 `l1_ratio`，glmnet 的 `alpha`）：$\alpha = 1$ 退化为 Lasso（稀疏选基因），$\alpha = 0$ 退化为 Ridge（共线基因共享权重）；原文最优 $\alpha = 0.9$ 接近 Lasso，故最终只保留 8 个非零系数基因。$\lambda$ 由 CV 自动选取（`ElasticNetCV`）。

**113 = 22 单算法变体 + 91 集成模型**。原文未公开网格明细，以下为可复现的**重构规则**（复现报告中必须声明）：

- 14 个基学习器变体 B = {Lasso, Ridge, Enet(α=0.1), Enet(α=0.5), Enet(α=0.9), Stepglm, glmBoost, plsRglm, RF, GBM, XGBoost, SVM, LDA, NaiveBayes}；
- 单算法变体 22 = B(14) + 8 个超参变体（RF 的 mtry 两档、GBM 的 interaction.depth 两档、XGB 的 eta 两档、SVM 的 cost 两档）；
- 集成 91 = C(14, 2) 的两两堆叠组合（第一层两基学习器概率 → 第二层 logistic 元学习器）。

评估：**分层 10 折 CV**（stratified 10-fold）在训练集（GSE135251）内做配置选择；最优配置在 5 个外部验证集报告 AUC；**mean AUC = 训练+验证的平均 = 0.839**，最优 = Enet(α=0.9)。

**输入特征**：DTNA⁺ Mac 的特征基因（05 的 FindAllMarkers top 基因，或 DTNA⁺ Mac vs 其余髓系的 DEG），经 RFE 收敛；最终模型基因 = **ARHGAP22, DHRS9, DTNA, ITGAX, RUNX2, TRPM2, TESK2, AUTS2**（8 基因，见 Fig.8H 与 SHAP 列表）。

## 3. SHAP 解释（Fig. 9A–D）

### 3.1 原理

SHAP（Shapley Additive exPlanations）把预测分解为特征的加性贡献。设特征全集 $F$，模型 $f$，特征 $j$ 的 Shapley 值为

$$\varphi_j = \sum_{S \subseteq F \setminus \{j\}} \frac{|S|!\,(|F| - |S| - 1)!}{|F|!} \left[ f(S \cup \{j\}) - f(S) \right]$$

即特征 $j$ 在所有特征子集组合下的边际贡献按子集大小加权平均。满足三条公理：

- **局部准确性**：$\sum_{j \in F} \varphi_j = f(x) - \mathbb{E}[f(x)]$；
- **缺失性**：对预测无影响的特征 $\varphi_j = 0$；
- **一致性**：若模型改动后特征 $j$ 的边际贡献不减，则 $\varphi_j$ 不减。

对线性模型（Enet）可用 **LinearExplainer** 精确计算（无需采样近似）：

$$\varphi_j = w_j \left( x_j - \mathbb{E}[x_j] \right)$$

其中 $w_j$ 为 Enet 学到的系数，$\mathbb{E}[x_j]$ 为特征 $j$ 在背景数据上的均值。

### 3.2 代码

## 5. 导师提示与陷阱

1. ** leakage 防线**：RFE 与超参搜索必须包在 CV 内部（用 Pipeline + cross_val_score），否则 AUC 虚高；外部验证集在配置选择阶段**完全不可见**。
2. **标准化**：Lasso/Ridge/Enet/SVM/LDA 对量纲敏感，必须 StandardScaler 且 scaler 在每折内 fit（Pipeline 自动保证）。
3. **Enet 的 α 语义**：sklearn 的 `l1_ratio` 即原文 α（α=0.9 接近 Lasso）；glmnet(R) 的 alpha 同义。跨语言复现时勿混。
4. **mean AUC=0.839 的口径**：原文为"training set + five external validation sets"的平均；复现表格必须逐队列列出后再平均，避免只报验证均值。
5. **8 基因 vs 7 基因**：Fig.8H 画 7 基因箱线（无 AUTS2），SHAP 列 8 基因（含 AUTS2）；两者都来自 Enet 非零系数，AUTS2 系数小故箱线未展示——复现时以系数表为准统一。
6. **小样本高维**：bulk 队列样本量几十到上百，特征 8 个是 RFE 后的结果；若跳过 RFE 直接用全转录组，Enet 会选出完全不同的基因集——RFE 是复现成败关键。
