## 1. 科学问题与统计原理

### 1.1 为什么需要质控（QC）

10x Chromium 的单细胞悬液制备会造成三类污染：① 空液滴（ambient RNA，低 UMI 低基因数）；② 双胞/多胞（doublet，UMI 与基因数异常高）；③ 凋亡/破损细胞（胞质 RNA 泄漏，线粒体转录本占比升高——因为线粒体有双层膜且 mt-mRNA 拷贝数高，细胞膜破裂后胞质 mRNA 降解而线粒体转录本相对保留）。QC 的目标就是在计数分布上切除这三类离群点。

### 1.2 MAD 离群过滤（原文方法）

原文采用 **Median Absolute Deviation（MAD）** 法：对某指标 $x$（如 nCount_RNA、nFeature_RNA、percent.mt），计算

- 中位数 $m = \mathrm{median}(x)$
- $\mathrm{MAD} = \mathrm{median}(|x_i - m|)$
- 修正 z 值（modified z-score）：$z_i = 0.6745 \cdot (x_i - m) / \mathrm{MAD}$

**判据**：$|z_i| > 3$（即偏离中位数超过 3 个 MAD）视为离群并剔除。

> 为什么用 MAD 而不是均值±3SD？单细胞计数分布严重右偏且含离群点，均值与 SD 会被离群点本身拉偏（masking 效应）；中位数与 MAD 的崩溃点（breakdown point）为 50%，稳健得多。系数 0.6745 使 MAD 在正态假设下等价于 SD（$\mathrm{MAD} \approx 0.6745\sigma$）。

### 1.3 高变基因（HVG）选择原理

Seurat `FindVariableFeatures`（method="vst"）：对每个基因拟合均值-方差关系。设基因 $g$ 的均值 $\mu_g$、方差 $\sigma^2_g$，先对 $\log\mu$ 与 $\log(\sigma^2/\mu)$（即离散度的对数）做局部多项式回归得到期望关系，再计算标准化残差作为"可变性"评分：

$$v_g = \frac{\log(\sigma^2_g/\mu_g) - \mathrm{fitted}_g}{\mathrm{sd}(\mathrm{residuals})}$$

取 $v_g$ 最高的 3000 个基因（原文指定 top 3000）。**意义**：单细胞数据的技术噪声（泊松/负二项抽样噪声）随均值增大而增大；直接在原始方差上排序会选出高表达管家基因。vst 法先扣除均值依赖的技术噪声，留下"超出技术预期的生物学变异"。

### 1.4 PCA → 近邻图 → 聚类 → UMAP 的链条

1. **PCA**：对 3000 HVG 的 Pearson 残差矩阵做 SVD，取前 k 个主成分（PC）。本质是在基因空间找方差最大的正交方向，把 ~2 万维压到 k≈30–50 维。
2. **FindNeighbors**：在选定 PC 空间构建 k-NN 图（默认 k=20），并用 Jaccard 相似度精炼边权（共享近邻比例），得到 SNN 图（shared nearest neighbor graph）。
3. **FindClusters**：在 SNN 图上做 **Louvain/Leiden 社区检测**——最大化模块度

$$Q = \frac{1}{2m}\sum_{ij}\left[A_{ij} - \frac{k_i k_j}{2m}\right]\delta(c_i, c_j)$$

其中 $A_{ij}$ 为邻接权重、$k_i = \sum_j A_{ij}$ 为节点度、$m = \frac{1}{2}\sum_{ij}A_{ij}$、$\delta(\cdot)$ 在 $c_i = c_j$ 时取 1。resolution 参数控制社区粒度（原文未给出，复现建议 0.4–0.8 扫描）。
4. **UMAP**：非线性降维可视化。在高维构造模糊拓扑（高斯核距离 → 归一化相似度），在低维用 Student-t 族分布拟合，交叉熵梯度下降优化。保留局部邻域结构，全局距离不可解释。

### 1.5 Harmony 去批次原理（原文指定）

多数据集合并后，技术批次（文库制备、测序深度、供体）会在 PC 空间形成与生物学无关的簇偏移。Harmony（Korsunsky et al. 2019）做**软 k-means + 批次校正的迭代优化**：

目标函数（对细胞 $i$ 的校正后嵌入 $\mathbf{z}_i$）：

$$\min_{\mathbf{c},\mathbf{r}} \; \sum_i \|\mathbf{z}_i - \mathbf{c}_{k(i)}\|^2 \;+\; \lambda \sum_i \sum_k r_{ik}\left\|\mathbf{c}_k - \sum_b \frac{r_{ik}\varphi_{ib}\,\mathbf{c}_{kb}}{\sum_b r_{ik}\varphi_{ib}}\right\|^2 \;+\; \text{熵正则}$$

- 第一项：细胞靠近其所属聚类中心 $\mathbf{c}_k$（软分配权重 $r_{ik}$）；
- 第二项：惩罚"聚类中心在不同批次间的偏移"，即把每个聚类内部的批次均值差异抹平（$\varphi_{ib}$ 为细胞 $i$ 属于批次 $b$ 的指示，$\mathbf{c}_{kb}$ 为聚类 $k$ 在批次 $b$ 内的中心）；
- 第三项（熵正则）：鼓励每个细胞只属于少数聚类，防止过度平滑。

迭代：E 步更新软分配 $r_{ik} \propto \exp(-\|\mathbf{z}_i - \mathbf{c}_k\|^2/2)$ → M 步用 ridge 回归闭式解更新校正量 → 直至收敛。**效果**：同一细胞类型跨数据集混合，而不同细胞类型保持分离。这就是原文 Fig. 2A（整合前按数据集分离）→ Fig. 2B（整合后混合）的含义。

## 2. 逐步代码（R，Seurat 4.3.0）

### 2.1 读入与单样本 QC

```r
# code/02_qc_integrate.R
library(Seurat); library(harmony); library(data.table); library(future)
plan("multisession", workers = 16)
set.seed(20260101)

datasets <- c("GSE289173","GSE212837","GSE202379","GSE189600","GSE189175")
obj.list <- list()

for (gse in datasets) {
  # 假设每个 GSE 下按 sample 分目录存放 10x mtx
  samp.dirs <- list.dirs(file.path("raw/scrna", gse), recursive = FALSE)
  sc.list <- lapply(samp.dirs, function(d)
    Read10X(d) |> CreateSeuratObject(project = basename(d)))
  so <- merge(sc.list[[1]], sc.list[-1], add.cell.ids = basename(samp.dirs))
  so$dataset <- gse
  so$sample  <- sub("_[^_]+$", "", colnames(so))   # 按实际命名调整
  obj.list[[gse]] <- so
}

# --- 指标计算 ---
qc <- function(so) {
  so[["percent.mt"]] <- PercentageFeatureSet(so, pattern = "^MT-")
  so[["percent.rb"]] <- PercentageFeatureSet(so, pattern = "^RP[SL]")
  so
}
obj.list <- lapply(obj.list, qc)

# --- MAD 过滤（原文：偏离中位数 >3 MAD 视为离群）---
mad_filter <- function(so, feats = c("nCount_RNA","nFeature_RNA","percent.mt")) {
  keep <- rep(TRUE, ncol(so))
  for (f in feats) {
    x  <- so[[f]][[1]]
    m  <- median(x); madv <- median(abs(x - m))
    z  <- 0.6745 * (x - m) / madv
    keep <- keep & (abs(z) <= 3)
  }
  so[, keep]
}
obj.list <- lapply(obj.list, mad_filter)
# 注意：percent.mt 的离群是"单侧"问题（过高=凋亡），实践中常改为
# z > 3 剔除 + 硬阈值 percent.mt < 20 双保险；原文只写了 3 MAD，
# 复现时先严格按 3 MAD，若残留高 mt 细胞再补硬阈值并记录。

saveRDS(obj.list, "processed/sc_list_qc.rds")
```

**QC 检查点**：记录每步剩余细胞数； violin 图（nCount / nFeature / percent.mt 分 dataset）确认双峰/拖尾被切除。最终全队列合并细胞数应逼近原文 **570,194**（允许 ±2%，因 MAD 对分布敏感）。

### 2.2 标准化、HVG、PCA、Harmony、聚类、UMAP

```r
so <- merge(obj.list[[1]], obj.list[-1])
so <- NormalizeData(so, normalization.method = "LogNormalize", scale.factor = 1e4)

so <- FindVariableFeatures(so, selection.method = "vst", nfeatures = 3000)  # 原文 3000 HVG
so <- ScaleData(so, features = VariableFeatures(so))                        # z-score 标准化
so <- RunPCA(so, features = VariableFeatures(so), npcs = 50, verbose = FALSE)

ElbowPlot(so, ndims = 50)   # 人工+JackStraw 辅助选 k；肝脏 57 万细胞经验 k=30

# --- Harmony 去批次（原文指定，在聚类前）---
so <- RunHarmony(so, group.by.vars = "dataset",   # 批次 = 数据集
                 reduction = "pca", reduction.use = "pca",
                 dims.use = 1:30, max.iter.harmony = 20,
                 plot_convergence = TRUE)

# --- 基于 harmony embedding 的图聚类与 UMAP ---
so <- FindNeighbors(so, reduction = "harmony", dims = 1:30)
so <- FindClusters(so, resolution = 0.6)          # 0.4/0.6/0.8/1.0 扫描后按 marker 可分性定
so <- RunUMAP(so, reduction = "harmony", dims = 1:30, seed.use = 20260101)

markers <- list(
  Hepatocytes    = c("ASGR1","CYP2C19","CYP3A4"),
  Endothelial    = c("PTH1R","PTPRB","STAB2"),
  Tcells         = c("CD2","CD3D","CD3E"),
  MonoMac        = c("CD163","LYZ","MARCO"),
  HSC            = c("COL3A1","DCN"),
  Cholangiocytes = c("KRT7","CFTR"),
  Bcells         = c("CD79A","MS4A1","IGHM"))

# 方法 A（可复现、客观）：每个 cluster 对每套 marker 取平均表达 z-score 打分，取最大者
score.mat <- sapply(markers, function(g)
  colMeans(as.matrix(GetAssayData(so, "data")[g, ])))   # 基因在 cluster 内平均
clus <- sort(unique(so$seurat_clusters))
assign <- sapply(clus, function(c){
  s <- rowMeans(t(score.mat)[, so$seurat_clusters == c, drop=FALSE])
  names(which.max(s)) })
so$celltype <- assign[as.character(so$seurat_clusters)]

# 方法 B（稳健性复核）：AddModuleScore + FindAllMarkers 双验证
so <- AddModuleScore(so, features = markers, name = "ct_")
# 每个 cluster 取 score 最高模块，应与方法 A 一致；不一致的 cluster 人工看 DotPlot

DotPlot(so, features = unique(unlist(markers)), group.by = "celltype") +
  RotatedAxis() + theme(axis.text.x = element_text(angle = 90))
ggsave("figures/Fig2E_marker_dotplot.pdf", width = 10, height = 6)

# 每个 cluster 的差异 marker（注释的证据链，存入 results/）
mk <- FindAllMarkers(so, group.by = "celltype", only.pos = TRUE,
                     logfc.threshold = 0.25, min.pct = 0.25)
fwrite(mk, "results/major_celltype_markers.csv")
table(so$celltype)   # 与原文 7 类计数核对
```

**注释原则（导师强调）**：marker 打分只是初筛；最终以"每 cluster 的 top 差异基因是否落在该类型经典 marker/功能基因"为准，遇到双阳性 cluster（如内皮+间质）要拆分或标记 doublet 嫌疑。

## 3. 参数空间与调参指引

| 参数 | 原文值 | 调参空间 | 影响 |
|---|---|---|---|
| HVG 数 | 3000 | 2000–5000 | 过少丢稀有群体信号，过多引入噪声 |
| PCA dims | 未给出（建议 30） | 20–50 | 过少欠拟合结构，过多带入技术噪声 |
| resolution | 未给出 | 0.4–1.2 | 直接决定 cluster 数；用 marker 可分性 + clustree 稳定性选 |
| MAD 阈值 | 3 | 2.5–3.5 | 越严细胞越少；注意与原文细胞总数核对 |
| Harmony dims.use | 1:30 | =PCA dims | 与上游一致 |

## 4. 常见故障

1. **Harmony 后疾病信号也被抹平**：说明批次与疾病高度共线（某数据集只含 MASH）。对策：group.by 仍用 dataset，但检查每个 dataset 的疾病构成；必要时把 dataset×disease 交互作为协变量评估，或对共线数据集降权。
2. **肝细胞占比过高掩盖稀有群体**：正常——原文肝细胞占 56.5%。子聚类阶段（04/05）只对目标群体 subset 后重跑 HVG/PCA/cluster。
3. **merge 后细胞 barcode 冲突**：merge 的 add.cell.ids 必须唯一；读 h5 时同理。
4. **线粒体基因命名**：人 `^MT-`，小鼠 `^mt-`；GSE166504 为小鼠，QC 模式串要切换。
