## ② 背景原理

### 2.1 扰动策略的逻辑

| 扰动 | 预期 | 解释 |
|---|---|---|
| SOX17 过表达（T320） | 恢复谱系身份 → 更敏感 | 谱系因子维持"敏感状态" |
| SOX17 敲低（亲本 C） | 去分化 → 更耐受 | 谱系因子丢失使细胞进入可塑状态 |
| Slug 过表达（C） | 部分耐受 + 更快适应 | EMT 是"使能"而非"充分" |
| CD24/CD44 分选 | 同一群体内不同状态 | 状态与适应度对应 |
| CB-839 + 奥拉帕利 | 协同 | 代谢依赖可靶向 |

### 2.2 为什么用可诱导系统

组成型过表达会产生克隆选择与适应；**doxycycline 诱导**允许在同一克隆内比较"开/关"，减少克隆间差异。Slug 用 pInducer20（Addgene #44012）+ Addgene #82162；SOX17 用组成型 TFORF2260（Addgene #141998），因为需要长期维持谱系身份。

### 2.3 活细胞成像的定量

IncuCyte 每 ≥24 h 采集相位图，计算**汇合度（confluence, %）**。汇合度 ≈ 细胞面积占比，可作为增殖/存活的代理。关键：同一孔内不要过度汇合（>90% 会饱和）；每 3 天换液+药物。

### 2.4 Transwell 侵袭

Matrigel 包被的 8 μm 孔膜；细胞穿过膜后被固定/结晶紫染色；计数或面积定量。原文用 30% Matrigel、50,000 细胞、72 h。

### 2.5 qPCR 的 ΔΔCt

$$\Delta\Delta C_t = (C_{t,\text{target}} - C_{t,\text{RPL19}})_{\text{sample}} - (C_{t,\text{target}} - C_{t,\text{RPL19}})_{\text{control}}$$
相对表达 = $2^{-\Delta\Delta C_t}$。原文用 RPL19 作内参。

### 2.6 Bliss 协同

$$E_{AB} = E_A + E_B - E_A E_B$$
$$S = E_{obs} - E_{AB}$$
S>0 协同；S<0 拮抗。需要**全剂量矩阵**（奥拉帕利 1–320 μM × CB-839 0/50 nM），并单独测 CB-839 单药。

### 4.4 qPCR

```r
# code/09_01_qpcr.R
# 输入：results/09_qpcr_ct.csv（sample, gene, ct, replicate）
library(dplyr); library(tidyr); library(ggplot2)
ct <- read.csv("results/09_qpcr_ct.csv")

# 先转宽表，使 RPL19 与目标基因在同一行；再算 ΔCt/ΔΔCt
wide <- ct %>%
  select(sample, gene, replicate, ct) %>%
  pivot_wider(names_from = gene, values_from = ct)
stopifnot("RPL19" %in% colnames(wide))

ddct <- wide %>%
  mutate(dct = SNAI2 - RPL19) %>%                 # 目标基因按实际列名替换
  group_by(sample) %>%
  mutate(ddct = dct - mean(dct[sample == "C"]),
         rel = 2^(-ddct)) %>%
  ungroup()

summ <- ddct %>% group_by(sample, gene) %>%
  summarise(mean = mean(rel), sd = sd(rel), n = n(), .groups = "drop")

p <- ggplot(summ, aes(sample, mean, fill = sample)) +
  geom_col() + geom_errorbar(aes(ymin = mean - sd, ymax = mean + sd), width = .2) +
  facet_wrap(~ gene, scales = "free_y") +
  labs(y = "Relative expression (2^-ddCt)", x = NULL) +
  theme_classic() + theme(axis.text.x = element_text(angle = 45, hjust = 1))
ggsave("figures/FigED6k_snai2_qpcr.pdf", p, width = 6, height = 4)
```

```r
# code/09_05_combination.R
# 输入列：line, olaparib_uM, cb839_nM, replicate, viability
# 必须包含三条臂：奥拉帕利单药（cb839=0）、CB-839 单药（olaparib=0, cb839=50）、联合
suppressPackageStartupMessages({library(drc); library(dplyr); library(tidyr); library(tibble)})
d <- read.csv("results/09_viability_combination.csv")

# 按条件取均值（先平均技术/生物学重复）
avg <- d %>% group_by(line, olaparib_uM, cb839_nM) %>%
  summarise(viability = mean(viability), .groups = "drop")

fit_ic50 <- function(df) {
  m <- drm(viability ~ olaparib_uM, data = df %>% filter(olaparib_uM > 0), fct = LL.4())
  coef(m)[["e"]]   # LL.4 的 ED50 参数名为 e
}

ic <- avg %>% group_by(line, cb839_nM) %>%
  group_modify(~ tibble(ic50 = fit_ic50(.x))) %>% ungroup()

ratio <- ic %>% select(line, cb839_nM, ic50) %>%
  pivot_wider(names_from = cb839_nM, values_from = ic50,
              names_prefix = "cb") %>%
  mutate(ratio = cb50 / cb0)   # 联合 / 奥拉帕利单药
write.csv(ratio, "results/09_ic50_combination_ratio.csv", row.names = FALSE)

# Bliss：E_AB = E_A + E_B - E_A*E_B；S = E_obs - E_AB
e_a <- avg %>% filter(cb839_nM == 0) %>%
  transmute(line, olaparib_uM, e_a = viability / 100)
e_b <- avg %>% filter(olaparib_uM == 0, cb839_nM == 50) %>%
  transmute(line, e_b = viability / 100)

bliss <- avg %>% filter(cb839_nM == 50, olaparib_uM > 0) %>%
  left_join(e_a, by = c("line", "olaparib_uM")) %>%
  left_join(e_b, by = "line") %>%
  mutate(e_obs = viability / 100,
         e_expected = e_a + e_b - e_a * e_b,
         bliss = e_obs - e_expected)
write.csv(bliss, "results/09_bliss_scores.csv", row.names = FALSE)
stopifnot(all(c("e_a","e_b") %in% colnames(bliss)))
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 慢病毒感染效率低 | 病毒滴度低/细胞状态差 | 浓缩病毒；polybrene；换新鲜细胞 |
| 过表达无表型 | 表达不足/克隆选择 | WB 验证；换克隆；延长选择 |
| shRNA 敲低不足 | 构建无效 | 用 3 条中最好的 2 条；qPCR+WB |
| Slug 诱导 45 天细胞漂移 | 长期培养 | 冻存早期克隆；每次复苏后重新诱导 |
| 成像汇合度过早饱和 | 接种过密 | 降低密度；缩短观察间隔 |
| Transwell 全穿过 | 时间过长/Matrigel 过稀 | 缩短至 48 h；增加 Matrigel |
| qPCR 内参不稳定 | 处理影响 RPL19 | 换内参（GAPDH/ACTB）；报告稳定性 |
| CB-839 单药毒性 | 浓度过高 | 滴定；用 50 nM |
| Bliss 计算错误 | 未测单药 | 必须完整矩阵 |
| 结果不可重复 | 细胞代次/血清批次 | 固定代次与血清；记录 |
