## ② 背景原理

### 2.1 平台差异

| 平台 | 样本 | 特点 | 复现注意 |
|---|---|---|---|
| inDrop | Kuramochi C–T320 | 液滴法；barcode 白名单；UMI 计数 | **GEO counts 行为基因 symbol、列为细胞**；metadata 已为 G1 口径并带 `State`（C,S1–S5） |
| 10X Chromium 3′ v3.1 | persisters、其他细胞系、PDX | 标准 CellRanger 输出 | 处理数据为 counts；PDX 只保留 human |
| Cell hashing（TotalSeq-A HTO1–5） | Kuramochi persisters、Ovsaho、COV362 | 抗体 barcode 去多重 | `CITE-seq-Count` v1.4.3 + Seurat |
| 10X CellPlex（CMO） | A375、PC9 | 化学标记多重 | CellRanger 7.0.0，assignment confidence 0.8 |

### 2.2 为什么只保留 G1

细胞周期是单细胞转录组最大的技术变异来源之一。原文用 `CellCycleScoring` 判定 G1/S/G2M，**只保留 G1 细胞**做状态与模块分析，避免"增殖状态"被误读为"适应状态"。代价是损失约一半细胞；因此必须在 QC 表中报告 G1 比例。

**本项目的实际情况**：GEO 提供的 counts/metadata 文件名带 `_g1`，且每线细胞数与原文 ED Fig. 6 图注一致（C 453、T1 1223 …），说明 **GEO 已按 G1 过滤**。因此主口径不再二次过滤；仅用 `CellCycleScoring` 复核 phase 分布，并把"是否重算 G1"作敏感性分析（D3）。

### 2.3 DrImpute

inDrop 数据稀疏、dropout 严重。原文在聚类前用 **DrImpute（k=5:10）** 做缺失填补。DrImpute 通过多个 k 的邻域平均构建共识矩阵；k 范围越大越平滑，但也可能抹平稀有状态。**敏感性分析**：k=5、k=10、k=5:10 三档。

### 2.4 TPM 与 log

原文："Raw gene expression matrices were TPM-normalized (scale factor of 10^4) and log2-transformed." 即先 TPM，再 `log2(TPM/1e4 + 1)`。

**重要区别**：TPM 按**基因长度**归一化，Seurat `LogNormalize` 是 CP10k（只按细胞总 counts，不按基因长度），二者**不等价**。GEO 提供的是 counts，本项目主口径用 `LogNormalize`（CP10k），并在方法学中声明这一偏离（D21）；若严格复现 TPM，需要基因长度表并把 TPM 矩阵作为备选输入。**关键陷阱**：如果输入已是 log2 TPM，再做一次 `NormalizeData` 会二次变换（尺度错配）；先检查 `range(mat)`。

### 2.5 Louvain 与分辨率

Louvain 在加权图上优化模块度；`resolution` 控制簇的粗细。原文 resolution 0.3–0.6，选择依据是"每线可解释的亚群数"与后续状态共享性。本项目主口径固定 `resolution=0.5`，并对 0.3/0.4/0.6 做敏感性（D3/D4）。

## ④ 逐步可运行代码

### 4.1 读取并核对矩阵方向

> **实测数据格式**（2026-10-18 核对 GEO 文件）：
> - counts 矩阵：**行=基因 symbol（A1BG/A2M…），列=细胞 barcode**；表头第一格为空（无行名标题）。
> - metadata：列 `cell, nGene, nUMI, orig.ident, percent.mito, State`；`State ∈ {C,S1–S5}`；`percent.mito` 为**比例**（0.145 = 14.5%）；**无 phase、无 ribo**。
> - metadata 文件名带 `_g1`，即 GEO 已按 G1 口径给出细胞；本项目保留全部细胞，并**另算** phase 作 QC（D3/D22）。

```r
# code/03_01_load_qc.R
suppressPackageStartupMessages({
  library(Matrix); library(Seurat); library(dplyr); library(ggplot2)
})
set.seed(20261018)

read_geo <- function(path, meta_path) {
  meta <- read.delim(meta_path, check.names = FALSE)
  stopifnot("cell" %in% colnames(meta))
  rownames(meta) <- make.unique(meta$cell)

  # read.csv 能正确处理"表头比数据少一列"的基因×细胞矩阵
  mat <- as.matrix(read.csv(path, row.names = 1, check.names = FALSE))
  if (mean(colnames(mat) %in% rownames(meta)) < 0.5) mat <- t(mat)  # 兜底
  stopifnot(mean(colnames(mat) %in% rownames(meta)) > 0.95)

  meta <- meta[colnames(mat), , drop = FALSE]
  meta$sample <- meta$orig.ident          # 原文按线分析
  meta$percent.mito <- as.numeric(meta$percent.mito) * 100
  cat("matrix:", nrow(mat), "genes x", ncol(mat), "cells\n")
  cat("published State:\n"); print(table(meta$State, useNA = "ifany"))
  list(mat = mat, meta = meta)
}

x <- read_geo(
  "raw/geo/GSE206125/GSE206125_kuramochi_all_C_to_T320.csv.gz",
  "raw/geo/GSE206125/GSE206125_kuramochi_C_to_T320_metadata_g1.tsv.gz"
)
mat <- x$mat; meta <- x$meta
write.csv(as.data.frame(table(meta$State)), "results/03_published_state_counts.csv",
          row.names = FALSE)
```

### 4.2 QC

```r
# 计算每个细胞的 QC 指标（不依赖 metadata 的 nGene/nUMI）
qc <- data.frame(
  cell       = colnames(mat),
  n_counts   = Matrix::colSums(mat),
  n_genes    = Matrix::colSums(mat > 0),
  perc_mito  = Matrix::colSums(mat[grepl("^MT-", rownames(mat)), , drop = FALSE]) /
               pmax(Matrix::colSums(mat), 1) * 100,
  perc_ribo  = Matrix::colSums(mat[grepl("^RP[SL]", rownames(mat)), , drop = FALSE]) /
               pmax(Matrix::colSums(mat), 1) * 100
)

# 原文阈值：n_counts <500 或 >mean+2SD；n_genes <500；mito >20%
upper <- mean(qc$n_counts) + 2 * sd(qc$n_counts)
keep <- qc$n_counts >= 500 & qc$n_counts <= upper &
        qc$n_genes  >= 500 & qc$perc_mito <= 20

# 基因过滤：至少 1% 细胞表达
gene_keep <- Matrix::rowSums(mat > 0) >= 0.01 * ncol(mat)
mat  <- mat[gene_keep, keep, drop = FALSE]
meta <- meta[keep, , drop = FALSE]

# 把本项目计算的 QC 指标写回 metadata（4.3 的 ScaleData 回归要用）
meta$perc_mito  <- qc$perc_mito[keep]
meta$perc_ribo  <- qc$perc_ribo[keep]
meta$n_counts   <- qc$n_counts[keep]
meta$n_genes    <- qc$n_genes[keep]
meta$percent.mito <- meta$perc_mito   # 统一为百分比口径

qc$keep <- keep
write.csv(qc, "results/03_qc_pre.csv", row.names = FALSE)
write.csv(qc[keep, ], "results/03_qc_post.csv", row.names = FALSE)
write.csv(as.data.frame(table(meta$sample)), "results/03_cells_per_condition.csv",
          row.names = FALSE)
```

### 4.5 **按样本分别**回归、降维、聚类（原文 Fig. 1d 口径）

> 原文 Methods：「For the individual analysis of the Kuramochi datasets (C-T320) ... Louvain clustering」；Fig. 1d 的亚群编号是 `C-0, C-1, T1-0 … T320-2`，即**每条线单独聚类**。不能把所有线混在一起聚一次。

```r
# code/03_04_cluster.R
DefaultAssay(srt) <- "imputed"
srt_list <- SplitObject(srt, split.by = "sample")
stopifnot(length(srt_list) == 10)

srt_list <- lapply(names(srt_list), function(s) {
  x <- srt_list[[s]]
  # vst 需要 counts：先在 RNA assay 上选 HVG，再切回 imputed 做缩放/PCA
  DefaultAssay(x) <- "RNA"
  x <- FindVariableFeatures(x, selection.method = "vst", nfeatures = 2000, verbose = FALSE)
  DefaultAssay(x) <- "imputed"
  x <- ScaleData(x, vars.to.regress = c("nCount_RNA", "percent.mt", "percent.ribo"),
                 verbose = FALSE)
  x <- RunPCA(x, npcs = 30, verbose = FALSE)
  npc <- 10   # 以 elbow 图定；记录实际值
  x <- FindNeighbors(x, dims = 1:npc, verbose = FALSE)
  x <- FindClusters(x, resolution = 0.5, algorithm = 1, verbose = FALSE)  # Louvain
  x <- RunUMAP(x, dims = 1:npc, verbose = FALSE)
  x$line_cluster <- paste(s, x$seurat_clusters, sep = "__")
  x
})
names(srt_list) <- names(SplitObject(srt, split.by = "sample"))
saveRDS(srt_list, "processed/03_kura_seurat_list.rds")

# 每线 UMAP（拼图）
library(patchwork)
plots <- lapply(names(srt_list), function(s) {
  DimPlot(srt_list[[s]], reduction = "umap", label = TRUE) + ggtitle(s) + NoLegend()
})
p <- wrap_plots(plots, ncol = 5)
ggsave("figures/Fig1d_UMAP_by_line.pdf", p, width = 15, height = 6)
ggsave("figures/Fig1d_UMAP_by_line.png", p, width = 15, height = 6, dpi = 300)

# 合并对象：只用于 04/05 的表达矩阵与标签，不用于跨样本 UMAP
line_clusters <- bind_rows(lapply(names(srt_list), function(s) {

write.table(line_clusters, "results/03_line_clusters.tsv",

srt_all <- CreateSeuratObject(counts = mat, meta.data = meta, min.cells = 0, min.features = 0)
```

```r
markers <- bind_rows(lapply(names(srt_list), function(s) {
  m <- FindAllMarkers(
    srt_list[[s]], test.use = "MAST",
    logfc.threshold = 0.25, min.pct = 0.2,

    only.pos = TRUE, verbose = FALSE
  )
  m$sample <- s
  m
}))
write.csv(markers, "results/03_cluster_markers.csv", row.names = FALSE)

freq <- markers %>% distinct(sample, cluster) %>%
  left_join(as.data.frame(table(line_clusters$sample, line_clusters$cluster)) %>%
              setNames(c("sample", "cluster", "n_cells")),
            by = c("sample", "cluster")) %>%
  group_by(sample) %>% mutate(fraction = n_cells / sum(n_cells)) %>% ungroup()
```

## ⑥ 预期结果与 QC 检查点

| 检查点 | 预期 | 判据 |
|---|---|---|
| 矩阵方向与细胞匹配 | metadata ⊆ matrix 列 | >95% |
| metadata 列 | `cell,nGene,nUMI,orig.ident,percent.mito,State` | 缺任一列需显式报错 |
| QC 后细胞数 | GEO 已给 8,240 个 G1 细胞 | 与 metadata 行数一致；各线见下表 |
| G1 比例 | GEO 已按 G1 过滤 | 用 `CellCycleScoring` 复核；记录非 G1 比例 |
| 每线 cluster 数 | Fig. 1d 每线 1–3 个亚群 | 与原文分面数量同量级；记录 |

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 找不到 `sample`/`phase`/`perc_ribo` | 误以为 metadata 含这些列 | GEO 实际只有 `orig.ident/State/percent.mito`；按 4.1 映射并自行计算 |
| 每线亚群数与原图不符 | 把所有线混在一起聚类 | 必须按 `sample` 拆分后各自聚类（4.5） |
| 矩阵行列颠倒 | 文件方向与预期相反 | 用 metadata barcode 命中率自动判断（4.1） |
| 二次 log 变换 | GEO 已是 log2 TPM | 检查 `range(mat)`；>30 说明可能已 log |
| 所有细胞被过滤 | 阈值按 counts 但输入是 TPM | 阈值需按数据尺度调整并记录 |
| DrImpute 内存溢出 | 稠密矩阵 | 分块/降采样；≥64 GB |
| UMAP 按样本完全分离 | 批次效应 > 生物学 | 检查是否需要 Harmony/fastMNN；原文对 Kuramochi 未做整合 |
| 没有 G1 细胞 | 细胞周期基因名不匹配 | 用作者提供的 `regev_lab_cell_cycle_genes.txt` |
| 线粒体比例全 0 | 基因名不是 `MT-` 前缀 | 检查 Ensembl ID vs symbol |
| MAST 报错 | 未安装 MAST | `BiocManager::install("MAST")` |
| 聚类结果每次不同 | 未设种子/并行 | `set.seed(20261018)`；固定 `future` 计划 |
| 找不到 `percent.mt` | 未计算 | 在创建对象时写入 meta.data |
