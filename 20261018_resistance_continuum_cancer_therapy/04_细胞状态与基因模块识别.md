## ① 科学问题与逻辑位置

**问题**：

1. 各线内部的转录亚群，能否归并为**少数跨样本共享的状态**（S1–S5）？
2. 这些状态由哪些**基因程序**（A–F）支撑？程序如何沿连续谱逐步组装？
3. persister 处于连续谱的哪个位置？

**逻辑位置**：03 号模块给出"每线 cluster"；本模块把 cluster 升维为**状态**与**模块**，是后续 CNA（05）、ATAC（06）、PDX 映射（07）、CRISPR（08）共同的语义层。

**上游**：03 的 Seurat 对象与 cluster 标记。
**下游**：`processed/04_state_assignment.tsv`、`results/04_gene_modules.csv`、`results/04_state_frequency.csv`、`results/04_module_gsea_<module>.csv`。

## ② 背景原理

### 2.1 两阶段聚类：先"线内"，再"跨线"

直接在全部细胞上做一次聚类会让"样本来源"成为主导因素（批次/治疗史）。原文的策略是：

1. **线内聚类**（03 号模块）：每线独立找亚群；
2. **跨线归并**（本模块）：用每个亚群的平均表达谱做相关聚类，找出跨线共享的状态。

这相当于把"细胞级"问题转换为"亚群级"问题，降低技术噪声，同时保留状态结构。

### 2.2 状态定义的数学

- 每线每簇取 **top 100 DEG**（按 `p_val_adj` 排序；原文按 adjusted P）。
- 合并去重 → 原文得到 **1,511** 个基因。
- 计算每个（样本 × 簇）在 1,511 基因上的平均表达向量。
- 两两 **Spearman 相关** → 距离 `1 - ρ`。
- **average-linkage** 层次聚类。
- 在树图上按结构切 **k=5**，得到 S1–S5。
- 每个细胞继承其所属（样本, 簇）的状态标签。

**为什么用 Spearman**：对表达谱的单调变换不敏感，适合跨平台/跨样本比较；比 Pearson 更稳健。

### 2.3 模块识别（Neftel 方法）

Neftel et al. (Cell 2019) 的核心思想：肿瘤细胞状态不是离散类型，而是**多个程序的连续混合**。因此：

- 不假设互斥；一个基因可属于多个模块；
- 通过"找所有可能的细胞簇 → 每个簇的差异签名 → 按签名相似性合并"来发现程序；
- 最终每个模块是一组**协同表达**的基因，而不是一个硬聚类。

### 2.4 GSEA 的排序统计量

原文：`sign(avg_logFC) × (-log10(P))` 作为基因排序；`fgsea` 做预排序 GSEA；最小基因集 10、最大 500；10,000 次置换；P<0.05、FDR<0.25（Fig. 2b 用 P<0.01）。NES 的符号表示方向：正=模块内富集，负=缺失。

### 4.4 模块识别（Neftel 流程）

```r
# code/04_02_modules.R
library(Seurat); library(dplyr); library(proxy); library(GeneOverlap)

# 关键：用非填补数据
DefaultAssay(srt) <- "RNA"
expr <- GetAssayData(srt, slot = "data")

# 1,000 HVG
DefaultAssay(srt) <- "RNA"
if (length(VariableFeatures(srt)) == 0) {
  srt <- FindVariableFeatures(srt, nfeatures = 1000, verbose = FALSE)
}
hvg <- head(VariableFeatures(srt), 1000)
stopifnot(length(hvg) > 0)
centered <- t(scale(t(as.matrix(expr[hvg, ])), center = TRUE, scale = FALSE))

# 1 − Pearson 距离
d <- as.dist(1 - cor(centered, method = "pearson"))
hc_mod <- hclust(d, method = "average")

# 枚举 k=2..20 的所有候选簇（去掉 <30 细胞或 >80% 细胞）
N <- ncol(expr)
candidates <- list()
for (k in 2:20) {
  g <- cutree(hc_mod, k = k)
  for (cl in unique(g)) {
    idx <- which(g == cl)
    if (length(idx) >= 30 && length(idx) <= 0.8 * N) {
      candidates[[paste(k, cl, sep = "_")]] <- colnames(expr)[idx]
    }
  }
}
# 去重（同一细胞集合只保留一次）
candidates <- candidates[!duplicated(lapply(candidates, sort))]
cat("candidate clusters:", length(candidates), "\n")

# 每个候选簇做 DE（相对其余细胞）
sig_list <- list()
for (nm in names(candidates)) {
  cells <- candidates[[nm]]
  ident <- ifelse(colnames(srt) %in% cells, "in", "out")
  Idents(srt) <- factor(ident, levels = c("out", "in"))
  m <- FindMarkers(srt, ident.1 = "in", ident.2 = "out",
                   test.use = "MAST", logfc.threshold = 0, min.pct = 0.1,
                   min.cells.feature = 10, only.pos = TRUE, verbose = FALSE)
  m$gene <- rownames(m)
  m <- m %>% filter(avg_log2FC > log2(1.8), p_val_adj < 0.001)  # 原文 1.8 倍 = log2FC 0.85
  if (nrow(m) > 50) sig_list[[nm]] <- m
}
cat("signatures passing thresholds:", length(sig_list), "\n")

# Jaccard > 0.75 合并：保留基因数最多的签名
jaccard <- function(a, b) length(intersect(a, b)) / length(union(a, b))
keep <- names(sig_list); drop <- c()
for (i in seq_along(keep)) {
  for (j in seq_along(keep)) {
    if (i >= j || keep[i] %in% drop || keep[j] %in% drop) next
    if (jaccard(sig_list[[keep[i]]]$gene, sig_list[[keep[j]]]$gene) > 0.75) {
      smaller <- if (nrow(sig_list[[keep[i]]]) < nrow(sig_list[[keep[j]]])) i else j
      drop <- c(drop, keep[smaller])
    }
  }
}
sig_list <- sig_list[setdiff(names(sig_list), unique(drop))]
```

### 4.5 签名聚成模块

```r
# 对签名基因集合做 Jaccard 聚类，再将同一大簇的签名合并为模块
genesets <- lapply(sig_list, `[[`, "gene")
jm <- outer(seq_along(genesets), seq_along(genesets),
            Vectorize(function(i, j) jaccard(genesets[[i]], genesets[[j]])))
hc_sig <- hclust(as.dist(1 - jm), method = "average")

# 原文：按 Jaccard 聚类签名，**≥3 signatures** 的簇才构成模块；未给切树高度。
# 主口径：在 Jaccard 距离 0.25（= 相似度 0.75）处切树；若没有模块达到 3 个签名，
# 放宽到 0.40 并记录（D5/D16），不要强行指定 k=6。
cut_at <- 0.25
modules <- cutree(hc_sig, h = cut_at)
if (all(table(modules) < 3)) {
  cut_at <- 0.40
  modules <- cutree(hc_sig, h = cut_at)
}
tab <- table(modules)
keep_mods <- names(tab[tab >= 3])
if (length(keep_mods) == 0) stop("no module has >=3 signatures; check thresholds")
sizes <- sort(tab[keep_mods], decreasing = TRUE)
if (length(keep_mods) > 6) {           # 目标 6 个模块，按签名数保留最大的 6 个
  warning("more than 6 modules; keeping top 6 by signature count")
  keep_mods <- names(sizes)[1:6]
}
map <- setNames(LETTERS[seq_along(keep_mods)], keep_mods)
module_df <- lapply(seq_along(genesets), function(i) {
  data.frame(signature = names(genesets)[i],
             module = map[as.character(modules[i])],
             gene = genesets[[i]], stringsAsFactors = FALSE)
}) %>% bind_rows() %>% filter(!is.na(module))

write.csv(module_df, "results/04_gene_modules.csv", row.names = FALSE)
print(table(module_df$module))
```

```r
# code/04_03_gsea.R
library(fgsea); library(msigdbr); library(dplyr)

run_gsea <- function(markers, pathway_df) {
  r <- markers %>%
    mutate(rank = sign(avg_log2FC) * -log10(pmax(p_val, 1e-300))) %>%
    arrange(desc(rank))
  stats <- setNames(r$rank, r$gene)
  fgsea(pathways = split(pathway_df$gene_symbol, pathway_df$gs_name),
        stats = stats, minSize = 10, maxSize = 500,
        nperm = 10000, eps = 0)
}

hallmark <- msigdbr(species = "Homo sapiens", category = "H")
# 对每个模块的 marker 列表运行；模块基因本身作为 "marker" 时需要
# 用模块 vs 非模块的 DE 结果，而不是直接拿模块基因当 ranked list。
# 因此先对每个模块做 AddModuleScore 高/低分组 DE：
for (m in names(module_list)) {
  srt$grp <- ifelse(srt[[paste0("module_", m, "1")]][, 1] >
                    median(srt[[paste0("module_", m, "1")]][, 1]), "high", "low")
  Idents(srt) <- factor(srt$grp, levels = c("low", "high"))
  dm <- FindMarkers(srt, ident.1 = "high", ident.2 = "low", test.use = "MAST",
                    logfc.threshold = 0, min.pct = 0.1, verbose = FALSE)
  dm$gene <- rownames(dm)
  res <- run_gsea(dm, hallmark)
  res$module <- m
  write.csv(res, paste0("results/04_module_gsea_", m, ".csv"), row.names = FALSE)
}
```

## ⑤ 参数解释与调参空间

| 参数 | 原文 | 本项目 | 改变后果 |
|---|---|---|---|
| top DEG/簇 | 100 | 100 | 过少丢失状态基因，过多引入噪声 |
| 状态基因数 | 1,511 | 运行时核对 | 差异 >20% 需检查 DE 设置 |
| 相关方法 | Spearman | Spearman | Pearson 对高表达基因更敏感 |
| 聚类连接 | average | average | complete 更保守，single 易链式 |
| k（状态） | 5 | 5（主） | 4/6 敏感性；报告 ARI |
| HVG（模块） | 1,000 | 1,000 | 过多引入噪声 |
| 距离（模块） | 1−Pearson | 同 | Spearman 会改变簇形状 |
| 候选簇大小 | ≥30、≤80% | 同 | 过小噪声大，过大不是"状态" |
| 签名阈值 | FC>1.8、adj P<0.001、>50 基因 | `log2FC>log2(1.8)`、adj P<0.001、>50 基因 | 放宽会增加假阳性模块 |
| Jaccard 合并 | >0.75 | 同 | 过低合并不同程序 |
| 每模块签名数 | ≥3 | 同 | 过少模块不稳定 |
| 模块切树 | 原文未给高度 | Jaccard 距离 0.25（=相似度 0.75）；无模块达 3 签名时放宽到 0.40 | 只影响模块粒度，不影响"≥3 签名"判据 |
| 模块数 | 6（A–F） | 目标 6；>6 时保留签名数最大的 6 个并记录 | 5–7 均可解释；报告差异（D16） |
| GSEA 置换 | 10,000 | 10,000 | 过少 P 值不稳 |

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 状态基因数远少于 1,511 | 各线 cluster 太少/DE 阈值过严 | 检查 03 号模块 resolution；放宽 `p_val_adj` 仅用于选基因 |
| k=5 时状态不可解释 | 树结构不支持 5 簇 | 报告 k=4/6；不要强行调参 |
| 一个状态只含一条线 | 批次/治疗史主导 | 检查是否做了跨线平均；必要时按线标准化 |
| 模块数不是 6 | 签名合并阈值不同 | 报告实际模块数；用生物学可解释性命名 A–F |
| 模块 A 基因不富集谱系因子 | 数据尺度/基因名问题 | 检查 `SOX17/PAX8/WT1` 是否存在；用 symbol |
| AddModuleScore 分数全 0 | 基因不在对象中 | `sum(module_list[[m]] %in% rownames(srt))` 断言 |
| GSEA 无显著通路 | ranked list 方向/命名错误 | 检查 `sign(logFC)` 与基因 symbol |
| persister 重叠不显著 | persister DE 阈值不同 | 用相同 MAST 阈值；报告 raw/adj 双口径 |
| 模块热图排序混乱 | 未按状态/线排序 | 手动设定列顺序（C→T320） |
| 代码运行数小时 | 候选簇枚举 × FindMarkers | 先对每簇算平均谱做粗筛，再对候选做 MAST |
