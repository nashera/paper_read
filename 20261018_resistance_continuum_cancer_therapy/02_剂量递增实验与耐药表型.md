## ① 科学问题与逻辑位置

**问题**：逐步倍增药物剂量，能否把一群药物敏感细胞"推"成一组适应度逐级升高的群体？这种升高是预存耐药克隆的选择、单纯治疗时间的累积，还是剂量递增特有的"预适应"？

## ② 背景原理

### 2.1 为什么用剂量递增而不是直接高剂量

直接高剂量会杀死绝大多数细胞，只有极少数**预存**耐药克隆存活；这会把"选择"误当成"适应"。递增策略让细胞在**亚致死剂量**下先发生转录/表观重编程（persister-like priming），再逐步面对更高剂量，从而暴露**适应性轨迹**。原文用两组对照把这两种解释分开：

- **治疗-恢复两轮**（ED Fig. 2a）：若为预存克隆选择，第二轮存活细胞的 IC50 应继续升高；实际未升高 → 支持持久细胞表型。
- **恒量 vs 递增**（ED Fig. 2b–h）：恒量延长可提高耐药但通常不及递增；直接高剂量无法汇合 → 支持"低剂量预适应"。

### 2.2 IC50 与"部分耐受"

IC50 是相对 DMSO 对照的 50% 抑制浓度。原文观察到 C 约 2 μM、T320 约 60 μM。关键解释：**最适应的 T320 仍对其适应剂量 320 μM 敏感**（IC50 远低于 320），所以这是"部分耐受/适应"，不是完全耐药。因此本项目术语严格区分 adapted / persister / resistant（`PROJECT_SPEC.md` §4）。

### 2.3 四参数 logistic 模型

$$Y = \text{Bottom} + \frac{\text{Top}-\text{Bottom}}{1+10^{(\log_{10}IC50 - X)\times \text{HillSlope}}}$$

- `Top`：无药时最大存活（通常归一化为 100%）
- `Bottom`：最高剂量下的残余存活
- `HillSlope`：曲线陡度
- 拟合用 R `drc::drm(fct = LL.4())` 或 GraphPad Prism 9 非线性回归；原文用 Prism 9。

### 4.2 剂量递增主流程

```text
起始：1×10^6 cells / 150 mm dish
D0：接种；D1：加药（1 μM olaparib 或对应起始剂量）
维持：每 3 天换新鲜含药培养基
判定：汇合度 >70%（IncuCyte 或显微镜，双人复核）
传代：0.25% trypsin/EDTA 5 min 37°C → 计数 → 取 1×10^6 接种新皿 → 剂量 ×2
冻存：每一步留 3–5 管（10% DMSO + 50% FBS + 40% medium）
终点：320 μM 下达到 >70% 汇合
```

### 4.3 活力实验与 IC50 拟合

```r
# code/02_01_ic50.R
suppressPackageStartupMessages({
  library(drc); library(dplyr); library(ggplot2); library(readr)
})
set.seed(20261018)

# 输入：长表 results/02_viability_long.csv
# 列：line, drug, dose_uM, replicate, viability_pct
d <- read_csv("results/02_viability_long.csv", show_col_types = FALSE)

fit_one <- function(df) {
  # 4 参数 log-logistic；原文献用 GraphPad Prism 9 的 nonlinear regression
  m <- drm(viability_pct ~ dose_uM, data = df, fct = LL.4())
  coef(m)[["e"]]   # drc::LL.4 的 ED50 参数名为 e
}

# 先按生物学重复分别拟合，再汇总 mean ± SD（契约要求 sd/n）
ic50_rep <- d %>%
  group_by(line, drug, replicate) %>%
  group_modify(~ tibble(ic50 = fit_one(.x))) %>%
  ungroup()

ic50 <- ic50_rep %>%
  group_by(line, drug) %>%
  summarise(ic50 = mean(ic50), sd = sd(ic50), n = n(), .groups = "drop")

write_csv(ic50, "results/09_ic50_summary.csv")

p <- ggplot(d, aes(dose_uM, viability_pct, colour = line)) +
  geom_point(size = 0.8, alpha = 0.5) +
  geom_smooth(method = "glm", formula = y ~ x, se = FALSE) +
  scale_x_log10() +
  labs(x = "Drug (μM, log10)", y = "Viability (% of DMSO)",
       title = "Dose–response across adapted lines") +
  theme_classic(base_size = 12)
ggsave("figures/Fig1b_IC50_all_lines.pdf", p, width = 6, height = 4)
ggsave("figures/Fig1b_IC50_all_lines.png", p, width = 6, height = 4, dpi = 300)
```

> 注：`geom_smooth(method="glm")` 只是可视化占位；**IC50 数值必须取 `drc` 拟合结果**，不要从图上读数。

### 4.4 persister 生成与治疗-恢复

```text
Persister：
  1×10^6 Kuramochi / 150 mm 皿
  加 10 μM 或 320 μM olaparib（>IC90），9 天
  每 3 天换含药培养基
  贴壁存活细胞 = persister（P10 / P320）
  撤药恢复 9 天 → 做活力实验

两轮治疗-恢复（排除预存克隆）：
  Round 1：320 μM 9 天 → 恢复 9 天 → 存活细胞
  Round 2：再 320 μM 9 天 → 恢复 9 天
  测 IC50；若与亲本 C 无显著差异 → 支持 persister 而非预存耐药克隆
```

### 4.5 恒量延长与直接高剂量对照

```text
恒量延长（T5-E / T20-E / T80-E）：
  在 5 / 20 / 80 μM 下持续培养，
  时长 = 对应递增组从该剂量到下一剂量所需的天数
  （原文示例：T5-E 50 天、T20-E 40 天、T80-E 47 天）
  然后测 IC50 与相对细胞数

直接高剂量（T2.5.C / T5.C / T10.C）：
  未处理细胞直接置于 2.5 / 5 / 10 μM
  时长 = 递增组达到该剂量的累计天数
  （原文示例：34 / 52 / 111 天）
  记录能否汇合；不能汇合则只报细胞数
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 细胞在低剂量就停止增殖 | 起始剂量过高/细胞状态差 | 回到 IC30 以下；复苏新管 |
| 高剂量始终无法汇合 | 递增过快（跨度过大） | 改为 ×1.5 或延长适应时间 |
| IC50 曲线不拟合 | 最高剂量未覆盖 >90% 抑制 | 扩展剂量范围；检查 DMSO 毒性 |
| 各线 IC50 差异不显著 | 传代瓶颈过大/药物失效 | 核对药物批次与储存（−80°C、避光） |
| persister 实验污染 | 长期培养 + 高剂量 | 加抗生素；缩短操作时间 |
| 重复实验差异大 | 血清批次/传代数不同 | 固定血清批次；记录传代数 |
| 形态突然改变 | 支原体/遗传漂移 | 支原体检测；STR；换新管 |
| 恒量对照过度耐药 | 时间因素强于剂量 | 同时报告累计天数，避免把时间效应归因于递增 |
| T320 细胞生长更快 | 适应后代谢重编程 | 记录倍增时间；活力实验归一化到 DMSO |
