## ① 科学问题与逻辑位置

本模块不产生生物学结论，只负责**把可复现性变成可执行的环境**：确认原文数据到底公开了什么、代码是否能跑、哪些中间对象缺失，并建立后续所有模块依赖的目录、参考文件与校验和。

**上游输入**：原文 Data/Code availability、GEO SuperSeries GSE247691、Metabolomics Workbench ST003102、GitHub `yanailab/drug-resistance`。
**下游输出**：`raw/**`（只读）、`logs/00_checksums.md5`、`logs/00_data_manifest.tsv`、可复现的 R/Python/CLI 环境。

**核心判断**：原文的**处理后数据非常完整**（scRNA counts + metadata + ATAC 20 样本计数 + CRISPR counts + WES CNV/SNV），足以支撑 03–08 的**计算复现**；**唯一的数据缺口是 ATAC 的 T320/T320W 加药/撤药 8 个样本**（Fig. 3f），需从 SRA 重跑（D7）。

### 2.3 数据缺口（必须显式记录）

1. **ATAC 计数只公开了 20/28 样本**：`consensus_peaks_kuramochi_all.tsv.gz` 含 chr/start/end + 20 个样本计数（C、T5–T320、P10、P320，各 2 重复），足以复现 Fig. 3c–e；**缺 T320_nodrug/T320_drug/T320W_nodrug/T320W_drug 8 个样本**，Fig. 3f 需从 SRA 重跑（D7）。SOFT 中各样本 `supplementary_file_1 = NONE`，6 个 bigWig 是系列级轨道。
2. **作者代码依赖本地 `.rda`**：`modules/gene_modules.R` 等脚本 `load()` 的 `kura_all_g1_together_seurat.rda`、`genes_to_remove.rda` 未发布（D14）。
3. **Kuramochi 主聚类/状态定义脚本未见**：仓库有 `modules/`、`a375_analysis.R`、`ovsaho_analysis.R`、`cov362_analysis.R`、`pc9_analysis.R`、`pdx_*.R`、`plot_cnvs.R`、`atac/`，但未看到 C–T320 的完整状态定义脚本；需按 Methods 重建。
4. **代谢组**：ST003102 的原始强度矩阵是否可直接批量下载需在 S6 验证；若不可得，用补充表做定性核对（D8）。
5. **WES raw fastq/BAM**：GEO 只给 CNV/SNV 表；若要从 fastq 重跑 Control-FREEC，需 SRA（BioProject **PRJNA1040167**）。

### 4.2 下载全部 GEO 处理数据

```bash
#!/usr/bin/env bash
# code/01_01_download_geo.sh
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
BASE="https://ftp.ncbi.nlm.nih.gov/geo/series"

fetch () {  # $1=GSE  $2=file
  local gse="$1" f="$2"
  local pre="${gse:0:6}nnn"
  local out="$ROOT/raw/geo/$gse"
  mkdir -p "$out"
  if [ ! -s "$out/$f" ]; then
    echo "[GET] $gse/$f"
    curl -fL --retry 3 --retry-delay 5 \
      "$BASE/$pre/$gse/suppl/$f" -o "$out/$f"
  fi
}

# GSE206125 — Kuramochi inDrop scRNA-seq
for f in \
  GSE206125_kuramochi_all_C_to_T320.csv.gz \
  GSE206125_kuramochi_C_to_T320_metadata_g1.tsv.gz \
  GSE206125_inDrop_barcode1_list.txt.gz \
  GSE206125_inDrop_barcode2_list.txt.gz ; do fetch GSE206125 "$f"; done

# GSE247684 — A375 / PC9
for f in \
  GSE247684_a375_all_C_to_T4.csv.gz \
  GSE247684_a375_metadata_g1.tsv.gz \
  GSE247684_pc9_all_C_to_T1.2_P1.2.csv.gz \
  GSE247684_pc9_metadata_g1.tsv.gz ; do fetch GSE247684 "$f"; done

# GSE247685 — ATAC-seq
for f in \
  GSE247685_consensus_peaks_kuramochi_all.tsv.gz \
  GSE247685_BS03661A_BS07471A.bw \
  GSE247685_BS03668A_BS07478A.bw \
  GSE247685_BS19919A_BS19920A.bw \
  GSE247685_BS19921A_BS19922A.bw \
  GSE247685_BS19923A_BS19924A.bw \
  GSE247685_BS19925A_BS19926A.bw ; do fetch GSE247685 "$f"; done

# GSE247686 — CRISPR
```

### 4.3 校验和与清单

```bash
#!/usr/bin/env bash
# code/01_02_checksums.sh
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
cd "$ROOT"
# macOS 用 md5；Linux 用 md5sum
if command -v md5sum >/dev/null 2>&1; then
  find raw -type f -print0 | sort -z | xargs -0 md5sum > logs/00_checksums.md5
else
  find raw -type f -print0 | sort -z | xargs -0 md5 -r > logs/00_checksums.md5
fi
printf 'file\tbytes\n' > logs/00_data_manifest.tsv
find raw/geo raw/metabolomics -type f -exec sh -c 'printf "%s\t%s\n" "$1" "$(wc -c < "$1")"' _ {} \; \
  >> logs/00_data_manifest.tsv
wc -l logs/00_checksums.md5 logs/00_data_manifest.tsv
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
