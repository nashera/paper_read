## ② 背景原理

### 2.1 inferCNV 的直觉

单细胞 RNA-seq 的**平均表达**沿染色体呈现"块状"偏移：某段染色体若发生扩增，该段基因平均表达升高；缺失则降低。inferCNV 把每个细胞在各染色体上的平滑表达与**参考细胞**比较，估计相对拷贝数。

关键参数：

- **参考（reference）**：未处理的 C 细胞；参考必须是"近二倍体/稳定"的群体。
- **cutoff**：基因表达过滤阈值（原文 0.1），去除低表达基因。
- **denoise**：对表达矩阵去噪，减少 dropout 造成的假信号。
- **HMM**：用隐马尔可夫模型把连续信号切成离散的 CNA 状态（原文默认）。
- **cluster_by_groups**：按样本/分组聚类，避免不同样本混在一起。

### 2.2 为什么 CNA 不能完全定义状态

- CNA 是**克隆层面**的遗传事件，状态是**细胞层面**的表达程序；
- 同一克隆可处于不同状态（可塑性）；
- 不同克隆可收敛到同一状态（趋同）；
- inferCNV 是表达推断，受表达程序本身影响（例如模块 A 的基因在 chr 上成簇，会造成假 CNA）。

因此原文的结论是"CNA 与状态相关，但不充分"。

### 2.3 WES 与 Control-FREEC

WES 提供正交验证：BWA-MEM 比对 → GATK 局部重比对/碱基质量校正 → **Control-FREEC**（以未处理 C 为对照）估计拷贝数与 LOH。原文还对 SNV 做 ANNOVAR 注释（gnomAD 3.0、COSMIC 90），用于检查 **BRCA1/2 继发突变**。

### 2.4 重叠显著性检验

把"模块基因"映射到基因组区间（TSS ±1 kb），把 CNA 区段作为另一组区间；计算观测重叠数；用 **regioneR** 在保持区段大小/染色体分布的前提下随机化 10,000 次，得到零分布与经验 P 值（双侧）。原文用 regioneR 1.10.0、10,000 次置换。

## ④ 逐步可运行代码

### 4.1 构建 gene order 文件

```bash
# code/05_00_gene_order.sh
# 从 Ensembl 93 GTF 生成 inferCNV 需要的三列：gene, chr, start, end
zcat raw/reference/Homo_sapiens.GRCh38.93.gtf.gz \
| awk -F'\t' '$3=="gene" {
    match($9, /gene_name "([^"]+)"/, a);
    match($9, /gene_id "([^"]+)"/, b);
    if (a[1] != "") print a[1] "\t" $1 "\t" $4 "\t" $5;
  }' | sort -u > raw/reference/gene_order_hg38_ensembl93.tsv
wc -l raw/reference/gene_order_hg38_ensembl93.tsv
```

> macOS 自带 awk 不支持 `match(..., arr)` 三参数；用 `gawk`（`brew install gawk`）或在 Linux 上运行。

### 4.2 inferCNV 主流程

```r
# code/05_01_infercnv.R
suppressPackageStartupMessages({
  library(Seurat); library(inferCNV); library(dplyr)
})
set.seed(20261018)

srt <- readRDS("processed/03_kura_seurat_g1.rds")
DefaultAssay(srt) <- "RNA"

# 计数矩阵（inferCNV 需要原始 counts；若 GEO 给的是 TPM，先确认并记录）
counts <- GetAssayData(srt, slot = "counts")
if (max(counts) < 50) warning("counts 看起来像已归一化数据；inferCNV 结果需谨慎解释")

ann <- data.frame(
  cell = colnames(srt),
  group = as.character(srt$sample),
  stringsAsFactors = FALSE
)
write.table(ann, "processed/05_infercnv_annotation.tsv",
            sep = "\t", quote = FALSE, row.names = FALSE, col.names = FALSE)

infercnv_obj <- CreateInferCNVObject(
  raw_counts_matrix = counts,
  annotations_file  = "processed/05_infercnv_annotation.tsv",
  delim             = "\t",
  gene_order_file   = "raw/reference/gene_order_hg38_ensembl93.tsv",
  ref_group_names   = c("C")
)

infercnv_obj <- infercnv::run(
  infercnv_obj,
  cutoff = 0.1,
  out_dir = "results/05_infercnv_out",
  cluster_by_groups = TRUE,
  denoise = TRUE,
  HMM = TRUE,
  num_threads = 8,
  write_expr_matrix = TRUE
)
saveRDS(infercnv_obj, "processed/05_infercnv.rds")
```

### 4.3 抽取 CNA 区段

```r
# code/05_02_cna_segments.R
# inferCNV HMM 输出通常在 results/05_infercnv_out/HMM_CNV_predictions*.txt
files <- list.files("results/05_infercnv_out", pattern = "HMM_CNV_predictions",
                    full.names = TRUE)
stopifnot(length(files) > 0)
seg <- lapply(files, read.delim, check.names = FALSE) %>% bind_rows()

# 标准化列名（不同 inferCNV 版本列名略有差异）
seg <- seg %>%
  rename_with(~ case_when(
    grepl("cell_group|cell_group_name", .x) ~ "sample",
    grepl("chr", .x, ignore.case = TRUE) ~ "chr",
    grepl("start", .x, ignore.case = TRUE) ~ "start",
    grepl("end", .x, ignore.case = TRUE) ~ "end",
    grepl("state|CNV", .x, ignore.case = TRUE) ~ "call",
    TRUE ~ .x
  ))

write.csv(seg, "results/05_cna_segments.csv", row.names = FALSE)
```

### 4.6 CNA 区段与模块基因重叠（regioneR）

```r
# code/05_05_cna_overlap.R
suppressPackageStartupMessages({
  library(GenomicRanges); library(regioneR); library(dplyr); library(TxDb.Hsapiens.UCSC.hg38.knownGene)
})
set.seed(20261018)

mod <- read.csv("results/04_gene_modules.csv")
seg <- read.csv("results/05_cna_segments.csv")

# 基因 → TSS（±1 kb）
genes <- unique(mod$gene)
tx <- genes(TxDb.Hsapiens.UCSC.hg38.knownGene)
sym <- AnnotationDbi::mapIds(org.Hs.eg.db::org.Hs.eg.db,
                             keys = names(tx), column = "SYMBOL", keytype = "ENTREZID")
keep <- !is.na(sym) & sym %in% genes
gene_gr <- tx[keep]
gene_gr$symbol <- sym[keep]
gene_gr <- resize(gene_gr, width = 2001, fix = "center")

# CNA 区段 → GRanges（按 gain/loss 分层）
seg_gr <- GRanges(as.character(seg$chr), IRanges(seg$start, seg$end))
for (dir in c("gain", "loss")) {
  cna_gr <- seg_gr[grepl(dir, seg$call, ignore.case = TRUE)]
  if (length(cna_gr) == 0) next
  for (m in unique(mod$module)) {
    target <- gene_gr[gene_gr$symbol %in% mod$gene[mod$module == m]]
    obs <- sum(countOverlaps(target, cna_gr) > 0)

    # 置换：保持区段大小与染色体分布
    perm <- sapply(1:10000, function(i) {
      rnd <- randomizeRegions(cna_gr, genome = "hg38", per.chromosome = TRUE)
      sum(countOverlaps(target, rnd) > 0)
    })
    p <- (sum(perm >= obs) + 1) / (length(perm) + 1)
    cat(sprintf("%s %s: obs=%d, p=%.4f\n", m, dir, obs, p))
  }
}
```

> 注：`randomizeRegions` 需要 BSgenome/基因组注释；若环境不具备，可用 `regioneR::permTest` 的 `randomizeRegions` 等价实现，并在 `logs/DECISIONS.md` 记录替代。

## ⑤ 参数解释与调参空间

| 参数 | 原文 | 本项目 | 改变后果 |
|---|---|---|---|
| inferCNV cutoff | 0.1 | 0.1 | 过高丢失基因，过低引入噪声 |
| 参考群体 | C | C | 参考不纯会削弱信号 |
| denoise | TRUE | TRUE | 关闭会保留 dropout 假信号 |
| HMM | TRUE | TRUE | 关闭则只有连续信号 |
| cluster_by_groups | — | TRUE | 分组聚类避免样本混合 |
| 出图细胞比例 | 30% | 30% | 影响可读性，不影响统计 |
| 置换次数 | 10,000 | 10,000 | 过少 P 值不稳 |
| CNA 方向阈值 | 未报告 | 按 HMM call | 需在方法学注明 |

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| inferCNV 报 gene_order 缺失基因 | 基因名不匹配（Ensembl vs symbol） | 统一为 symbol；检查 `%in%` |
| 热图全是噪声 | 输入已是归一化/TPM | 用 counts；或在方法学声明 |
| 参考群体也有大片 CNA | Kuramochi 本身有 CNA | 参考只用于相对比较；解释时注意 |
| `randomizeRegions` 报错 | 缺 BSgenome/hg38 | 安装 `BSgenome.Hsapiens.UCSC.hg38` |
| WES 表列名不同 | 版本差异 | 运行时打印列名并映射 |
| 找到 BRCA1/2 变异但非致病 | 胚系多态 | 用 COSMIC/gnomAD 过滤；报告分类 |
| 模块基因映射丢失 | symbol 重复/别名 | 用 `mapIds`；记录丢失清单 |
| 内存不足 | 全细胞 inferCNV | 每样本下采样或分染色体 |
| 结果不可重复 | HMM 随机初始化 | 固定种子；记录版本 |
