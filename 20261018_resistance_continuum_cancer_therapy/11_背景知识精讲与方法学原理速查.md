## ② 生物学背景

### 2.1 高级别浆液性卵巢癌（HGSOC）与 BRCA

- HGSOC 是最常见的卵巢癌亚型，特征为 **TP53 突变近普遍**、**同源重组缺陷（HRD）**。
- **BRCA1/BRCA2** 参与同源重组修复（HR）。BRCA2 缺陷细胞无法准确修复 DNA 双链断裂，依赖易错的非同源末端连接（NHEJ）。
- **Kuramochi**：BRCA2 突变 HGSOC 细胞系；**Ovsaho**：BRCA2 纯合缺失；**COV362**：BRCA1 突变。三者都是 PARP 抑制剂敏感模型。

### 2.2 PARP 抑制剂与合成致死

- PARP1/2 负责碱基切除修复（BER）。抑制 PARP 会导致单链断裂累积，复制叉崩溃形成双链断裂。
- 在 HR 缺陷细胞中，双链断裂无法修复 → **合成致死**。
- 奥拉帕利（olaparib）是口服 PARP1/2 抑制剂；他拉唑帕利（talazoparib）效力更强，用于 PDX。
- **PARP 捕获（trapping）**：部分抑制剂把 PARP 固定在 DNA 上，毒性更大；这也是耐药机制之一。

### 2.3 耐药的三层机制

| 层级 | 机制 | 时间尺度 | 本项目对应 |
|---|---|---|---|
| 遗传 | BRCA1/2 回复突变、PARP1 突变、复制叉保护 | 长期 | WES 未见继发 BRCA1/2；CNA 存在 |
| 转录/表观 | persister 重编程、EMT、干性、代谢重编程 | 短期–中期 | S1–S5、模块 A–F、ATAC |
| 微环境 | 药物递送、缺氧、免疫 | 中期 | PDX（有限） |

### 2.4 Persister、耐受与耐药

- **Drug-tolerant persister（DTP）**：少数细胞在致死剂量下进入可逆的存活状态（Sharma et al., Cell 2010）。通常依赖表观重编程、抗氧化、代谢适应。
- **Tolerance vs resistance**：
  - tolerance：IC50 右移，但细胞仍对高剂量敏感；撤药可逆。
  - resistance：可在高剂量下持续增殖；常伴随遗传/稳定表观改变。
- 原文的 adapted lines 属于 tolerance/partial resistance；PDX 三轮后属于 resistance。

### 2.5 EMT 与干性

- **EMT（上皮–间质转化）**：上皮标志物（E-cadherin/CDH1）下降，间质标志物（VIM、FN1、SNAI1/2、TWIST1、ZEB1）上升；细胞获得迁移/侵袭能力。
- **Hybrid EMT state**：上皮与间质标志物共存（模块 B 的 KRT8/KRT18 + FN1）。
- **干性**：CD44^high、CD24^low、ALDH1^high 等；与耐药相关，但**相关不等于因果**。
- 原文的关键区分：EMT 提供**可塑性**，使细胞能进入后续状态；它不是耐药的充分条件。

### 2.6 去分化与谱系因子

- **SOX17**：卵巢癌谱系存活因子，与 PAX8、WT1 构成转录复合物（Lin et al., Oncogene 2022）。
- 谱系因子丢失 → 去分化 → 可塑性升高；恢复 SOX17 → 部分恢复敏感。
- 注意：SOX17 在不同癌种中可能是抑癌或促癌，不能外推。

### 2.7 NRF2、ATF4、AP1 与应激

- **NRF2（NFE2L2）**：抗氧化反应主调控因子；靶基因包括 TXNRD1、NQO1、HMOX1、GPX4、GCLM、G6PD、TKT、PGD。
- **ATF4**：整合应激反应（ISR）效应因子；与 NRF2 协同调节氨基酸代谢、ASNS、CHAC1、SHMT2。
- **AP1（JUN/FOS）**：应激/炎症相关；可作为"先锋因子"增加增强子可及性（推测）。
- 三者共同构成原文所说的"应激调控轴"。

### 2.8 代谢重编程

- **糖酵解**：PFKP、PGK1、ALDOA、ENO1、GAPDH、LDHA。
- **PPP（磷酸戊糖途径）**：G6PD、PGD、TKT；产生 NADPH（抗氧化）与核糖-5-磷酸（核苷酸合成）。
- **核苷酸合成**：IMPDH2、GUK1、DTYMK、TYMS、CAD、CTPS1、DHFR。
- **铁死亡/铁稳态**：GPX4、FTL、FTH1、STEAP3、HMOX1；脂质过氧化。
- **谷氨酰胺分解**：GLS → 谷氨酸 → α-酮戊二酸（TCA）与谷胱甘肽（GSH）。
- **CB-839（telaglenastat）**：GLS 抑制剂；与奥拉帕利联用的假设是同时压制 GSH 与核苷酸前体。

### 2.9 染色质与表观记忆

- ATAC-seq 测开放染色质；开放区域通常含增强子/启动子。
- **染色质记忆**：某些可及性状态在撤药后部分保留，再刺激时快速恢复；机制可能涉及 AP1 先锋活性、H3K4me1/H3K27ac 等。
- 原文的 T320W 实验是**现象学**证据，不是机制证明。

### 2.10 PDX

- 患者肿瘤植入免疫缺陷小鼠；保留组织结构与部分异质性。
- 局限：小鼠基质替代人基质、免疫缺失、传代选择、成本高。
- 原文用 NSG 小鼠、皮下植入、talazoparib 口服灌胃。

## ③ 算法与方法学速查

### 3.1 单细胞平台

| 平台 | 原理 | 特点 |
|---|---|---|
| inDrop | 液滴 + 条形码 | 早期平台；细胞数较少；本文 Kuramochi |
| 10X Chromium | 液滴 + 凝胶珠 | 高通量；3′ 端计数 |
| Cell hashing | 抗体-寡核苷酸标记样本 | 多样本混合，去多重 |
| CellPlex | 化学标签 | 10X 官方多重方案 |

### 3.2 归一化

- **TPM**：$TPM_i = \frac{10^6 \cdot (r_i / L_i)}{\sum_j (r_j / L_j)}$；消除基因长度与测序深度。
- **CP10k + log1p**：Seurat `LogNormalize`；$x' = \ln(1 + 10^4 x / \sum x)$。
- **尺度**：log 化后数据用于聚类/可视化；差异表达仍用 counts（MAST/DESeq2）。

### 3.3 QC 与细胞周期

- 线粒体比例高 = 濒死/破损细胞；核糖体比例高 = 活跃翻译/技术偏差。
- `CellCycleScoring`：用 S/G2M 基因集的平均表达打分，再分配到周期阶段。
- 只保留 G1 可减少周期效应，但会损失细胞数并可能偏倚状态比例。

### 3.4 降维与聚类

- **PCA**：线性降维；保留主要方差。
- **UMAP**：非线性嵌入；保留局部结构；**不能**直接用 UMAP 距离做统计。
- **Louvain/Leiden**：图聚类；resolution 控制粒度。
- **ARI（Adjusted Rand Index）**：比较两次聚类的一致性；>0.7 通常认为稳定。

### 3.5 状态与模块

- **Spearman 相关**：对单调变换稳健；用于亚群平均谱。
- **Average linkage**：层次聚类连接方式；对噪声较稳健。
- **Jaccard 指数**：$J(A,B)=|A\cap B|/|A\cup B|$；用于签名合并。
- **Neftel 模块**：多程序混合模型；不强制互斥。

### 3.6 GSEA

- 预排序 GSEA：基因按统计量排序，计算富集分数（ES）的 running sum。
- **NES**：归一化 ES；正=在排序顶部富集。
- **FDR**：置换零分布估计；GSEA 常用 FDR<0.25（探索性），严格分析用 FDR<0.05。

### 3.7 inferCNV

- 输入：counts 矩阵、注释、gene order。
- 步骤：基因过滤 → 平滑 → 参考比较 → denoise → HMM 分段。
- 输出：每个细胞的相对表达/CNA 状态。
- 局限：受表达程序、基因密度、参考纯度影响。

### 3.8 WES / Control-FREEC

- 比对（BWA-MEM）→ 去重 → 局部重比对 → 碱基质量校正 → 拷贝数/LOH 估计。
- Control-FREEC 使用对照样本（未处理）估计正常拷贝数。
- SNV 注释：ANNOVAR + gnomAD/COSMIC。

### 3.9 ATAC-seq

- Tn5 插入 → 开放区域片段化 → 测序。
- MACS2 call peak；IDR 评估重复一致性；consensus peak 合并。
- DESeq2 差异可及性；HOMER motif 富集。
- **RPGC**：每基因组拷贝归一化，适合跨样本比较。

### 3.10 CRISPR 筛选

- 文库设计：每个基因多条 sgRNA；低 MOI 保证单整合。
- 选择：抗生素 48 h；t0 与 end 取样。
- MAGeCK：`count` 统计 sgRNA；`mle` 估计基因 β score。
- β<0 = 敲除后耗竭（必需）；β>0 = 富集（抑癌/毒性）。
- 假阳性来源：文库覆盖、脱靶、瓶颈、归一化。

### 3.11 药物联用

- **IC50**：4PL 拟合；报告 95% CI。
- **Bliss 独立**：$E_{AB}=E_A+E_B-E_AE_B$；S>0 协同。
- **Loewe 相加**：基于剂量-效应曲线；与 Bliss 可能不一致。
- **HSA**：最高单药效应；常用于高通量。
- 注意：不同模型结论可能不同；需报告模型与假设。

## ④ 公式与定义速查

| 名称 | 公式/定义 |
|---|---|
| IC50（4PL） | $Y=B+\frac{T-B}{1+10^{(\log IC50-X)\cdot H}}$ |

| 术语 | 含义 | 常见误用 |
|---|---|---|
| adapted line | 剂量递增后可在该剂量汇合的群体 | 误称"resistant" |
| persister | 高剂量短期存活、可逆 | 误称"resistant" |
| resistance | 稳定、可在高剂量增殖 | 与 tolerance 混用 |
| tolerance | IC50 右移但仍敏感 | 与 resistance 混用 |
| state（S1–S5） | 跨样本共享的转录状态 | 与 cluster 混用 |
| module（A–F） | 协同表达的基因程序 | 误认为互斥 |
| EMT | 上皮–间质转化 | 误认为耐药充分条件 |
| dedifferentiation | 谱系身份丢失 | 与 EMT 等同 |

| peak | ATAC 开放区域 | 与基因混用 |
| motif | TF 结合序列模式 | 误认为直接结合证据 |
| β score | MAGeCK 基因必需性 | 误认为表达量 |
| Bliss | 药物独立作用模型 | 误认为适用于所有机制 |

## ⑥ 常见误解与纠正

| 误解 | 纠正 |
|---|---|
| "BRCA 突变肿瘤对 PARP 抑制剂一定敏感" | 存在原发性/获得性耐药；HR 恢复、药物外排、复制叉保护等 |
| "persister 就是耐药细胞" | persister 多可逆；resistance 需稳定改变 |
| "EMT 导致耐药" | EMT 与耐药相关；因果方向与充分性需扰动实验 |
| "CNA 决定细胞状态" | CNA 与状态相关，但状态可由表达可塑性独立变化 |
| "ATAC motif 富集 = TF 结合" | motif 只是序列富集；需 ChIP/CUT&RUN 验证 |
| "CRISPR β 越负越必需" | 需结合 P/FDR、文库覆盖、细胞背景 |
| "Bliss 协同 = 临床有效" | 体外协同不等于体内疗效/安全 |
| "单细胞 UMAP 上的距离有统计意义" | UMAP 只用于可视化；统计需用表达/邻域 |
| "训练集 C-index 可作为泛化性能" | 必须外部验证（本项目的 PDX/其他系） |
| "未检出 = 不存在" | 受深度、覆盖、阈值限制；需报告检测限 |
