## ② 背景原理

### 2.1 三层 QC

| 层 | 内容 | 本项目落地 |
|---|---|---|
| 数值层 | 原文报告的关键数值 | §六逐项列出；允许波动默认 ±10%（比例）或 ±30%（跨平台） |
| 判据层 | Go / No-Go | ✅ 通过 → 推进；⚠️ 偏差 → 排查后记录放行；❌ → 第二条独立实现复核 |
| 结题层 | gap 表 | §十逐模块填写 |

### 2.2 为什么"跑不出"不等于"不可复现"

L0 §12：跑不出文献的数不叫失败；**改参数直到跑出才叫失败**。在单细胞/表观领域，"跑不出"常见于：平台差异、参考版本、分选门、聚类随机性、数据缺口。必须先用 ≥2 条独立路径排除实现问题，才能讨论"文献不可复现"。

### 2.3 证据分级

| 级别 | 定义 | 本项目示例 |
|---|---|---|
| **A（直接实验）** | 扰动/分选/给药直接改变表型 | 剂量递增、SOX17/Slug 扰动、CD24/CD44 分选、CB-839 联用 |
| **B（正交一致）** | 两种以上独立方法同向 | scRNA 状态 + ATAC motif + PDX cluster |
| **C（计算推断）** | 单一计算模型 | inferCNV、HOMER motif、MAGeCK β score |
| **D（推测）** | 机制假设，未直接验证 | "染色质记忆"、"AP1–NRF2–ATF4 rheostat"、克隆演化顺序 |

## ⑨ 批判性评述（证据等级与过度解读清单）

### 9.1 原文的强项

1. **纵向设计**：剂量递增 + 多时间点 + 多模型，比单时间点"敏感 vs 耐药"更有说服力。
2. **多组学正交**：scRNA + ATAC + WES + CRISPR + 代谢组 + PDX，证据链完整。
3. **功能扰动**：SOX17/Slug/CD24-CD44/药物联用，把相关性推向因果。
4. **概念清晰**：明确区分 adapted / persister / resistant，避免"耐药"一词的滥用。

### 9.2 过度解读与替代解释

| # | 原文表述 | 问题 | 证据等级 | 替代解释 |
|---|---|---|---|---|
| C1 | "resistance continuum" 可直接外推临床 | 320 μM 远高于临床暴露；2D 培养 | B→C | 临床肿瘤可能存在不同轨迹；需患者纵向数据 |
| C2 | "epigenetically reinforced cell states" | 未做因果表观编辑（CRISPRi/dCas9-p300） | C | 转录网络重编程即可解释，无需"加固" |
| C3 | "EMT enables adaptation" | Slug 过表达只解释部分；未做 EMT 抑制 rescue | B | EMT 可能只是伴随程序；其他程序同样使能 |
| C4 | "cellular memory" | T320W 再暴露可恢复开放性；也可能是选择 | C | 克隆选择 vs 真正记忆未区分 |
| C5 | "CNA–state correspondence" | inferCNV 基于表达；WES 仅 4 样本 | C | 表达程序本身可造成假 CNA |
| C6 | "metabolic dependencies" | 单一文库、单一细胞系、~10 倍增 | B/C | 需正交 CRISPRi/药物验证 |
| C7 | "AP1–NRF2–ATF4 rheostat" | 纯推测 | D | 无直接剂量-响应实验 |
| C8 | PDX "resistance" | n=1 患者、3 代 | B | 个体特异；需更多 PDX |
| C9 | CB-839 synergy | 仅体外；50 nM 暴露未测 | B | 体内药代/毒性未知 |
| C10 | persister 与 adapted 的连续性 | persister 定义操作化（贴壁存活） | B | 可能存在未被捕获的异质性 |

### 9.3 对复现的启示

- 把"趋势一致"与"数值一致"分开报告；
- 对 C 级证据（inferCNV、motif）明确标注推断性质；
- 不把体外 adapted 线称为"耐药模型"；
- 阴性/不显著结果保留（例如某些模块 GSEA 不显著、某些 CNA 重叠不显著）；
