## ① 科学问题与逻辑位置

### 1.1 这一模块要回答什么

**人类 CRC 中发现的髓系亚群，在小鼠肿瘤模型中是否存在对应的细胞？如果存在，能否用小鼠模型研究 anti-CSF1R / anti-CD40 对这些亚群的作用？**

原文的回答：可以。做法：

1. 选两个同系（syngeneic）小鼠肿瘤模型：**MC38**（C57BL/6，结肠癌）与 **Renca**（BALB/c，肾细胞癌）；
2. 用 anti-CSF1R（Renca）或 anti-CD40（MC38）处理，取肿瘤/tdLN，10x scRNA-seq（anti-CD40 还做 TCR）；
3. 分别聚类，识别主要免疫细胞；再把两个模型的**髓系细胞整合**，得到 **15 个髓系簇（mM01–mM15）**；
4. 用 **logistic regression 相似性分析**（Young et al. 2018）把小鼠髓系簇映射到人类 `hM01–hM13`；
5. 发现：`mM15_Macro-Vegfa` ↔ 人 `hM13_TAM-SPP1`；`mM11–mM14` ↔ 人 `hM12_TAM-C1QC`；`mM06/mM07` ↔ 人 `hM04_cDC1`；`mM04/mM05` ↔ 人 `hM03_cDC2`。

## ② 背景原理

### 2.1 为什么选 MC38 与 Renca

| 模型 | 宿主 | 肿瘤类型 | 免疫特征 | 为什么用 |
|---|---|---|---|---|
| **MC38** | C57BL/6 | 结肠腺癌 | 免疫原性较高，对 ICB/CD40 敏感 | 与人类 CRC 同源；anti-CD40 单药有效 |
| **Renca** | BALB/c | 肾细胞癌 | 免疫原性中等，对 CSF1R 阻断敏感 | anti-CSF1R 单药有效；TAM 丰富 |

原文先"筛选"模型：Renca 生长对 anti-CSF1R 敏感，MC38 对 anti-CD40 敏感（Fig. S6A）。这不是随意选模型，而是**用模型对药物的敏感性**来确保后续 scRNA-seq 有可检测的表型。

### 2.2 同系（syngeneic）模型的含义

- 肿瘤细胞系与宿主同遗传背景（MC38 来自 C57BL/6，Renca 来自 BALB/c），因此肿瘤不被宿主排斥，可研究免疫微环境与治疗；
- 但同系模型不能完全代表人类肿瘤的遗传多样性、基质、免疫治疗历史；
- 结论外推需谨慎（14 号批判性评述第 6 条）。

### 2.3 给药与取样

| 模型 | 药物 | 剂量/途径 | 时间 | 取样 |
|---|---|---|---|---|
| MC38 | anti-CD40（FGK45） | 5 mg/kg i.p. | day 2 / day 10 | 肿瘤 + tdLN；3 个肿瘤/tdLN 合并 |
| MC38 | anti-PD1（29F1A.12） | 15 mg/kg i.p. | 联合组 | 同上 |
| MC38 | isotype | rat IgG2a（2A3）/ mouse IgG1 | 对照 | 同上 |
| Renca | anti-CSF1R（M279） | 400 µg/鼠 i.p.，3×/周 ×4 | 末次后 24 h（day 8） | 肿瘤 |
| Renca | isotype | mouse IgG1（MOPC-21） | 对照 | 同上 |

原文还提到：Renca 用 anti-CD40 时因 BALB/c 毒性，改为 100 µg/鼠、day 12/19 给药；MC38 的 anti-CD40 方案是 5 mg/kg。复现时不要把两个模型的剂量混用。

### 2.4 组织消化与分选

- **MC38**：机械解离 + Collagenase D 0.5 mg/mL + DNase I 40 U/mL；gentleMACS `h_tumor_03` → 37°C 15 min → `h_tumor_02`；70 µm 过滤。
- **Renca**：Liberase TL 0.2 mg/mL + DNase I 20 U/mL；`h_tumor_01` → 37°C 15 min → `h_tumor_02`；70 µm 过滤。
- **Renca scRNA-seq**：消化时加 **20 µM Actinomycin D**，下游染色/分选保持 5 µM，抑制解离诱导的转录伪影（Wu et al., Neuron 2017）。
- **分选**：
  - MC38：CD45⁺、Thy1.2⁺TCRβ⁺（T）、CD11c⁺MHCII⁺（DC）；
  - Renca：bulk CD45⁺、CD45⁺CD3⁺（T）、CD45⁺CD3⁻B220⁻Ly6G⁻Ly6C⁻（macrophage/DC enriched）；
  - 混合比例：Study 1 = 75% macrophage/DC + 25% bulk CD45⁺；Study 2 = 65% bulk CD45⁺ + 25% macrophage/DC + 10% T。
  - **Study 1 + Study 2 合并用于聚类；Study 2 单独用于 anti-CSF1R 簇频率定量**（D14）。

### 2.5 10x 化学与测序

- anti-CD40（MC38）：**10x 5′ + V(D)J**（TCR）；
- anti-CSF1R（Renca）：**10x 3′**；
- 目标深度：基因表达 50,000 reads/cell；TCR 5,000 reads/cell；150:8:0:150（R1:i7:i5:R2）；HiSeq4000/NovaSeq。

### 2.6 整合（integration）

原文用 **Seurat v3 标准整合流程**（`FindIntegrationAnchors` + `IntegrateData`），把 MC38 与 Renca 的髓系细胞放在同一空间，得到 15 簇。现代 Seurat 5 对应：

```r
obj <- IntegrateLayers(
  object = obj,
  method = CCAIntegration,
  orig.reduction = "pca",
  new.reduction = "integrated.cca",
  verbose = FALSE
)
obj <- FindNeighbors(obj, reduction = "integrated.cca", dims = 1:30)
obj <- FindClusters(obj, resolution = 1.0)
obj <- RunUMAP(obj, reduction = "integrated.cca", dims = 1:30)
```

**关键**：整合的目的是"让同一细胞类型在不同模型中对齐"，不是"抹掉模型差异"。若整合后所有簇都按模型分开，说明批次过强或整合不足；若所有簇都混在一起，可能过度整合。检查每个簇中 MC38/Renca 的比例（Fig. S6F）。

### 2.7 跨物种相似性（logistic regression）

原文（Methods p.e9–e10）：

1. 训练集：人类 10x 髓系 `hM01–hM13`；测试集：小鼠髓系 `mM01–mM15`（两个模型分别算，再平均）。
2. 对训练集每个簇，下采样到所有簇的最小细胞数；若某簇 <50，则下采样到 50。
3. 对每个簇训练一个二分类 logistic regression（elastic net，`alpha=0.99`，10-fold CV），offset = `log(f/(1−f))`，`f` 是该簇在训练集中的比例。
4. 对测试集每个细胞，每个模型输出 logit（offset=0）；在测试簇内平均 → 相似性矩阵；转概率 `plogis` 可视化。

**直觉**：每个训练簇一个"分类器"，看测试簇的细胞更像哪个训练簇。与 PCA/相关性相比，它对簇大小不平衡更稳健（下采样 + offset）。

### 2.8 人–鼠 ortholog

- 人类基因用 HGNC symbol，小鼠用 MGI symbol；跨物种比较前需一标一 ortholog。
- 用 `biomaRt`（Ensembl）`getLDS` 或 OrthoDB；只保留 one-to-one；记录丢失基因（D20）。
- 不能用大写/小写直接匹配（`C1QC` vs `C1qc` 可以，但 `CD80` vs `Cd80` 可以；有些基因名不同，如 `MS4A1` vs `Ms4a1`，多数可大小写转换，但不保证）。
- 丢失基因可能包括关键 marker；若 `SPP1`/`C1QC` 丢失，跨物种映射会失真。必须在 `results/ortholog_lost.tsv` 中列出。

## ④ 逐步可运行代码

### 4.1 `code/08_01_mouse_qc_annot.R`：小鼠数据 QC 与主要免疫类型

```r
#!/usr/bin/env Rscript
# code/08_01_mouse_qc_annot.R
# 用法: Rscript code/08_01_mouse_qc_annot.R <project_dir>
# 输入: raw/mouse_mc38/{matrix.mtx,features.tsv,barcodes.tsv,metadata.tsv}
#       raw/mouse_renca/{matrix.mtx,features.tsv,barcodes.tsv,metadata.tsv}
# 输出: processed/mouse_annot.rds, results/mouse_qc_summary.tsv

suppressPackageStartupMessages({
  library(Seurat); library(Matrix); library(dplyr); library(tidyr); library(tibble)
})
set.seed(20261018)
args <- commandArgs(trailingOnly = TRUE)
proj <- ifelse(length(args) >= 1, args[1], ".")
dir.create(file.path(proj, "processed"), showWarnings = FALSE, recursive = TRUE)

read_10x <- function(dir, model) {
  mtx <- Read10X(data.dir = dir, gene.column = 2)
  meta_path <- file.path(dir, "metadata.tsv")
  if (file.exists(meta_path)) {
    meta <- read.delim(meta_path, check.names = FALSE)
    stopifnot(nrow(meta) == ncol(mtx))
    rownames(meta) <- colnames(mtx)
    obj <- CreateSeuratObject(counts = mtx, meta.data = meta, project = model)
  } else {
    obj <- CreateSeuratObject(counts = mtx, project = model)
  }
  obj$model <- model
  obj
}

mc38  <- read_10x(file.path(proj, "raw", "mouse_mc38"), "MC38")
renca <- read_10x(file.path(proj, "raw", "mouse_renca"), "Renca")

qc_one <- function(obj) {
  obj[["percent.mt"]] <- PercentageFeatureSet(obj, pattern = "^mt-")
  obj <- subset(obj, subset = nFeature_RNA >= 600 & nFeature_RNA <= 4000 &
                  nCount_RNA >= 1600 & nCount_RNA <= 25000 &
                  percent.mt <= 10)
  obj
}
mc38 <- qc_one(mc38); renca <- qc_one(renca)

# 合并前先各自标准化/找 HVG；用 Seurat 5 的 split layer 方式
obj <- merge(mc38, renca, add.cell.ids = c("MC38", "Renca"))
obj <- JoinLayers(obj)   # Seurat 5：merge 后 RNA assay 是 multi-layer，先合并
# 下游 09–11 需要的 metadata：必须是有效值；缺失时明确报错，不能补 NA 后静默通过
required_meta <- c("mouse_id", "study", "treatment", "tissue")
for (f in required_meta) {
  if (!f %in% colnames(obj@meta.data) || all(is.na(obj@meta.data[[f]]))) {
    stop("mouse metadata 缺少有效列：", f, "；请从 Cell Ranger/实验设计表补齐后再跑")
  }
}
# study 取值规范化：Study 2 / study2 / Study_2 → Study2；只允许 Study1/Study2
obj$study <- gsub("[ _]", "", sub("^study", "Study", obj$study, ignore.case = TRUE))
if (!all(obj$study %in% c("Study1", "Study2"))) {
  stop("study 取值必须是 Study1/Study2；实际：", paste(unique(obj$study), collapse = ", "))
}

# Renca 没有 day2/day10 药效时间点；按原文末次给药后 24 h（day 8）记为 day8
if (!"timepoint" %in% colnames(obj@meta.data) || all(is.na(obj$timepoint))) {
  if (all(obj$model == "Renca")) obj$timepoint <- "day8" else stop("MC38 metadata 缺少 timepoint")
}
obj <- NormalizeData(obj)
obj <- FindVariableFeatures(obj, nfeatures = 2000)
obj <- ScaleData(obj)
obj <- RunPCA(obj, npcs = 30)
obj <- FindNeighbors(obj, dims = 1:30)
obj <- FindClusters(obj, resolution = 0.8)
obj <- RunUMAP(obj, dims = 1:30)

# 主要免疫类型（粗略；髓系在 08_02 重新整合）
markers <- list(
  T       = c("Cd3e","Cd3d","Cd3g","Trac","Trbc1","Trbc2"),
  NK      = c("Nkg7","Klrd1","Klrb1c","Gzma","Gzmb"),
  B       = c("Cd79a","Cd79b","Ms4a1","Cd19"),
  Myeloid = c("Lyz2","Cd68","Csf1r","Itgam","Fcgr3","S100a8","S100a9"),
  DC      = c("Cd11c","Itgax","Mhc2","H2-Ab1","Cd209a","Clec9a"),
  Stromal = c("Col1a1","Col3a1","Dcn","Acta2","Pdgfra"),
  Tumor   = c("Epcam","Krt18","Krt8","Cdh1")
)
score <- sapply(markers, function(g) colMeans(GetAssayData(obj, layer = "data")[intersect(g, rownames(obj)), , drop = FALSE]))
obj$major_type <- colnames(score)[max.col(score, ties.method = "first")]
# CD45 门控：T/NK/B/Myeloid/DC 为 CD45+；其余为 CD45-
obj$cell_type <- ifelse(obj$major_type %in% c("T","NK","B","Myeloid","DC"), "CD45+", "CD45-")

saveRDS(obj, file.path(proj, "processed", "mouse_annot.rds"))  # Seurat（粗分 major_type）

# 全 CD45+ 分母表：09/10 用，避免从髓系子集取分母
cd45_counts <- obj@meta.data %>%
  filter(cell_type == "CD45+") %>%
  count(mouse_id, study, model, treatment, timepoint, tissue, name = "n_cd45")
write.table(cd45_counts, file.path(proj, "results", "mouse_cd45_counts.tsv"),
            sep = "\t", quote = FALSE, row.names = FALSE)
write.table(data.frame(table(obj$model, obj$major_type)),
            file.path(proj, "results", "mouse_qc_summary.tsv"),
            sep = "\t", quote = FALSE, row.names = FALSE)
cat("mouse cells:", ncol(obj), "\n")
```

> **注意**：`Read10X` 期望 `barcodes.tsv.gz`/`features.tsv.gz`/`matrix.mtx.gz`；若下载的是 `.h5`，用 `Read10X_h5()`。`metadata.tsv` 的列名需与原文一致：`treatment`（Isotype/anti-CD40/anti-CSF1R）、`timepoint`（day2/day10/NA）、`tissue`（Tumor/tdLN）、`mouse_id`。若 metadata 不在矩阵目录，用 `left_join` 按 barcode 合并。

### 4.2 `code/08_02_integrate.R`：髓系整合与 15 簇

```r
#!/usr/bin/env Rscript
# code/08_02_integrate.R
# 用法: Rscript code/08_02_integrate.R <project_dir>
# 输入: processed/mouse_annot.rds
# 输出: processed/mouse_myeloid_integrated.rds, results/mouse_myeloid_markers.tsv

suppressPackageStartupMessages({
  library(Seurat); library(dplyr); library(tidyr); library(tibble)
})
set.seed(20261018)
args <- commandArgs(trailingOnly = TRUE)
proj <- ifelse(length(args) >= 1, args[1], ".")
obj <- readRDS(file.path(proj, "processed", "mouse_annot.rds"))

# 取髓系（含 DC、单核、巨噬、中性粒、肥大）
mye <- subset(obj, subset = major_type %in% c("Myeloid", "DC"))
mye <- NormalizeData(mye)
mye <- FindVariableFeatures(mye, nfeatures = 2000)
mye <- ScaleData(mye)
mye <- RunPCA(mye, npcs = 30)

# Seurat 5 整合：按 model 分层
mye[["RNA"]] <- split(mye[["RNA"]], f = mye$model)
mye <- IntegrateLayers(
  object = mye,
  method = CCAIntegration,
  orig.reduction = "pca",
  new.reduction = "integrated.cca",
  verbose = FALSE
)
mye <- FindNeighbors(mye, reduction = "integrated.cca", dims = 1:30)
mye <- FindClusters(mye, resolution = 1.0)
mye <- RunUMAP(mye, reduction = "integrated.cca", dims = 1:30)

# 15 簇的手工注释（以 Fig. S6E 的 marker 为准；先看 FindAllMarkers 再定）
markers <- FindAllMarkers(mye, only.pos = TRUE, min.pct = 0.25,
                          logfc.threshold = 0.5)
write.table(markers, file.path(proj, "results", "mouse_myeloid_markers.tsv"),
            sep = "\t", quote = FALSE, row.names = FALSE)

# 手工映射表：cluster -> mM 标签（示例；S6 按 marker 表核对后固定）
```

### 4.3 `code/08_03_similarity.R`：人–鼠 logistic regression 相似性

```r
#!/usr/bin/env Rscript
# code/08_03_similarity.R
# 用法: Rscript code/08_03_similarity.R <project_dir>
# 输入: processed/human_10x_norm.rds, processed/human_annot.rds,
#       processed/mouse_myeloid_integrated.rds, results/ortholog_map.tsv
# 输出: results/human_mouse_similarity.tsv, figures/Fig3H_similarity_heatmap.pdf/.png

suppressPackageStartupMessages({
  library(Seurat); library(glmnet); library(dplyr); library(tidyr)
  library(tibble); library(pheatmap)
})
set.seed(20261018)
args <- commandArgs(trailingOnly = TRUE)
proj <- ifelse(length(args) >= 1, args[1], ".")

hum <- readRDS(file.path(proj, "processed", "human_10x_norm.rds"))
man <- readRDS(file.path(proj, "processed", "human_annot.rds"))
mouse <- readRDS(file.path(proj, "processed", "mouse_myeloid_integrated.rds"))
orth <- read.delim(file.path(proj, "results", "ortholog_map.tsv"))

# 人类表达：logtpm；小鼠：data（log-normalized）
h_expr <- as.matrix(assay(hum, "logtpm"))
m_expr <- as.matrix(GetAssayData(mouse, layer = "data"))
h_cl <- factor(man$cluster_id)
m_cl <- factor(mouse$cluster_id)

# 只保留髓系簇
h_keep <- grep("^hM", levels(h_cl), value = TRUE)
m_keep <- grep("^mM", levels(m_cl), value = TRUE)
h_expr <- h_expr[, h_cl %in% h_keep, drop = FALSE]
h_cl   <- droplevels(h_cl[h_cl %in% h_keep])
m_expr <- m_expr[, m_cl %in% m_keep, drop = FALSE]
m_cl   <- droplevels(m_cl[m_cl %in% m_keep])

# ortholog：人类 symbol -> 小鼠 symbol；取一标一
orth <- orth[orth$human %in% rownames(h_expr) & orth$mouse %in% rownames(m_expr), ]
orth <- orth[!duplicated(orth$human) & !duplicated(orth$mouse), ]
h_expr <- h_expr[orth$human, , drop = FALSE]
m_expr <- m_expr[orth$mouse, , drop = FALSE]
rownames(m_expr) <- orth$human  # 统一为人类 symbol

# 下采样：每个簇到最小簇大小；<50 的簇按 50
min_size <- max(50, min(table(h_cl)))
set.seed(20261018)
idx <- unlist(lapply(levels(h_cl), function(k) {
  cells <- which(h_cl == k)
  sample(cells, min(length(cells), min_size))
}))
h_expr <- h_expr[, idx, drop = FALSE]
h_cl <- droplevels(h_cl[idx])

# 每个训练簇一个 logistic regression（elastic net, alpha=0.99）
train_one <- function(k) {
  y <- as.integer(h_cl == k)
  f <- mean(y)
  off <- rep(log(f / (1 - f)), length(y))
  # 手动 10-fold CV（glmnet 的 cv.glmnet 对 offset 支持不一致）
  folds <- sample(rep(1:10, length.out = length(y)))
  lambdas <- 10^seq(-3, 1, length.out = 50)
  cv_err <- sapply(lambdas, function(lam) {
    err <- numeric(10)
    for (j in 1:10) {
      tr <- folds != j; te <- folds == j
      fit <- glmnet(t(h_expr[, tr, drop = FALSE]), y[tr], family = "binomial",
                    alpha = 0.99, lambda = lam, offset = off[tr])
      pr <- predict(fit, newx = t(h_expr[, te, drop = FALSE]),
                    offset = off[te], type = "response")
      err[j] <- mean((pr - y[te])^2)
    }
    mean(err)
  })
  best <- lambdas[which.min(cv_err)]
  fit <- glmnet(t(h_expr), y, family = "binomial", alpha = 0.99,
                lambda = best, offset = off)
  list(fit = fit, lambda = best, f = f)
}

models <- lapply(levels(h_cl), train_one)
names(models) <- levels(h_cl)

# 测试：小鼠每个簇的平均 logit（offset=0）
predict_logit <- function(model, expr) {
  as.numeric(predict(model$fit, newx = t(expr), offset = rep(0, ncol(expr)),
                     type = "link"))
}
logit_mat <- sapply(models, function(m) {
  # 每个小鼠细胞一个 logit；按簇平均
  v <- predict_logit(m, m_expr)
  tapply(v, m_cl, mean)
})
# logit_mat: mouse cluster × human cluster
prob_mat <- plogis(logit_mat)
out <- as.data.frame(as.table(logit_mat)) %>%
  rename(mouse_cluster = Var1, human_cluster = Var2, mean_logit = Freq) %>%
  mutate(probability = plogis(mean_logit))

write.table(out, file.path(proj, "results", "human_mouse_similarity.tsv"),
            sep = "\t", quote = FALSE, row.names = FALSE)

# 热图
pdf(file.path(proj, "figures", "Fig3H_similarity_heatmap.pdf"), width = 7, height = 8)
pheatmap(prob_mat, cluster_rows = TRUE, cluster_cols = TRUE,
         color = colorRampPalette(c("white", "orange", "darkred"))(100),
         main = "Human–mouse myeloid similarity (probability)")
dev.off()
png(file.path(proj, "figures", "Fig3H_similarity_heatmap.png"),
    width = 2100, height = 2400, res = 300)
pheatmap(prob_mat, cluster_rows = TRUE, cluster_cols = TRUE,
         color = colorRampPalette(c("white", "orange", "darkred"))(100),
         main = "Human–mouse myeloid similarity (probability)")
dev.off()

cat("similarity matrix:", nrow(prob_mat), "x", ncol(prob_mat), "\n")
```

> **性能提示**：`glmnet` 的 10-fold CV × 50 lambda × 13 簇，在 10k 细胞 × 2k 基因上可能较慢；可先用 `nlambda=20` 和 5-fold 做筛选，再对最终模型用 10-fold。原文用 10-fold；主路径保持 10-fold，时间可接受（约 10–20 min/簇）。

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 整合后所有簇按模型分开 | 批次过强；整合不足 | 增加 anchors/PCs；检查 `split()` 的 layer；用 Harmony 作敏感性 |
| 整合后所有簇混在一起 | 过度整合；细胞类型被抹平 | 降低整合强度；检查 marker；用未整合的 PCA 作对照 |
| 簇数不是 15 | resolution/PCs 不同；QC 阈值不同 | 调整 resolution；以 marker 表为准，不硬追 15 |
| mM 标签映射错 | Seurat cluster 编号随种子变化 | 先 `FindAllMarkers`，按 marker 表手工映射；记录 `DECISIONS.md` |
| 相似性矩阵全是高概率 | 训练集下采样不足；模型过拟合；offset 错 | 检查下采样；检查 `alpha`；检查 offset 公式 |
| 相似性矩阵全是低概率 | 基因尺度不匹配（人类 log TPM vs 小鼠 log-normalized） | 统一为 log2(TPM+1) 或 scaled data；检查 ortholog |
| ortholog 丢失关键基因 | one-to-one 过滤太严 | 检查 `ortholog_lost.tsv`；必要时用多对多并标注 |
| TCR 数据缺失 | 只下载了 GEX，未下载 V(D)J | 从 E-MTAB-8832 下载 TCR；在 11 号使用 |
| 小鼠 metadata 对不上 | barcode 后缀/前缀不同 | 用 `make.unique` 或统一去掉 `-1`；检查 `colnames` |
| anti-CSF1R 与 anti-CD40 混在一张 UMAP | 未按 `model`/`treatment` 分层 | 整合时按 `model` split；可视化时 facet |
