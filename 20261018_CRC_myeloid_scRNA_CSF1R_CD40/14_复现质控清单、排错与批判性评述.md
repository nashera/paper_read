## ① 科学问题与逻辑位置

本文件是项目的**质量门（L2）与决策权威（D 表）**：它不产生新的生物学结论，而是回答三个问题：

1. **我们跑出来的数，和文献报告的数是同一个东西吗？** —— 数值层门槛。
2. **如果不一样，是"我们没复现出来"，还是"文献不可复现"？** —— 判据层与 gap 表。
3. **文献的结论本身能推到哪里？** —— 证据等级与批判性评述。

上游：所有模块的产物（`processed/`、`results/`、`figures/`）。
下游：结题报告、对外发表的方法学声明、后续项目的 D 表复用。

## ② 背景原理：为什么单细胞复现的 QC 不能只看 p 值

单细胞复现的误差有**四层**，每层都可能让"结果看起来对、其实错"：

| 层 | 典型误差 | 检测手段 |
|---|---|---|
| **测量层** | 双细胞、空滴、线粒体、环境 RNA、批次 | QC 前后细胞数、doublet score 分布、mito% 分布、熵 |
| **注释层** | 簇标签错配、恶性/非恶性混淆、跨平台标签不一致 | marker 表达、CNV、logistic regression 相似性、Ro/e |
| **统计层** | 多重比较、单侧检验、伪重复（细胞当 n）、选择偏差 | 逐图核对 n 的定义、p 的形式、FDR 口径 |
| **推断层** | 轨迹方向、相关性网络、LR 预测、生存截断 | 独立实现、负对照、敏感性分析、证据分级 |

因此本文件的 QC 表不是"p<0.05 就过"，而是**每个关键数值都要求方向 + 量级 + 口径三者同时对上**。

## ④ 逐步可运行代码：QC 汇总与 gap 表生成

以下脚本在每个模块跑完后汇总关键指标，生成 `results/qc_summary.tsv` 与 `results/gap_table.tsv`。它是**只读汇总**，不修改任何上游产物。

```r
#!/usr/bin/env Rscript
# code/14_01_qc_summary.R
# 用法: Rscript code/14_01_qc_summary.R <project_dir>
# 输入: results/*.tsv, processed/*.rds, logs/*.log
# 输出: results/qc_summary.tsv, results/gap_table.tsv

suppressPackageStartupMessages({
  library(readr); library(dplyr); library(tidyr); library(tibble)
})

args <- commandArgs(trailingOnly = TRUE)
proj <- ifelse(length(args) >= 1, args[1], ".")
stopifnot(dir.exists(file.path(proj, "results")))

read_tsv_safe <- function(p) {
  if (!file.exists(p)) return(NULL)
  read_tsv(p, show_col_types = FALSE)
}

# ---- 1. 文献报告值（全部可在原文定位；未报告处 NA） ----
ref <- tribble(
  ~metric, ~literature, ~source,
  "n_cells_10x", 43817, "Results, p.444",
  "n_cells_smartseq2", 10468, "Results, p.444",
  "n_cells_mouse_cd40", 119698, "STAR Methods table, p.e8",
  "n_cells_mouse_csf1r", 8578, "STAR Methods table, p.e8",
  "n_clusters_leukocyte_10x", 38, "Results, p.444",
  "n_clusters_leukocyte_smartseq2", 36, "Results, p.444",
  "n_clusters_myeloid_human", 13, "Results, p.444",
  "n_clusters_myeloid_mouse", 15, "Results, p.450",
  "n_clusters_ILC", 4, "Results, p.444",
  "n_clusters_T", 18, "Results, p.444",
  "n_clusters_B", 5, "Results, p.444",
  "n_MSI_H", 3, "STAR Methods, p.e7",
  "hr_activated_DC", 0.53, "Fig. 5J",
  "p_activated_DC", 0.01, "Fig. 5J"
)

# ---- 2. 我方实测值（由各模块写入 results/module_metrics.tsv） ----
obs <- read_tsv_safe(file.path(proj, "results", "module_metrics.tsv"))
if (is.null(obs)) {
  stop("缺少 results/module_metrics.tsv：请先运行 01–13 号模块脚本")
}

qc <- ref %>%
  left_join(obs, by = "metric") %>%
  mutate(
    abs_diff = observed - literature,
    pct_diff = ifelse(literature != 0, 100 * abs_diff / literature, NA_real_),
    tolerance = case_when(
      grepl("^n_cells", metric) ~ 5,
      grepl("^n_clusters", metric) ~ 0,   # 簇数按绝对差判定
      TRUE ~ 10
    ),
    status = case_when(
      is.na(observed) ~ "PENDING",
      grepl("^n_clusters", metric) & abs_diff == 0 ~ "PASS",
      grepl("^n_clusters", metric) & abs(abs_diff) <= 1 ~ "WARN",
      !grepl("^n_clusters", metric) & abs(pct_diff) <= tolerance ~ "PASS",
      !grepl("^n_clusters", metric) & abs(pct_diff) <= 2 * tolerance ~ "WARN",
      TRUE ~ "FAIL"
    )
  )

write_tsv(qc, file.path(proj, "results", "qc_summary.tsv"))

# ---- 3. gap 表模板 ----
gap <- qc %>%
  filter(status != "PASS") %>%
  transmute(
    module = NA_character_,
    metric = metric,
    literature = literature,
    observed = observed,
    consistent = status,
    reason = NA_character_,
    action = NA_character_
  )
write_tsv(gap, file.path(proj, "results", "gap_table.tsv"))

cat("QC 汇总完成：", nrow(qc), "项；PASS", sum(qc$status == "PASS"),
    "WARN", sum(qc$status == "WARN"), "FAIL", sum(qc$status == "FAIL"),
    "PENDING", sum(qc$status == "PENDING"), "\n")
```

```r
#!/usr/bin/env Rscript
# code/14_02_module_metrics.R
# 各模块把实测值追加到 results/module_metrics.tsv（长表：metric, observed, module）
# 用法示例（02 号脚本末尾）：
append_metric <- function(proj, metric, observed, module) {
  f <- file.path(proj, "results", "module_metrics.tsv")
  d <- data.frame(metric = metric, observed = observed, module = module)
  if (file.exists(f)) {
    old <- read.delim(f)
    d <- rbind(old, d)
  }
  write.table(d, f, sep = "\t", quote = FALSE, row.names = FALSE)
}
```

## 十、批判性评述（教授视角）

### 10.1 文章最强的三点

1. **双平台设计**：Smart-seq2 的基因深度 + 10x 的细胞覆盖，使稀有髓系亚群（cDC1、pDC、过渡态单核）同时被"看见"和"看清"。这是 2020 年时点上的最佳实践，也解释了为什么 hM07/hM11 主要由 10x 捕获。
2. **从"图谱"走到"治疗"**：不是停在 cluster 描述，而是用 anti-CSF1R / anti-CD40 两个临床相关策略，把 cluster 与"谁被耗竭、谁被激活"连起来。C1QC⁺/SPP1⁺ 的差异耗竭是全文最有转化价值的观察。
3. **互作分析的"双层"设计**：bulk 相关性网络（细胞共变）+ LR 表达/置换（分子对）互为补充，且用正常黏膜（GTEx）作对照，避免了"所有边都阳性"的假象。

### 10.4 如果要继续做（扩展方向）

1. **空间验证**：用 CRC 空间转录组/CODEX 验证 SPP1⁺ TAM–CAF/内皮、C1QC⁺ TAM–T 细胞的空间邻接；这是把 LR 预测升级为"空间一致"的最直接路径。
2. **谱系追踪**：小鼠 `Csf1r-CreERT2` + 骨髓移植/光转换，验证 FCN1⁺ → TAM 与 NLRP3⁺ → SPP1⁺ 的真实分化。
3. **功能敲除**：anti-CSF1R + anti-SPP1 联合、C1QC⁺ 选择性清除（如 `C1qa-Cre` + DTR）、cDC1 特异性 `Cd40` 敲除，检验治疗机制。
4. **临床队列**：治疗前/后配对活检 + 单细胞 + 空间，验证 anti-CSF1R/anti-CD40 的人类药效标志物；尤其关注 SPP1⁺ TAM 的“残留”是否预测耐药。
5. **方法学**：把相关性网络升级为**去卷积 + 因果图模型**（如 scRNA-informed deconvolution + mediation analysis），并用负对照校准边。
6. **统计**：预注册分析计划、固定截断点、外部验证（如 TCGA 以外队列）、多重比较校正。
