## ① 科学问题与逻辑位置

### 1.1 这一模块要回答什么

**在 06 号得到"哪些细胞类型共变"之后，能否进一步推断"它们通过哪些配体–受体对交流"？**

原文的回答：可以给出**表达层面的预测**。做法：

1. 汇总 FANTOM5 与 CellPhoneDB 的 LR 对；
2. 在 Smart-seq2 中定义"配体/受体在某细胞类型中表达"（>20% 细胞且 log2(TPM+1)>3）；
3. 对每对细胞类型 A（配体）与 B（受体），计算 `Int(A/B) = E_A(L) × E_B(R)`；
4. 随机打乱所有细胞的 cluster label，重复 1,000 次，得到每个 LR 对在每对细胞类型间的零分布；
5. 用正态近似算 p 值，BH 校正；
6. 重点报告 CXCL10–CXCR3、SPP1–ITGAV、SDC2–MMP2、FN1–ITGA5。

### 1.2 输入 / 输出

| 类型 | 内容 | 契约 |

| 输入 | Smart-seq2 `logtpm`（基因 × 细胞） | `processed/human_smartseq2_norm.rds` |

## ② 背景原理

### 2.1 LR 数据库

| 数据库 | 来源 | 内容 | 版本/记录 |
|---|---|---|---|
| **FANTOM5** | Ramilowski et al., Nat Commun 2015 | 人类配体–受体对，基于 FANTOM5 CAGE 表达与文献 | 下载日期写入 `logs/` |
| **CellPhoneDB** | Vento-Tormo et al., Nature 2018 | 配体–受体对，含多亚基受体复合物 | v2.0.0（原文引用 2018 版） |

两个数据库的列名/方向不同，必须先统一为 `ligand`、`receptor` 两列。CellPhoneDB 的 `partner_a`/`partner_b` 需要根据 `receptor_a`/`receptor_b` 的布尔值判断哪一个是配体；FANTOM5 通常是 `ligand`/`receptor`。

### 2.2 表达阈值

原文：某基因在某细胞类型中"表达"，当且仅当

$$
\frac{\#\{i \in c: \log_2(\mathrm{TPM}_{g,i}+1) > 3\}}{|c|} > 0.20
$$

不满足则把该细胞类型的平均表达置 0。注意：

- 阈值是 **log2(TPM+1)>3**，即 TPM > 7；
- 用**表达细胞比例**而不是平均表达，避免少数高表达细胞拉高均值；
- 置 0 后，`Int` 自动为 0，不需要额外过滤。

### 2.3 互作分数

对配体 $L$、受体 $R$、配体细胞类型 $A$、受体细胞类型 $B$：

$$
\mathrm{Int}(A/B)_{L/R} = E_A(L) \times E_B(R)
$$

其中 $E_A(L)$ 是 $L$ 在 $A$ 所有细胞中的平均表达（已按 2.2 置 0）。这是**乘积模型**：配体高且受体高 → 分数高；任一侧不表达 → 0。它不建模亲和力、拷贝数、竞争、可溶性/膜结合。

### 2.4 置换零模型

原文：随机打乱所有细胞的 cluster label，重复 1,000 次，每次重新计算所有 LR 对的所有细胞类型对分数，得到零分布；用正态分布近似算 p。

**关键点**：

- 置换的是**细胞标签**，不是表达矩阵；因此保留了每个基因的表达分布、dropout、细胞大小，只破坏"标签–表达"的关联。
- 零分布不是"无互作"的物理零模型，而是"标签随机"的统计零模型；它控制的是细胞类型组成，不控制空间、蛋白、受体占用。
- 1,000 次的 p 值分辨率是 0.001；用正态近似可以给出更细的 p，但尾部精度仍受 1,000 限制。建议同时报经验 p：`(b+1)/(B+1)`。

### 2.5 多重比较与特异性

- 检验数 = LR 对数 × 细胞类型对（有向）。例如 2,000 × 40 × 40 = 3.2M；BH 后显著的对可能仍很多。
- 原文关注"cell population specificity"：一个 LR 对在特定 A→B 上显著，而在其它 A'→B' 上不显著。复现时应报告：
  - `interaction_score`（观测）；
  - `p_perm`（正态近似单侧）；
  - `p_adj`（BH）；
  - `specificity` = 该对的 z-score 在全部细胞类型对中的排名/最大值比。
- 不要只报"显著对数"，要报"哪些 LR 对在哪些细胞类型对上特异"。

### 2.6 重点 LR 对的生物学

| LR 对 | 配体细胞 | 受体细胞 | 生物学 | 原文证据 |
|---|---|---|---|---|
| **CXCL10–CXCR3** | `hM12_TAM-C1QC` | T 细胞（`CXCR3`） | 招募/激活 Th1、CD8 T；CXCL10 是 IFNγ 诱导的趋化因子 | Fig. 3F、S5E |
| **SPP1–ITGAV** | `hM13_TAM-SPP1` | 表达 `ITGAV` 的细胞（CAF/内皮/肿瘤） | SPP1 促黏附/迁移/血管生成 | Fig. 3F、S5F |
| **SDC2–MMP2** | `hM13_TAM-SPP1`（SDC2） | CAF/内皮（MMP2） | MMP2 降解 ECM，SDC2 参与基质结合 | Fig. 3F、S5F |
| **FN1–ITGA5** | `hM13_TAM-SPP1`（FN1） | 表达 `ITGA5` 的细胞 | 纤连蛋白–整合素促迁移/存活 | Fig. 3F、S5F |

> ⚠️ **导师批注**：`SDC2–MMP2` 的方向要小心：原文说 SPP1⁺ TAM  preferential expression of SDC2，MMP2 由 CAF/内皮高表达；所以是 "SPP1⁺ TAM 的 SDC2 ← CAF/内皮的 MMP2"（受体在 TAM，配体在基质）。复现画弦图时不要把所有箭头都画成 TAM→基质。`Int(A/B)` 的 A 是配体细胞、B 是受体细胞；`SDC2` 是受体，`MMP2` 是配体，方向是 CAF/内皮 → SPP1⁺ TAM。

## ④ 逐步可运行代码

### 4.1 `code/07_01_load_lr_db.R`：统一 LR 表

```r
#!/usr/bin/env Rscript
# code/07_01_load_lr_db.R
# 用法: Rscript code/07_01_load_lr_db.R <project_dir>
# 输入: raw/lr_db/fantom5_lr.tsv, raw/lr_db/cellphonedb_lr.tsv
# 输出: processed/lr_pairs_unified.tsv

suppressPackageStartupMessages({
  library(data.table); library(dplyr); library(tidyr); library(tibble)
})
args <- commandArgs(trailingOnly = TRUE)
proj <- ifelse(length(args) >= 1, args[1], ".")
dir.create(file.path(proj, "processed"), showWarnings = FALSE, recursive = TRUE)

read_fantom <- function(path) {
  d <- fread(path, data.table = FALSE, check.names = FALSE)
  # 兼容常见列名
  cn <- tolower(colnames(d))
  lig <- colnames(d)[cn %in% c("ligand", "ligand_symbol", "ligand_gene")]
  rec <- colnames(d)[cn %in% c("receptor", "receptor_symbol", "receptor_gene")]
  if (length(lig) != 1 || length(rec) != 1) {
    stop("FANTOM5 表需要 ligand/receptor 两列；实际列名: ", paste(colnames(d), collapse = ", "))
  }
  data.frame(ligand = d[[lig]], receptor = d[[rec]], source = "FANTOM5",
             stringsAsFactors = FALSE)
}

read_cellphonedb <- function(path) {
  d <- fread(path, data.table = FALSE, check.names = FALSE)
  cn <- tolower(colnames(d))
  # CellPhoneDB v2 interaction_table.csv:
  # partner_a, partner_b, receptor_a, receptor_b, is_integrin
  need <- c("partner_a", "partner_b", "receptor_a", "receptor_b")
  if (!all(need %in% cn)) {
    stop("CellPhoneDB 表需要 partner_a/partner_b/receptor_a/receptor_b；实际列名: ",
         paste(colnames(d), collapse = ", "))
  }
  a <- d[[which(cn == "partner_a")]]
  b <- d[[which(cn == "partner_b")]]
  as_bool <- function(x) {
    if (is.logical(x)) return(x)
    tolower(trimws(as.character(x))) %in% c("true", "t", "1", "yes")
  }
  ra <- as_bool(d[[which(cn == "receptor_a")]])
  rb <- as_bool(d[[which(cn == "receptor_b")]])
  # 若 receptor_a=TRUE，则 a 是受体、b 是配体；否则 a 是配体、b 是受体
  ligand <- ifelse(ra, b, a)
  receptor <- ifelse(ra, a, b)
  # 若 receptor_b=TRUE 且 receptor_a=FALSE，则 b 是受体、a 是配体（与上面一致）
  data.frame(ligand = ligand, receptor = receptor, source = "CellPhoneDB",
             stringsAsFactors = FALSE)
}

f <- read_fantom(file.path(proj, "raw", "lr_db", "fantom5_lr.tsv"))
c <- read_cellphonedb(file.path(proj, "raw", "lr_db", "cellphonedb_lr.tsv"))

lr <- bind_rows(f, c) %>%
  filter(!is.na(ligand), !is.na(receptor), ligand != "", receptor != "") %>%
  mutate(across(c(ligand, receptor), trimws)) %>%
  distinct(ligand, receptor, .keep_all = TRUE) %>%
  arrange(ligand, receptor)

write.table(lr, file.path(proj, "processed", "lr_pairs_unified.tsv"),
            sep = "\t", quote = FALSE, row.names = FALSE)
cat("unified LR pairs:", nrow(lr), "\n")
cat("FANTOM5:", sum(lr$source == "FANTOM5"),
    "CellPhoneDB:", sum(lr$source == "CellPhoneDB"), "\n")
```

> **注意**：CellPhoneDB 的 `receptor_a`/`receptor_b` 语义在不同版本可能变化；运行前用 `head()` 检查 3–5 行，确保 `ligand`/`receptor` 没有反。若表是 "partner_a/partner_b" 但无 `receptor_a`，改用 `is_integrin`/注释或直接按 `partner_a=ligand` 处理，并在 `logs/` 记录。

### 4.2 `code/07_02_lr_permutation.R`：观测分数 + 1,000 次置换

```r
#!/usr/bin/env Rscript
# code/07_02_lr_permutation.R
# 用法: Rscript code/07_02_lr_permutation.R <project_dir> [n_perm]
# 输入: processed/human_smartseq2_norm.rds, processed/human_smartseq2_annot.rds,
#       processed/lr_pairs_unified.tsv
# 输出: results/lr_pairs_significant.tsv, results/lr_null_summary.tsv

suppressPackageStartupMessages({
  library(SingleCellExperiment); library(SummarizedExperiment)
  library(data.table); library(dplyr); library(tidyr); library(tibble)
  library(parallel); library(matrixStats)
})
set.seed(20261018)
args <- commandArgs(trailingOnly = TRUE)
proj <- ifelse(length(args) >= 1, args[1], ".")
n_perm <- ifelse(length(args) >= 2, as.integer(args[2]), 1000L)
stopifnot(n_perm >= 100)
dir.create(file.path(proj, "results"), showWarnings = FALSE, recursive = TRUE)

sce <- readRDS(file.path(proj, "processed", "human_smartseq2_norm.rds"))
ann <- readRDS(file.path(proj, "processed", "human_smartseq2_annot.rds"))
stopifnot(identical(colnames(sce), colnames(ann)))
cl <- factor(ann$cluster_id)
expr <- as.matrix(assay(sce, "logtpm"))
lr <- read.delim(file.path(proj, "processed", "lr_pairs_unified.tsv"))
lr <- lr[lr$ligand %in% rownames(expr) & lr$receptor %in% rownames(expr), ]
stopifnot(nrow(lr) > 0)

# ---- 1) 只保留配体/受体基因，降低置换成本 ----
genes <- unique(c(lr$ligand, lr$receptor))
expr_sub <- expr[genes, , drop = FALSE]
# 去掉在所有细胞中都不表达的基因
expr_sub <- expr_sub[rowMaxs(expr_sub) > 0, , drop = FALSE]
lr <- lr[lr$ligand %in% rownames(expr_sub) & lr$receptor %in% rownames(expr_sub), ]

# ---- 2) 预计算：每个基因 × 簇的 sum、n、frac(>3) ----
ind <- model.matrix(~ 0 + cl)          # cells × clusters, sparse
colnames(ind) <- levels(cl)
n_cells <- colSums(ind)
sum_expr <- expr_sub %*% ind           # genes × clusters
frac_expr <- (expr_sub > 3) %*% ind / rep(n_cells, each = nrow(expr_sub))
mean_expr <- sum_expr / rep(n_cells, each = nrow(expr_sub))
mean_expr[frac_expr <= 0.20] <- 0      # 不表达置 0

lig_idx <- match(lr$ligand, rownames(mean_expr))
rec_idx <- match(lr$receptor, rownames(mean_expr))
L_obs <- mean_expr[lig_idx, , drop = FALSE]  # pairs × clusters
R_obs <- mean_expr[rec_idx, , drop = FALSE]

# ---- 3) 观测分数：pairs × clusters × clusters ----
score_array <- function(L, R) {
  # 返回 list：每个 pair 的 K×K 矩阵；用向量化 outer
  K <- ncol(L)
  out <- vector("list", nrow(L))
  for (i in seq_len(nrow(L))) out[[i]] <- outer(L[i, ], R[i, ])
  out
}
obs_list <- score_array(L_obs, R_obs)
obs_vec <- unlist(obs_list, use.names = FALSE)
K <- ncol(L_obs)
pair_names <- paste0(lr$ligand, "->", lr$receptor)
cluster_pairs <- expand.grid(ligand_cluster = colnames(L_obs),
                             receptor_cluster = colnames(R_obs),
                             stringsAsFactors = FALSE)
obs_df <- data.frame(
  lr_pair = rep(pair_names, each = K * K),
  ligand = rep(lr$ligand, each = K * K),
  receptor = rep(lr$receptor, each = K * K),
  ligand_cluster = rep(cluster_pairs$ligand_cluster, times = nrow(lr)),
  receptor_cluster = rep(cluster_pairs$receptor_cluster, times = nrow(lr)),
  interaction_score = obs_vec,
  stringsAsFactors = FALSE
)

# ---- 4) 置换：打乱 cl，重新计算 mean_expr，累积 sum/sumsq ----
perm_one <- function(b) {
  cl_perm <- sample(cl)
  ind_p <- model.matrix(~ 0 + cl_perm)
  colnames(ind_p) <- levels(cl)
  n_p <- colSums(ind_p)
  sum_p <- expr_sub %*% ind_p
  frac_p <- (expr_sub > 3) %*% ind_p / rep(n_p, each = nrow(expr_sub))
  mean_p <- sum_p / rep(n_p, each = nrow(expr_sub))
  mean_p[frac_p <= 0.20] <- 0
  L <- mean_p[lig_idx, , drop = FALSE]
  R <- mean_p[rec_idx, , drop = FALSE]
  unlist(score_array(L, R), use.names = FALSE)
}

# 用 mclapply 并行；Windows 下改用 parLapply
n_cores <- max(1L, min(8L, parallel::detectCores() - 1L))
perm_list <- mclapply(seq_len(n_perm), perm_one, mc.cores = n_cores)
perm_mat <- do.call(cbind, perm_list)  # length(obs_vec) × n_perm
null_mean <- rowMeans(perm_mat)
null_sd <- rowSds(perm_mat)
# 经验 p（单侧）：观测 >= 置换值
emp_p <- (rowSums(perm_mat >= obs_vec) + 1) / (n_perm + 1)
# 正态近似 p（单侧）
z <- (obs_vec - null_mean) / pmax(null_sd, 1e-12)
p_norm <- pnorm(z, lower.tail = FALSE)

obs_df$null_mean <- null_mean
obs_df$null_sd <- null_sd
obs_df$z <- z
obs_df$p_perm <- p_norm
obs_df$p_emp <- emp_p
obs_df$p_adj <- p.adjust(p_norm, method = "BH")

# specificity：该细胞类型对的 z 在同一个 LR 对内的相对排名
obs_df <- obs_df %>%
  group_by(lr_pair) %>%
  mutate(specificity = z / max(z, na.rm = TRUE)) %>%
  ungroup()

# 契约列名：celltype_ligand / celltype_receptor
obs_df <- obs_df %>%
  mutate(celltype_ligand = ligand_cluster,
         celltype_receptor = receptor_cluster)
write.table(obs_df, file.path(proj, "results", "lr_pairs_significant.tsv"),
            sep = "\t", quote = FALSE, row.names = FALSE)
write.table(data.frame(lr_pair = pair_names, null_mean = null_mean,
                       null_sd = null_sd, n_perm = n_perm),
            file.path(proj, "results", "lr_null_summary.tsv"),
            sep = "\t", quote = FALSE, row.names = FALSE)

cat("LR pairs:", nrow(lr), "; cluster pairs:", K * K,
    "; tests:", nrow(obs_df), "; n_perm:", n_perm, "\n")
cat("p_adj<0.05:", sum(obs_df$p_adj < 0.05), "\n")
```

> **性能提示**：`perm_mat` 的大小 = tests × n_perm。若 tests 为 3.2M、n_perm=1,000，矩阵为 25.6 GB，内存会爆。因此脚本只保留**配体/受体基因**（约 1,000–2,000 个），并把 LR 对限制在至少一侧表达的 pair；实际 tests 通常在 10^5–10^6。若仍过大，先把 `n_perm=200` 做筛选，再对候选 pair 跑 1,000 次；或按 `lr_pair` 分块。**不要**把整个 15k 基因矩阵放进置换。

### 4.3 `code/07_03_chord.R`：重点 LR 对的弦图

```r
#!/usr/bin/env Rscript
# code/07_03_chord.R
# 用法: Rscript code/07_03_chord.R <project_dir>
# 输入: results/lr_pairs_significant.tsv
# 输出: figures/Fig3F_lr_bubble.pdf/.png,
#       figures/FigS5E_chord_CXCL10_CXCR3.pdf/.png,
#       figures/FigS5F_chord_SPP1_ITGAV.pdf/.png

suppressPackageStartupMessages({
  library(dplyr); library(ggplot2); library(circlize)
})
args <- commandArgs(trailingOnly = TRUE)
proj <- ifelse(length(args) >= 1, args[1], ".")
dir.create(file.path(proj, "figures"), showWarnings = FALSE)

d <- read.delim(file.path(proj, "results", "lr_pairs_significant.tsv"))
```

### 4.4 手算示例（2 个 LR 对 × 3 个簇）

设三个簇 A、B、C 的平均表达（已按 >20% 阈值置 0）：

| 基因 | A | B | C |
|---|---|---|---|
| L1（CXCL10） | 4.0 | 0 | 0 |
| R1（CXCR3） | 3.0 | 2.0 | 0 |
| L2（SPP1） | 0 | 5.0 | 0 |
| R2（ITGAV） | 2.0 | 3.0 | 0 |

对 LR1：`Int(A/B)` = 4.0×2.0 = 8.0；`Int(A/C)` = 4.0×0 = 0；`Int(B/A)` = 0×3.0 = 0。
对 LR2：`Int(B/A)` = 5.0×2.0 = 10.0；`Int(B/B)` = 5.0×3.0 = 15.0（自分泌，通常保留但需标注）。
置换时打乱 A/B/C 标签，L1/R1 的簇均值会变化；若 L1 只在 A 高、R1 在 A/B 高，真实标签下 `A→A`/`A→B` 分数高于随机，因此显著。这个例子说明：**自分泌（A→A）也会被算进去**；报告时要区分自分泌与旁分泌。

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| LR 表列名不匹配 | FANTOM5/CellPhoneDB 版本不同 | `07_01` 打印列名并 `stop()`；手动映射后记录 |
| 配体/受体反了 | CellPhoneDB `receptor_a/b` 解析错 | 用 3 行手算检查；`receptor_a=TRUE` → partner_a 是受体 |
| 所有 p 都显著 | 多重比较未校正；置换零分布 sd 太小；表达阈值太低 | BH；检查 `null_sd` 是否 >0；提高阈值 |
| 所有 p 都不显著 | 置换把表达也打乱了？没有——检查 `cl_perm` 是否真的与表达无关；检查 `mean_expr` 是否被置 0 太多 | 打印每簇表达基因数；检查 `frac_expr` |
| `perm_mat` 内存爆 | tests × n_perm 太大 | 先筛 LR 对；分块；降 n_perm 预筛 |
| 弦图方向反 | `xtabs` 的 row/col 顺序 | `ligand_cluster ~ receptor_cluster`；检查 `mat` 行列名 |
| 自分泌太多 | A→A 未标注 | 加 `autocrine` 列；报告时分开 |
| 结果与 Fig. 3F 不一致 | 数据库版本/表达阈值/细胞标签不同 | 记录 D12；用 Table S4B 的 LR 列表核对 |
