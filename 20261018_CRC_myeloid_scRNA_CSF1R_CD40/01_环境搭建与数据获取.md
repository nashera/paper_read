## ① 科学问题与逻辑位置

### 1.1 本模块要解决什么

本模块不产生生物学结论，只解决一个工程问题：**把原文公开的数据、参考文件与软件环境，以可核验、可重跑、可追溯的方式落到本机**。

上游：无（项目起点）。
下游：`02_人类CRC数据接入与统一预处理.md` 读取本模块产出的 `raw/**`；小鼠模块与 bulk/生存模块（编号见 `PROJECT_SPEC.md` §1.4）分别读取小鼠矩阵与 TCGA/GTEx 表；`14` 号文档用 `logs/00_checksums.md5` 做完整性校验。

### 1.3 为什么"版本钉死"是复现的一部分

单细胞分析对版本极其敏感：

- **Seurat 2/3 → 5**：`FindClusters` 的默认算法、`IntegrateData` 的接口、`RunUMAP` 的 `spread` 语义都变过；
- **Cell Ranger 2.1.0 → 7/8/9**：barcode 白名单、UMI 校正、参考基因组版本都变；
- **GSVA 1.3 → 1.54**：`gsva()` 的默认 `kcdf`、`mx.diff`、并行后端都变；
- **kallisto 0.43 → 0.50**：伪比对算法与 bootstrap 默认值有差异；
- **pagoda2 / URD / STARTRAC**：GitHub 包没有 CRAN 版本约束，必须记录 commit。

因此，`PROJECT_SPEC.md` §6 给出一张"版本钉死表"；本模块负责把这张表变成**可安装的环境文件**（`renv.lock`、`environment.yml`、`requirements.txt`）与**可核验的 sessionInfo**。

## ② 背景原理

### 2.1 GEO / ENA / ArrayExpress / Xena 各自是什么

| 数据库 | 内容 | 对本项目的意义 |
|---|---|---|
| **GEO**（Gene Expression Omnibus） | 基因表达数据仓库；Series（GSE）聚合样本与 supplementary files | 人类 CRC 的 processed matrix 与 metadata |
| **ENA**（European Nucleotide Archive） | 原始测序 reads 仓库；Project（PRJEB…）聚合 runs | 小鼠 FASTQ；若需从上游重跑 |
| **ArrayExpress / BioStudies** | 表达数据仓库；Experiment（E-MTAB-…）聚合 processed files | 小鼠 processed matrix 的另一入口 |
| **UCSC Xena** | 公共组学数据的统一坐标/注释浏览器；提供 TOIL RSEM、phenotype | TCGA/GTEx bulk 表达与临床 |

### 2.2 processed matrix vs raw FASTQ

- **processed matrix**：作者/数据库已做比对、定量、细胞过滤，给出 gene × cell 矩阵（10x 常为 `barcodes.tsv`、`features.tsv`、`matrix.mtx`；Smart-seq2 常为 `.txt/.csv/.rds`）。优点是可直接进入 02 号；缺点是**作者的上游参数不可见**，只能接受其 QC 口径。
- **raw FASTQ**：可完全重跑 Cell Ranger/kallisto，但人类数据不可得（隐私）；小鼠可得但耗时长（119,698 细胞级别的 10x 数据，Cell Ranger 需数十小时与大量磁盘）。
- **本项目的选择（D1）**：主路径用 processed matrix；小鼠 FASTQ 只在下游需要 TCR/velocity 的原始 BAM 时使用（05/11 号）；不把"从 FASTQ 重跑"作为默认路径。

### 2.3 校验和与可复现性

- `md5`/`sha256` 是对文件内容的指纹；下载后立即计算，写入 `logs/00_checksums.md5`。
- 复跑前用 `md5sum -c` 校验；若文件被替换，校验失败，脚本停止。
- **不要**把 checksum 写在 `raw/` 内（`raw/` 只读）；统一写 `logs/`。

### 2.4 环境隔离

- **R**：`renv` 锁定包版本；`renv::restore()` 按 `renv.lock` 重建。
- **Python**：`venv` 或 `conda`；`pip freeze > requirements.txt`。
- **系统层**：Cell Ranger、kallisto、velocyto 需要独立二进制；记录版本与安装路径。
- **容器（可选）**：URD 1.0.1 与旧版 pagoda2 在 R 4.5 上可能装不上；用 `rocker/r-ver:4.2` 或 `bioconductor/bioconductor_docker:RELEASE_3_16` 做兼容容器（D10）。

### 4.2 下载人类 CRC 数据（GEO GSE146771）

GEO 的 supplementary 文件可通过 `https://ftp.ncbi.nlm.nih.gov/geo/series/GSE146nnn/GSE146771/suppl/` 获取。下面脚本先用 NCBI eutils/E-utilities 列出文件，再逐个下载；不硬编码文件名。

```bash
#!/usr/bin/env bash
# code/01_01_fetch_geo.sh
# 用法: bash code/01_01_fetch_geo.sh
set -euo pipefail

PROJ="$(cd "$(dirname "$0")/.." && pwd)"
OUT="$PROJ/raw/human_crc_10x"
OUT2="$PROJ/raw/human_crc_smartseq2"
mkdir -p "$OUT" "$OUT2"

GSE="GSE146771"
BASE="https://ftp.ncbi.nlm.nih.gov/geo/series/GSE146nnn/${GSE}/suppl"

# 1) 列出 supplementary 文件（若目录列表不可用，回退到 GEO series matrix）
curl -fsSL "$BASE/" -o /tmp/gse146771_index.html
grep -oE 'href="[^"]+"' /tmp/gse146771_index.html \
  | sed 's/href="//; s/"//' \
  | grep -vE '^\.\.?/$|^/' > /tmp/gse146771_files.txt || true

if [ ! -s /tmp/gse146771_files.txt ]; then
  echo "[WARN] 目录列表为空，尝试直接下载 series matrix"
  curl -fL "https://ftp.ncbi.nlm.nih.gov/geo/series/GSE146nnn/${GSE}/matrix/${GSE}_series_matrix.txt.gz" \
    -o "$PROJ/raw/${GSE}_series_matrix.txt.gz"
else
  echo "[INFO] 发现文件："
  cat /tmp/gse146771_files.txt
  while read -r f; do
    case "$f" in
      *10x*|*10X*|*droplet*|*Droplet*) dest="$OUT" ;;
      *Smart*|*smart*|*SS2*|*ss2*)       dest="$OUT2" ;;
      *)                                  dest="$PROJ/raw" ;;
    esac
    echo "[GET] $f -> $dest"
    curl -fL "$BASE/$f" -o "$dest/$f"
  done < /tmp/gse146771_files.txt
fi

# 2) 下载 series matrix（临床/样本信息）
curl -fL "https://ftp.ncbi.nlm.nih.gov/geo/series/GSE146nnn/${GSE}/matrix/${GSE}_series_matrix.txt.gz" \
  -o "$PROJ/raw/${GSE}_series_matrix.txt.gz"

echo "[OK] GEO 下载完成；请检查文件大小并在 logs/DECISIONS.md 记录实际文件名"
```

> ⚠️ **导师批注**：GEO supplementary 的目录列表可能返回 HTML 而不是纯文本；上面的解析是"尽力而为"。更稳妥的做法是手动打开 `https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE146771`，把实际文件名填入 `logs/00_download_manifest.tsv`，再让脚本按 manifest 下载。**不要把猜测的文件名写死**。

### 4.4 下载 TCGA / GTEx（UCSC Xena）

Xena 提供 Python API（`xenaPython`）与直链。下面用 `xenaPython` 查询数据集与样本，再导出；具体 dataset ID 以 Xena 当前页面为准。

```python
#!/usr/bin/env python3
# code/01_03_fetch_xena.py
"""下载 TCGA COAD/READ 与 GTEx colon 的表达与临床数据。

依赖: pip install xenaPython
注意: Xena 的 dataset ID 可能随版本变化；运行前先打印可用 datasets 核对。
"""
import os
import sys
import pandas as pd
import xenaPython as xena

PROJ = os.path.abspath(os.path.join(os.path.dirname(__file__), ".."))
OUT_TCGA = os.path.join(PROJ, "raw", "tcga_coadread")
OUT_GTEX = os.path.join(PROJ, "raw", "gtex_colon")
os.makedirs(OUT_TCGA, exist_ok=True)
os.makedirs(OUT_GTEX, exist_ok=True)

HOST = "https://toil.xenahubs.net"
# 这些 dataset ID 需在 https://toil.xenahubs.net 页面核对后再运行
DATASETS = {
    "tcga_tpm": "tcga_RSEM_gene_tpm",
    "tcga_phenotype": "TCGA_phenotype_denseDataOnlyDownload.tsv",
    "gtex_tpm": "gtex_RSEM_gene_tpm",
    "gtex_phenotype": "GTEX_phenotype",
}

def fetch_expression(dataset, out_path, cohort_filter=None):
    samples = xena.dataset_samples(HOST, dataset, None)
    if cohort_filter:
        samples = [s for s in samples if any(k in s for k in cohort_filter)]
    if not samples:
        raise RuntimeError(f"{dataset}: 没有匹配样本；请检查 cohort_filter")
    # 分批取，避免单次请求过大
    frames = []
    for i in range(0, len(samples), 100):
        chunk = samples[i:i + 100]
        data = xena.dataset_gene_probes_values(HOST, dataset, chunk)
        # data 结构随 xenaPython 版本变化：需按当前版本核对
        df = pd.DataFrame(data)
        frames.append(df)
    out = pd.concat(frames, axis=1)
    out.to_csv(out_path, sep="\t")
    print(f"[OK] {dataset}: {out.shape} -> {out_path}")

def fetch_phenotype(dataset, out_path):
    samples = xena.dataset_samples(HOST, dataset, None)
    fields = xena.dataset_field(HOST, dataset)
    data = xena.dataset_data(HOST, dataset, samples, fields)
    df = pd.DataFrame(data, columns=["sample"] + list(fields))
    df.to_csv(out_path, sep="\t", index=False)
    print(f"[OK] {dataset}: {df.shape} -> {out_path}")

if __name__ == "__main__":
    # 先打印可用数据集，人工核对 ID
    print("Xena TCGA/GTEx dataset IDs must be verified on the Xena portal.")
    fetch_expression(DATASETS["tcga_tpm"],
                     os.path.join(OUT_TCGA, "tcga_coadread_rsem_tpm.tsv.gz"),
                     cohort_filter=["-COAD", "-READ"])
    fetch_phenotype(DATASETS["tcga_phenotype"],
                    os.path.join(OUT_TCGA, "tcga_coadread_phenotype.tsv"))
    fetch_expression(DATASETS["gtex_tpm"],
                     os.path.join(OUT_GTEX, "gtex_colon_rsem_tpm.tsv.gz"),
                     cohort_filter=["-colon", "-Colon"])
    fetch_phenotype(DATASETS["gtex_phenotype"],
                    os.path.join(OUT_GTEX, "gtex_colon_phenotype.tsv"))
```

> ⚠️ **导师批注**：`xenaPython` 的 `dataset_gene_probes_values` 返回结构在不同版本中可能是 tuple/dict/DataFrame；上面代码是骨架，**运行前必须按当前 `xenaPython` 文档核对返回结构**。如果 API 不稳定，改用 Xena 网页的"Download"直链（记录 URL 与日期），或 `gdc-client` 下载 TCGA 后自行定量。

### 4.6 校验和

```bash
#!/usr/bin/env bash
# code/01_05_checksums.sh
set -euo pipefail
PROJ="$(cd "$(dirname "$0")/.." && pwd)"
cd "$PROJ"
find raw -type f ! -name "*.md" -print0 \
  | sort -z \
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| `curl` 403/超时 | NCBI/ENA 限流；需要 User-Agent 或重试 | 加 `-A "Mozilla/5.0"`；`--retry 5 --retry-delay 10`；降低并发 |
| GEO 目录列表返回 HTML | FTP over HTTP 页面结构变化 | 手动从 GEO 页面复制文件名到 manifest；脚本按 manifest 下载 |
| 下载到 0 字节文件 | 链接是跳转页/需要登录 | `curl -fL`；检查 HTTP 状态；不要用 `wget -O` 覆盖已有文件 |
| ENA FASTQ 太大 | 119,698 细胞的 10x raw 可达数百 GB | 默认不下载 raw；只下载 processed；若需 velocity，按样本/run 选择性下载 |
| Xena API 返回结构不符 | `xenaPython` 版本变化 | 打印 `type(data)` 与 `data.keys()`；按当前文档调整；或改用网页直链 |
| `renv::restore()` 失败 | Bioconductor 版本与 R 不匹配 | 固定 R 4.5.1 + Bioc 3.22；`options(BiocManager.check_repositories=FALSE)` 仅作排错 |
| Seurat 5 安装失败 | 依赖 `Matrix`/`Rcpp` 版本冲突 | 先装 `Matrix`/`Rcpp`；用 `pak` 或 Posit Public Package Manager 二进制 |
| pagoda2 安装失败 | GitHub 依赖 `slam`/`mgcv`/`RcppArmadillo` | 先装系统依赖；或用 02 号的项目内 BF 实现（D5） |
| URD 安装失败 | 只支持旧 R | 用 `rocker/r-ver:4.2` 容器；或跳过 URD，用 PAGA+scVelo（D10） |
| `md5sum -c` 失败 | 文件被替换/下载不完整 | 重新下载；在 `logs/DECISIONS.md` 记录；不要忽略 |
| 磁盘不足 | 原始矩阵 + 中间对象 >150 GB | 先下载 processed；raw FASTQ 按需；中间对象压缩 `.rds`（`compress=TRUE`） |
