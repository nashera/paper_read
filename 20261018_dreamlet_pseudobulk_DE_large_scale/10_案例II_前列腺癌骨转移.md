## ① 科学问题与逻辑位置

- **上游**：Kfoury 等（Cancer Cell 2021）前列腺癌骨转移 scRNA-seq：9 例患者的 tumor / involved bone marrow / distal bone marrow + 7 例无癌患者的 benign bone marrow。
- **下游**：Fig. 4 全部面板；13 号的方法对照；14 号的 QC 门槛。
- **本模块回答**：**"肿瘤灶（tumor）与受累骨髓（involved marrow）相比，哪些基因/通路发生了改变？这些改变是细胞类型特异的吗？"**

这个案例与 COVID 的关键差别：**同一患者有多个部位样本**（tumor / involved / distal），是典型的**重复测量设计**——正是 LMM 随机效应要处理的结构。

---

## ② 背景原理

### 2.1 生物学背景：前列腺癌骨转移的微环境

| 组成部分 | 细胞类型 | 作用 |
|---|---|---|
| **肿瘤灶（Tumor）** | 上皮/肿瘤细胞 + 浸润免疫细胞 | 代谢活跃、免疫抑制 |
| **受累骨髓（Involved）** | 靠近肿瘤的骨髓 | 被肿瘤"教育"的微环境 |
| **远端骨髓（Distal）** | 远离肿瘤的骨髓 | 相对正常，但可能有全身效应 |
| **良性骨髓（Benign）** | 无癌患者的骨髓 | 对照 |

原文的核心发现：

- **MHC class II 蛋白**在 tumor 中上调（抗原提呈增强，可能是代偿性免疫激活）。
- **蛋白折叠 chaperone**（如 HSP 家族）在 tumor 中上调（内质网应激/蛋白稳态）。
- 这些改变在**多个单核细胞簇**中一致，说明是细胞类型特异的"状态转变"，而非某一群的扩增。

### 2.2 统计设计：三个对比

作者代码定义：

```r
types <- c("Benign", "Distal", "Involved", "Tumor")
pb$Status <- factor(pb$Status, types)

contrasts <- c(
  Tumor_Involved  = "StatusTumor - StatusInvolved",
  Tumor_Distal    = "StatusTumor - StatusDistal",
  Involved_Distal = "StatusInvolved - StatusDistal"
)
```

| 对比 | 回答的问题 | 原文用途 |
|---|---|---|
| `Tumor_Involved` | 肿瘤灶 vs 紧邻骨髓 | 主对比（157 DEG） |
| `Tumor_Distal` | 肿瘤灶 vs 远端骨髓 | 排除"全身效应" |
| `Involved_Distal` | 受累 vs 远端骨髓 | 肿瘤对邻近骨髓的"场效应" |

**DE 模型**：`~ 0 + Status + (1|subject.id)`——无截距，每个 Status 一个系数；`(1|subject.id)` 吸收患者间差异。contrast 在同一患者内比较，等价于**配对分析**。

### 2.3 方差分解的三个来源

```r
form <- ~ (1|subject.id) + (1|Status) + (1|subject.status)
```

| 来源 | 含义 | 原文结论 |
|---|---|---|
| `subject.id` | 患者间差异（遗传、年龄、体质） | **最强**来源 |
| `Status` | 样本部位（tumor/involved/distal/benign） | 525/1899 基因 >10% |
| `subject.status` | 患者是否患癌（cancer vs non-cancer） | 解释"癌 vs 非癌"的全身差异 |

> ⚠️ **导师批注**：`subject.id` 与 `subject.status` 不是同一层：前者是"个体"，后者是"个体所属的组"。二者在统计上**嵌套**（subject 嵌套于 status）。`variancePartition` 会把它们当作两个随机效应，可能分摊方差；解释时要说明这一点，不能把 `subject.status` 的分数直接当作"癌症的全身效应"。

### 2.4 关键基因的读法

- **CCNL1**（cyclin L1）：RNA 加工/转录调控；在疾病状态间方差高（Fig. 4E）。
- **VIM**（vimentin）：间质标志物；在患者间方差高——反映个体差异而非疾病。
- **MHC-II 基因**（`HLA-DRA`, `HLA-DRB1`, `CD74`）：tumor 中上调。
- **Chaperone 基因**（`HSPA1A`, `HSPA1B`, `HSP90AA1`, `DNAJB1`）：tumor 中上调。

### 4.2 pseudobulk + 权重 + 拟合

```r
# code/10_02_dreamlet_kfoury.R
suppressPackageStartupMessages({
  library(dreamlet); library(SingleCellExperiment); library(BiocParallel)
})

sce <- readRDS("processed/sce_kfoury_raw.rds")

pb <- aggregateToPseudoBulk(sce, assay = "counts",
                            cluster_id = "cells", sample_id = "ID",
                            BPPARAM = SnowParam(8))
pb$Status <- factor(pb$Status, c("Benign","Distal","Involved","Tumor"))
saveRDS(list(pb = pb, cellCounts = cellCounts(pb)), "processed/pb_kfoury.rds")

# 第一级 Poisson 权重
w0 <- lapply(assayNames(pb), function(k) {
  y <- as.matrix(assay(pb, k)); w <- y + 0.5; w / rowMeans(w)
})
names(w0) <- assayNames(pb)

form_w <- ~ (1|subject.id) + (1|Status) + (1|subject.status)
proc <- processAssays(pb, form_w, min.cells = 10, min.count = 10,
                      weightsList = w0, BPPARAM = SnowParam(8))
saveRDS(proc, "processed/proc_kfoury.rds")

contrasts <- c(
  Tumor_Involved  = "StatusTumor - StatusInvolved",
  Tumor_Distal    = "StatusTumor - StatusDistal",
  Involved_Distal = "StatusInvolved - StatusDistal"
)
fit <- dreamlet(proc, ~ 0 + Status + (1|subject.id),
                contrasts = contrasts, BPPARAM = SnowParam(8))
saveRDS(fit, "processed/fit_kfoury.rds")
writeLines(coefNames(fit), "logs/10_coefnames_kfoury.txt")

vp <- fitVarPart(proc, form_w, BPPARAM = SnowParam(8))
saveRDS(vp, "processed/vp_kfoury.rds")
```

### 4.3 结果提取与关键数字

```r
# code/10_03_results_kfoury.R
suppressPackageStartupMessages({ library(dreamlet); library(dplyr) })

fit <- readRDS("processed/fit_kfoury.rds")
coefs <- c("Tumor_Involved","Tumor_Distal","Involved_Distal")

tt <- bind_rows(lapply(coefs, function(cf) {
  bind_rows(lapply(assayNames(fit), function(k) {
    x <- as.data.frame(topTable(fit[[k]], coef = cf, number = Inf, sort.by = "none"))
    if (nrow(x) == 0) return(NULL)
    x$ID <- rownames(x); x$assay <- k; x$coef <- cf; x$SE <- x$logFC / x$t
    x
  }))
}))
# ★ study-wide BH 必须**按 coef 分组**（D6），不能把多个 coef 混在一起校正
tt <- tt |> dplyr::group_by(coef) |>
  dplyr::mutate(adj.P.Val.studywide = p.adjust(P.Value, method = "BH")) |>
  dplyr::ungroup()
write.table(tt, "results/topTable_kfoury_all.tsv", sep = "\t", quote = FALSE, row.names = FALSE)

# 单核细胞簇的关键数字（原文未给簇名，需按作者的 cells 标签对应）
mono <- tt[grepl("mono", tt$assay, ignore.case = TRUE), ]
cat("monocyte assays:", unique(mono$assay), "\n")
print(mono |> filter(coef == "Tumor_Involved") |>
        summarize(n_genes = n(), nDE = sum(adj.P.Val.studywide < 0.05)))
```

> 原文说"a monocyte cluster"有 1899 个表达基因、157 个 DEG；本项目的细胞类型标签来自 Kfoury 原始注释（`cells`），需要在 `table(sce$cells)` 里确认对应簇名。**不要**强行改名匹配。

                  coefs = c("Tumor_Involved","Tumor_Distal","Involved_Distal"),

# 敏感性分析：Hallmark（D9 的第二套）
hall <- msigdbr(species = "Homo sapiens", collection = "H")
hall.lst <- split(hall$gene_symbol, hall$gs_name)
hall.gsc <- GeneSetCollection(mapply(function(g, nm) {
  GeneSet(unique(g), setName = nm, geneIdType = SymbolIdentifier())
}, hall.lst, names(hall.lst), SIMPLIFY = FALSE))

## ⑤ 参数解释与调参空间

| 参数 | 本项目取值 | 可选 | 改变后果 |
|---|---|---|---|
| `Status` 水平顺序 | Benign/Distal/Involved/Tumor | 其他顺序 | `~0+Status` 下不影响系数含义，但影响输出顺序 |
| `min.cells` / `min.count` | 10 / 10 | 5/5 | 保留的细胞类型与基因数 |
| DE 公式 | `~0 + Status + (1|subject.id)` | 加 `(1|subject.status)` | 后者会与 Status 共线（患者嵌套于 status），慎用 |
| contrasts | 三个 | 只跑 Tumor_Involved | 影响结论广度 |
| VP 公式 | 三个随机效应 | 去掉 subject.status | 方差分数重新分配 |
| 基因集 | Hallmark | GO | 影响通路结论 |

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| `Status` 只有 3 个水平 | 良性样本被 QC 删除 | 检查 `min.cells` 与 `table(pb$Status)` |
| contrast 报 "coefficient not found" | 用了 `~ Status` 而不是 `~0+Status` | 无截距模型才能写 `StatusTumor - StatusInvolved` |
| 所有对比结果相同 | contrast 字符串写错 | `makeContrastsDream()` 检查 |
| `subject.id` 方差分数极低 | 患者 ID 列名错（用了 `ID`） | `ID` 是样本，`subject.id` 是患者 |
| 结果与原文差很多 | 细胞类型标签不同 | `table(sce$cells)`；按原文的 cluster 名 |
| 良性组被完全吸收 | `subject.status` 与 `Status` 共线 | 去掉 `subject.status` 做敏感性分析 |
