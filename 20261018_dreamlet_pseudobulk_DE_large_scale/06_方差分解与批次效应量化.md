## ① 科学问题与逻辑位置

- **上游**：`dreamletProcessedData`（与 05 号共享同一个 `E` + `weights`）。

- **本模块回答**：**"一个基因的表达变异，有多少来自疾病、多少来自受试者、多少来自建库批次、多少是残差？"**

它和 DE 是互补的两个问题：

| 问题 | 方法 | 输出 |
|---|---|---|
| 疾病是否**改变**某基因的均值？ | `dreamlet()` + `topTable()` | logFC、p、FDR |
| 表达变异**主要来自哪里**？ | `fitVarPart()` | 每个来源的方差比例（0–1） |

> ⚠️ **导师批注**：方差分数高 ≠ 该变量有显著效应。一个变量可以解释 40% 的方差却不显著（样本少、方差大），也可以 p 很小却只解释 2%（样本多、效应稳定）。**两者必须同时报告**，不能互相替代。

## ② 背景原理

### 2.1 方差分解的定义

对基因 $g$，模型

$$
y_{g,s}=\sum_{j}\mathbf x_{s,j}^\top\boldsymbol\beta_{g,j}
+\sum_{k}\mathbf z_{s,k}^\top\mathbf b_{g,k}+\varepsilon_{g,s},
\qquad
\mathbf b_{g,k}\sim\mathcal N(\mathbf 0,\sigma^2_{g,k}\mathbf I),
\quad
\varepsilon_{g,s}\sim\mathcal N(0,\sigma^2_{g,e}/w_{g,s}).
$$

`variancePartition::calcVarPart()` 先构造**全部成分**，再统一归一化：

| 成分 | 取值 $c_q$ |
|---|---|
| 随机效应 $k$ | $\sigma^2_{g,k}$（`VarCorr`） |
| 固定效应 $j$ | $\operatorname{Var}(\mathbf X_j\hat{\boldsymbol\beta}_{g,j})$（该 term 拟合值的样本方差） |
| 残差 | $\sigma^2_{g,e}$ |

$$
\boxed{\;\text{VP}_{g,q}=\frac{c_q}{\sum_{q'}c_{q'}}\;}
$$

因此**行内和恒为 1**（`calcVarPart` 的 fractions 输出）。强共线时不是">1"，而是分数不可解释、或触发 `colinearityScore > 0.99` 的告警；只有手工用不同分母分别求和才会出现 >1。

> ⚠️ **导师批注**：把随机效应分数写成 $\sigma^2_k/(\sum_k\sigma^2_k+\sigma^2_e)$（漏掉固定效应）会让所有随机分数**偏大**——这是早期文档的错误，已按 `calcVarPart` 的分母统一修正。

### 2.2 为什么用随机效应做方差分解

- 固定效应用 $B-1$ 个哑变量，每个都有自己的方差，无法汇总成"批次总体解释了多少"。
- 随机效应只估一个 $\sigma^2_{\text{batch}}$，直接给出"批次方差占总方差的比例"。
- 对连续变量（年龄），`variancePartition` 允许 `(1|Age)`：把年龄当作一个"随机截距"，其方差分数近似"年龄解释的比例"。更严格的做法是把年龄当固定效应并计算拟合值方差；作者代码在 AD 的 VP 里用了 `scale(Age)` 固定效应，在 COVID 的 VP 里用了 `Age` 固定效应 + `(1|sex)` + `(1|Source)` 随机效应。

### 2.3 公式的选择：VP 公式 ≠ DE 公式

| 队列 | VP 公式（作者代码） | 说明 |
|---|---|---|
| COVID | `~ Age + (1|sex) + (1|Source)` | 疾病状态 `Source` 作随机效应，估"六种状态解释的方差"；Age 固定；sex 随机 |
| Kfoury | `~ (1|subject.id) + (1|Status) + (1|subject.status)` | 受试者、样本状态、患者状态三个随机效应 |
| AD | `~ (1|SubID) + (1|poolID) + (1|Sex) + scale(Age) + (1|Dx)` | 受试者、pool、性别、年龄、诊断 |

> 注意 AD 的 VP 把 `Dx` 当随机效应（`(1|Dx)`），而 DE 把它当固定效应（`Dx`）。这再次体现"方差分解问的是来源，DE 问的是效应"。

### 2.4 方差分数的读法

- **Subject 高**（AD microglia 中位 38.4%）：技术重复一致性好，个体差异是主要来源 → 跨受试者设计是必要的。
- **pool 高**（932 个基因 >5%，NXPE1 达 97.3%）：建库批次效应强 → 必须建模，否则 FPR 膨胀。
- **Dx 低**（仅 101 个基因 >5%）：疾病效应温和 → 需要大样本才能检出（原文的论点）。
- **Residuals 高**：测量噪声或未建模的生物学变异。

### 2.5 GC 含量与批次效应

原文 Fig. 5F：把每个基因的 `poolID` 方差分数与基因的 GC 含量做 Spearman 相关，发现许多细胞类型显著相关（原文只说 "significant correlations"，未声明正负；方向由数据给出）。生物学解释：**PCR 扩增偏好**——高 GC 或低 GC 的片段扩增效率不同，而每个 pool 的 PCR 条件/酶批次不同，导致 GC 依赖的批次效应（引文 35、36：Risso 2011 GC-content normalization；Aird 2011 PCR bias）。

计算口径（作者 `compute_GC_content.R`）：

1. 从 GRCh38.104 GTF 取**全部 exon**；
2. 按 `gene_id` 合并（`GenomicRanges::reduce(split(...))`），得到每个基因的外显子并集；
3. 用 `Rsamtools::FaFile` 读参考基因组，`letterFrequency(..., "GC")` 数 GC；
4. `GC = nGC / 总外显子长度`（0–1）。

> ⚠️ **导师批注**：必须用**外显子并集**而不是"所有转录本拼接"，否则同一基因的不同 isoform 会被重复计数。作者的 `reduce()` 正是去重。

## ④ 逐步可运行代码

### 4.1 方差分解

```r
# code/06_01_variance_partition.R
# 用法：Rscript code/06_01_variance_partition.R psychad
suppressPackageStartupMessages({
  library(dreamlet); library(BiocParallel); library(dplyr); library(tidyr)
})

args <- commandArgs(trailingOnly = TRUE)
dataset <- if (length(args) >= 1) args[1] else "psychad"
proc <- readRDS(sprintf("processed/proc_%s.rds", dataset))

form <- switch(
  dataset,
  psychad = ~ (1|SubID) + (1|poolID) + (1|Sex) + scale(Age) + (1|Dx),
  kfoury  = ~ (1|subject.id) + (1|Status) + (1|subject.status),
  covid   = ~ Age + (1|sex) + (1|Source)
)

vp <- fitVarPart(proc, form, BPPARAM = SnowParam(16, progressbar = TRUE))
saveRDS(vp, sprintf("processed/vp_%s.rds", dataset))

# 宽表：每行一个 gene × assay，每列一个方差来源
write.table(as.data.frame(vp), sprintf("results/vp_%s.tsv", dataset),
            sep = "\t", quote = FALSE, row.names = FALSE)

# 长表：便于 ggplot
vp_long <- as.data.frame(vp) |>
  pivot_longer(cols = -c(gene, assay), names_to = "source", values_to = "fraction")
write.table(vp_long, sprintf("results/vp_%s_long.tsv", dataset),
            sep = "\t", quote = FALSE, row.names = FALSE)

# 关键汇总（对照原文数字）
summ <- vp_long |>
  group_by(assay, source) |>
  summarize(median = median(fraction, na.rm = TRUE),
            n_gt_5pct  = sum(fraction > 0.05, na.rm = TRUE),
            n_gt_10pct = sum(fraction > 0.10, na.rm = TRUE),
            n_gt_25pct = sum(fraction > 0.25, na.rm = TRUE),
            .groups = "drop")
write.csv(summ, sprintf("results/06_vp_summary_%s.csv", dataset), row.names = FALSE)
print(summ |> filter(assay == "Micro_PVM"), n = 20)
```

### 4.4 GC 含量与 pool 方差分数

```r
# code/06_04_gc_content.R
# 输入：raw/benchmark/gc/Homo_sapiens.GRCh38.104.gtf + 参考 FASTA
# 输出：processed/benchmark/gc/GRCh38.104_gc_content.tsv.gz
suppressPackageStartupMessages({
  library(GenomicRanges); library(rtracklayer); library(Rsamtools)
})

dir.create("processed/benchmark/gc", recursive = TRUE, showWarnings = FALSE)
GTFfile   <- "raw/benchmark/gc/Homo_sapiens.GRCh38.104.gtf"
FASTAfile <- "raw/benchmark/gc/Homo_sapiens.GRCh38.dna.primary_assembly.fa"

GTF <- import.gff(GTFfile, format = "gtf", genome = "GRCh38.104", feature.type = "exon")
grl <- GenomicRanges::reduce(split(GTF, elementMetadata(GTF)$gene_id))
reducedGTF <- unlist(grl, use.names = TRUE)
elementMetadata(reducedGTF)$gene_id <- rep(names(grl), elementNROWS(grl))

FASTA <- FaFile(FASTAfile); open(FASTA)
elementMetadata(reducedGTF)$nGCs   <- letterFrequency(getSeq(FASTA, reducedGTF), "GC")[, 1]
elementMetadata(reducedGTF)$widths <- width(reducedGTF)

calc_GC_length <- function(x) {
  c(sum(elementMetadata(x)$widths), sum(elementMetadata(x)$nGCs) / sum(elementMetadata(x)$widths))
}
df_GC <- as.data.frame(t(sapply(split(reducedGTF, elementMetadata(reducedGTF)$gene_id), calc_GC_length)))
colnames(df_GC) <- c("Length", "GC")
df_GC$ENSEMBL <- rownames(df_GC)

i <- match(df_GC$ENSEMBL, GTF$gene_id)
df_GC$SYMBOL <- GTF$gene_name[i]
rownames(df_GC) <- NULL

write.table(df_GC, "processed/benchmark/gc/GRCh38.104_gc_content.tsv",
            quote = FALSE, sep = "\t", row.names = FALSE)
```

```r
# code/06_05_gc_vs_pool.R
suppressPackageStartupMessages({ library(dplyr); library(ggplot2) })

gc <- read.delim("processed/benchmark/gc/GRCh38.104_gc_content.tsv")
vp <- as.data.frame(readRDS("processed/vp_psychad.rds"))
vp$gene_symbol <- vp$gene   # 若 vp 用 Ensembl，改用 gc 的 ENSEMBL 匹配
df <- inner_join(vp, gc[, c("ENSEMBL","SYMBOL","GC")],
                 by = c("gene" = "ENSEMBL")) |>
  filter(!is.na(poolID))

res <- df |>
  group_by(assay) |>
  summarize(n = dplyr::n(),
            rho = cor(GC, poolID, method = "spearman"),
            p   = cor.test(GC, poolID, method = "spearman")$p.value,
            .groups = "drop") |>
  mutate(FDR = p.adjust(p, method = "BH"))

write.csv(res, "results/vp_gc_psychad.tsv", row.names = FALSE)
print(res |> arrange(p), n = 25)

p <- ggplot(res, aes(x = reorder(assay, rho), y = rho, fill = FDR < 0.05)) +
  geom_col() + coord_flip() + theme_classic() +
  labs(x = NULL, y = "Spearman rho (GC vs pool variance)", fill = "FDR<5%")
ggsave("figures/Fig5F_gc_pool_correlation.png", p, width = 6, height = 6, dpi = 300)
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 方差分数之和远大于 1 | 协变量强共线（如 SubID 与 poolID） | 报告共线性；或去掉一个变量做敏感性分析 |
| 所有分数都很小 | 分母包含了未建模的大方差 | 检查是否漏了关键随机效应（batch/donor） |
| `fitVarPart` 报 "NA in formula variables" | 协变量有缺失 | 先 `drop_na` 或插补（记录） |
| 与作者数字差很多 | 公式不同（如把 Dx 当固定效应） | 对照作者代码 §2.3 |
| GC 相关符号与原文相反 | 用了 SYMBOL 匹配但 vp 是 Ensembl | 统一 ID；打印 `length(intersect())` |
| `plotVarPart` 列名带 `scale.Age.` | R 的 `make.names()` | 出图前重命名（作者代码同款） |
| 连续变量当随机效应报错 | `(1|Age)` 中 Age 是连续值 | variancePartition 支持，但需确认版本；否则改固定效应 |
