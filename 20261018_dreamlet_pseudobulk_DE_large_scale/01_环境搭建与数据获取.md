## ① 科学问题与逻辑位置

本模块不产生科学结论，它决定**后面所有数字的可比性**：

- **上游**：公共数据门户（Synapse / GEO / ArrayExpress / MSigDB）。
- **下游**：`02` 号把 h5ad 读成 `SingleCellExperiment` 并聚合；`03` 号做归一化与权重；`05`–`13` 全部依赖这里钉死的版本与文件。
- **核心风险**：**版本漂移**。同一个 GEO 号在不同年份可能被作者更新；同一个 h5ad 的 `X` 可能是原始计数、也可能是归一化后的矩阵；同一个基因集文件在不同 MSigDB 版本里基因数不同。任何一个错了，后面所有图都"看起来能跑但尺度不对"（L0 附录 C「尺度错配 / 版本漂移」）。

## ② 背景原理

### 2.1 为什么是 Bioconductor 而不是 Python

原文的全部统计都建立在三个 R 生态组件之上：

| 组件 | 作用 | 为什么不能用 Python 平替 |
|---|---|---|
| `SingleCellExperiment` (SCE) | 单细胞数据的标准容器：`assay`（表达矩阵）、`colData`（细胞元数据）、`rowData`（基因元数据）、`reducedDims` | `AnnData` 可以存同样的信息，但 `dreamlet` 的 API 只接受 SCE；`zellkonverter` 负责 h5ad↔SCE 的无损桥接 |
| `limma` | 线性模型、`eBayes` 经验贝叶斯、`topTable`、`camera` | 没有等价的 Python 实现能逐位复现 moderated t |
| `lme4` / `variancePartition::dream` | 线性混合模型（LMM）与 REML | `statsmodels` 的 MixedLM 可拟合类似的模型，但权重、自由度近似、EB 收缩的实现不同，数值不可比 |

因此本项目的**主语言是 R**；Python 只用于 h5ad 的检查、转换与少量作图辅助。

### 2.2 依赖拓扑（安装顺序）

```text
R 4.6.x
└── BiocManager 3.23
    ├── SingleCellExperiment ── SummarizedExperiment ── S4Vectors
    ├── zellkonverter ── basilisk（首次 readH5AD 时自动建 conda 环境）
    ├── edgeR ── limma
    ├── lme4 ── Matrix
    ├── variancePartition ── dream() / voomWithDreamWeights() / augmentPriorCount()
    ├── dreamlet ── aggregateToPseudoBulk() / processAssays() / dreamlet() / fitVarPart()
    ├── zenith ── camera 的 LMM 适配
    └── GSEABase / GO.db / org.Hs.eg.db / msigdbr ── 基因集
```

> ⚠️ **导师批注**：`zellkonverter` 通过 `basilisk` 调用 Python 的 `anndata`。首次 `readH5AD()` 会**自动创建 conda 环境**（可能下载数百 MB），在无网/受限网络的集群上会失败。生产环境建议预先跑一次 `zellkonverter::readH5AD()` 把环境缓存好，或在 `01` 号里显式配置 `BASILISK_USE_SYSTEM_DIR`。

### 2.3 H5AD 的三种"陷阱"

1. **`X` 不一定是原始计数**。很多门户把归一化矩阵放 `X`、原始计数放 `raw/X` 或 `layers["counts"]`。作者在 COVID 脚本里专门写了一段：`adata.X = adata.raw.X; adata.write("covid_counts.h5ad")`——说明原始文件确实是"`X` 为归一化值、`raw` 为计数"的结构。
2. **基因 ID 可能是 Ensembl 而不是 SYMBOL**。Kfoury 与 PsychAD 都是 Ensembl；COVID 用 `rowData(sce)$feature_name` 取 SYMBOL。
3. **`obs` 列名各队列不同**：`major_subset`（COVID）、`cells`（Kfoury）、`subclass`（AD）——这是 `aggregateToPseudoBulk(cluster_id=)` 的实参，写错会得到空 assay 或错误分组。

### 4.4 h5ad 体检（先看再读，避免"尺度错配"）

```python
# code/01_02_inspect_h5ad.py
# 用法：python code/01_02_inspect_h5ad.py raw/psychad_ad/xxx.h5ad
import sys, anndata as ad, numpy as np

path = sys.argv[1]
a = ad.read_h5ad(path, backed="r")
print("shape:", a.shape)
print("obs columns:", list(a.obs.columns))
print("var columns:", list(a.var.columns))
print("layers:", list(a.layers.keys()))
print("raw:", None if a.raw is None else a.raw.shape)

# 抽样检查 X 是否为非负整数（原始计数的判据）
idx = np.random.default_rng(20261018).choice(a.n_obs, size=min(500, a.n_obs), replace=False)
x = a[idx, :200].X
x = x.toarray() if hasattr(x, "toarray") else np.asarray(x)
print("X min/max:", float(x.min()), float(x.max()))
print("X 全为非负整数:", bool(np.all(x >= 0) and np.allclose(x, np.round(x))))
```

**判据**：`X min/max` 中 max 若是 5–20 的小数，说明 `X` 是归一化值（log 或 scaled），必须改读 `raw/X` 或 `layers["counts"]`（D1）。

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| `readH5AD()` 卡住/报 basilisk 错 | 首次运行要建 conda 环境，无网或权限不足 | 预跑一次；或设 `BASILISK_USE_SYSTEM_DIR` 指向可写目录；或改用 `SeuratDisk` 转 h5seurat |
