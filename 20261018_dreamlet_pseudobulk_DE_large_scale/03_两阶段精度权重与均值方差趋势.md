## ① 科学问题与逻辑位置

- **上游**：pseudobulk 计数矩阵 $Y_{s,k,g}$ 与每样本细胞数 $n_{s,k}$。
- **下游**：
  - `processed/proc_<dataset>.rds`：log2 CPM（`E`）+ 精度权重（`weights`）→ 05/06/07 全部复用；
  - `results/03_weights_diag_*.csv`：权重诊断。
- **本模块回答**：**"同一个基因在不同样本里的测量精度不同，这个差异从哪里来、怎么估、估得准不准？"**

原文的答案是两级：

1. **第一级（机制驱动）**：Poisson 计数模型 → 精度 ∝ 观测计数 → 权重 $w^{(0)}_{g,s} \propto Y_{g,s}+\text{prior}$。
2. **第二级（数据驱动）**：用 $w^{(0)}$ 拟合 LMM，得到每个基因的残差标准差 $\hat\sigma_g$，对 $\sqrt{\hat\sigma_g}$ vs 平均 log2 CPM 做低ess 平滑，得到 $\hat s(\cdot)\approx\mathbb E[\sqrt{\sigma}\mid\cdot]$，最终权重 $w_{g,s} = 1/\hat s(\text{fitted log-count}_{g,s})^4$。

两级的分工：第一级把"细胞数/reads 数"这个**已知的**精度差异先扣掉；第二级再用数据估计"基因特异的过离散"这一**未知的**放大因子。

## ② 背景原理

### 2.1 为什么 log2 CPM 的方差与计数成反比（δ 法）

设某基因在某样本的 pseudobulk 计数 $Y\sim\text{Poisson}(\mu)$，文库大小 $L$，则

$$
y=\log_2\!\left(\frac{Y+a}{L+1}\times 10^6\right).
$$

对 $Y$ 在 $\mu$ 处一阶展开：

$$
\frac{dy}{dY}=\frac{1}{(Y+a)\ln 2}
\;\Longrightarrow\;
\operatorname{Var}(y)\approx \frac{\operatorname{Var}(Y)}{(\mu+a)^2(\ln 2)^2}
=\frac{\mu}{(\mu+a)^2(\ln 2)^2}.
$$

当 $\mu\gg a$ 时，$\operatorname{Var}(y)\approx 1/(\mu(\ln2)^2)$，**精度**（方差倒数）$\approx \mu(\ln2)^2\propto\mu$。这就是"观测计数越多、测量越准"的数学形式，也是 $w^{(0)}\propto Y+\text{prior}$ 的依据——它是 $\mu\gg a$ 时的近似；严格精度是 $(\mu+a)^2/\mu$。

### 2.2 细胞抽样带来的额外方差（原文 theory_sims 的核心）

pseudobulk 不是"一个 Poisson 变量"，而是 $n$ 个细胞计数的和。设第 $i$ 个细胞的文库大小为 $L_i$、表达比例 $p_i$（跨细胞随机，均值 $\mu$、方差 $\sigma^2$），计数 $x_i\sim\text{Poisson}(p_iL_i)$，则

$$
X=\sum_{i=1}^{n}x_i,\qquad
\mathbb{E}[X]=n\mu\bar L,\qquad
\operatorname{Var}(X)=\underbrace{n\mu\bar L}_{\text{Poisson 噪声}}+\underbrace{n\sigma^2\zeta}_{\text{细胞间异质性}},\quad \zeta=\mathbb{E}[L^2].
$$

> **前提**：上式假设各细胞文库大小 $L_i$ 相同（或 $\operatorname{Var}(L)$ 相对于 $\sigma^2\zeta/\mu$ 可忽略）。若 $L_i$ 随机且与 $p_i$ 独立，精确式为
> $$
> \operatorname{Var}(X)=n\mu\bar L+n\bigl(\sigma^2\mathbb E[L^2]+\mu^2\operatorname{Var}(L)\bigr),
> $$
> VIF 相应多出一项 $\mu\operatorname{Var}(L)/(\sigma^2\zeta)$ 量级的贡献；作者的 `theory_sims.Rmd` 用固定文库（1k/5k/15k）模拟，故正文形式适用。

于是

$$
\boxed{\;
\operatorname{Var}(\log\text{CPM})\approx
\frac{1}{n\mu\bar L}\left(1+\frac{\sigma^2\zeta}{\mu\bar L}\right)
=\frac{1}{\mathbb{E}[X]}\left(1+\frac{\sigma^2\zeta}{\mathbb{E}[X]/n}\right)
\;}
$$

- 第一项 $1/\mathbb{E}[X]$：Poisson 计数噪声 → **第一级权重**。
- 括号内的**方差膨胀因子** $\text{VIF}=1+\sigma^2\zeta/(\mu\bar L)$：细胞间表达异质性造成的过离散 → **第二级经验趋势**要估的就是它。

作者公开仓库 `dreamlet_analysis/delta_method/theory_sims.Rmd`（**未随正文提供**）用 $\mu=0.001$、$\sigma^2=2\times10^{-7}$、文库 1k/5k/15k、细胞数 2–1000 做了蒙特卡洛验证：红线和绿线（用真参数 vs 用观测计数）都与黑点吻合，且 VIF 随 $\sigma^2$ 与文库大小上升。该模拟在正文中没有对应图，引用时只写代码仓库，不写“原文补充图”。

> ⚠️ **导师批注**：这一步是理解"为什么两级"的关键。只用 voom 的单级趋势，会把"细胞数差异"与"基因过离散"混在一个均值–方差曲线里；当各样本细胞数差异很大（AD 队列从几十到几千细胞）时，单级趋势无法同时拟合这两类异方差。**两级 = 先扣机制、再估残差。**

### 2.3 TMM 归一化与自适应先验计数

`processOneAssay()` 内部：

```r
y <- DGEList(y, remove.zeros = TRUE)
y <- calcNormFactors(y, method = "TMM")     # 有效文库大小
...
voomWithDreamWeights(y[keep, ], formula, data, weights = precWeights, ...)
```

`voomWithDreamWeights()` 再做：

```r
countsAug <- augmentPriorCount(counts, lib.size, prior.count = 0.5, scaledByLib = FALSE)
y <- t(log2(t(countsAug) / (lib.size + 1) * 1e6))
```

- **TMM**（trimmed mean of M-values）：以某样本为参考，用"大多数基因不差异表达"的假设估计缩放因子，使不同样本的 CPM 可比。它只影响文库大小，不改变计数。
- **自适应先验计数**（`augmentPriorCount`）：加的先验计数**按文库大小缩放**，使"零计数"样本的 log CPM 不会因为文库大小不同而产生虚假差异。原文 `theory_sims` 的注释明确说："Dreamlet implements an adaptive prior count approach"。默认 `prior.count = 0.5`（`voomWithDreamWeights` 的形参），`computeLogCPM()` 的默认则是 2（**两条路径不同，复现时必须确认走的是哪一条**）。

### 2.4 第二级：均值–方差趋势与 $1/\hat s^4$

`voomWithDreamWeights()` 的核心（源码逐行）：

```r
# 1) 用当前权重拟合 LMM，取残差标准差
fit$sigma <- sigma(fit)                      # 每基因一个
fit$Amean <- mean(fit@frame[,1])             # 平均 log2 表达

# 2) x = 平均 log2 CPM；y = sqrt(残差标准差)
sx <- fit$Amean + mean(log2(lib.size + 1)) - log2(1e6)
sy <- sqrt(fit$sigma)

# 3) 低ess 平滑（span = "auto" 时用 fANCOVA::loess.as 自动选窗宽）
l <- fANCOVA::loess.as(sx, sy)   # 或 stats::lowess(sx, sy, f = span)
f <- approxfun(l, rule = 2)

# 4) 把趋势应用到每个观测的拟合值上
fitted.cpm     <- 2^fitted.values
fitted.count   <- 1e-6 * t(t(fitted.cpm) * (lib.size + 1))
fitted.logcount<- log2(fitted.count)
w <- 1 / f(fitted.logcount)^4
```

**为什么是 4 次方？** 因为趋势的纵轴不是标准差本身，而是它的**平方根**：

- 源码里 `fit$sigma` 是残差标准差 $\hat\sigma_g$；
- `sy <- sqrt(fit$sigma)`，即纵轴 $y=\sqrt{\hat\sigma_g}$；
- 低ess 拟合得到 $\hat s(x)\approx\mathbb E[\sqrt{\sigma}\mid \text{平均表达}=x]$；
- 因此该观测的**预测标准差**是 $\hat s^2$，精度 $w=1/\text{Var}=1/(\hat s^2)^2=1/\hat s^4$。

所以 **4 次方是"双重开方"的代数结果，不是经验约定**。把趋势的纵轴误认为标准差，才会觉得 4 次方"太陡"。

> ⚠️ **导师批注**：复现者最容易在这里"好心改错"。只要记住"趋势拟合的是 √SD，权重是 1/SD²"，就不会把 `w <- 1/f(...)^4` 改成平方。改错会让低表达基因被过度信任，DE 结果系统性偏移，且与原文/limma 不可比。

### 2.5 第一级权重在 dreamlet 里怎么传

`processAssays()` 的形参是 **`weightsList`**（一个 list，每个细胞类型一个矩阵）：

```r
processAssays(pb, form, weightsList = list(celltypeA = w0_A, celltypeB = w0_B, ...))
```

内部：

```r
weights <- weightsList[[k]][, rownames(data), drop = FALSE]
processOneAssay(..., weights = weights)
# processOneAssay 内：
precWeights <- weights[rownames(y)[keep], colnames(y)]
voomWithDreamWeights(y[keep, ], formula, data, weights = precWeights, ...)
```

- `weightsList` 的矩阵必须**行 = 基因、列 = 样本**，且行列名与 pseudobulk 完全一致。
- `weightsList = NULL`（默认）时权重全为 1 → 退化为"只用第二级"，**这不是原文的主路径**。
- 底层 `voomWithDreamWeights()` 还有一个 `priorWeightsAsCounts = TRUE` 开关：当 `weights` 为 NULL（或全为 1）时，用 `countsAug + prior.count` 作初始权重（同一 δ 法思想，但数值与手工 `Y+0.5` **不等价**：它用的是加入先验计数后的值，且随后按行均值归一化）。只能作为敏感性分析的备选，见 D7。

## ④ 逐步可运行代码

### 4.1 构造第一级 Poisson 权重

```r
# code/03_00_poisson_weights.R
# 输入：processed/pb_<dataset>.rds
# 输出：processed/weights_poisson_<dataset>.rds（list，每个细胞类型一个 genes × samples 矩阵）
suppressPackageStartupMessages({ library(SingleCellExperiment); library(Matrix) })

make_poisson_weights <- function(pb, prior = 0.5) {
  out <- lapply(assayNames(pb), function(k) {
    y <- as.matrix(assay(pb, k))          # genes × samples，原始计数
    w <- y + prior                        # δ 法：精度 ∝ 期望计数
    # 行内缩放到均值 1（voom 内部还会再缩放一次；此处只为数值稳定）
    w <- w / rowMeans(w)
    w[!is.finite(w)] <- 1
    dimnames(w) <- dimnames(y)
    w
  })
  names(out) <- assayNames(pb)
  out
}

args <- commandArgs(trailingOnly = TRUE)
dataset <- if (length(args) >= 1) args[1] else "psychad"
pb <- readRDS(sprintf("processed/pb_%s.rds", dataset))$pb
w0 <- make_poisson_weights(pb)
saveRDS(w0, sprintf("processed/weights_poisson_%s.rds", dataset))
```

> 数值检查：`summary(w0[[k]][, 1])` 的分布应严重右偏（少数高表达基因权重很大）；若全为 1，说明 `assay(pb,k)` 读的是归一化矩阵。

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| `weightsList` 报 "Assays not found" | list 名字与 `assayNames(pb)` 不一致 | `names(w0) <- assayNames(pb)` |
| 权重矩阵维度不匹配 | `weightsList[[k]][, rownames(data)]` 取列失败 | 确保列名 = 样本 ID，且 `pb` 的 `colData` 行名一致 |
| 趋势图几乎水平 | 基因太少/表达范围太窄；或 `span` 太大 | 检查 `min.count`；`span=0.3` 试跑 |
| 趋势图在右端上翘 | 高表达基因的残差被模型吸收（饱和） | 常见于 LMM 过拟合；检查随机效应是否过多 |
| 权重全为 1 | `weightsList=NULL` 或 `res.proc` 来自旧对象 | 重跑 4.2 |
| `loess.as` 报错 | `fANCOVA` 未安装 | `install.packages("fANCOVA")` |
| log CPM 出现 -Inf | 先验计数为 0 或文库大小为 0 | 确保 `prior.count>0`；检查空样本 |
| TMM 报 "no genes left" | 过滤后基因太少 | 降低 `min.count` 或检查输入 |
