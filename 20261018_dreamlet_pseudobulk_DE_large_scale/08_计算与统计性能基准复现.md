## ① 科学问题与逻辑位置

- **上游**：AD 数据（用于构造 8 类 × 35k 基因的 H5AD）、模拟参数、置换标签。
- **下游**：`results/benchmark_*.csv` → `figures/Fig2A–E.*`、`FigS1–S3.*`；14 号用它们判断"复现是否成立"。
- **本模块回答三个问题**：
  1. **计算**：pseudobulk 聚合与 DE 拟合，dreamlet 比现有方法快多少、省多少内存？（Fig. 2A–C）
  2. **统计（模拟）**：在已知真值下，AUPR/F1/效应量估计谁最好？（Fig. 2D）
  3. **统计（真实数据）**：在**真实的相关结构**下置换标签，谁的 FPR 受控？（Fig. 2E）

> ⚠️ **导师批注**：这三类基准回答的是不同问题，不能互相替代。模拟数据可以给出"真值"，但模拟本身可能不真实（原文引文 29 专门批评这一点）；真实数据置换最接近"零假设下的实际行为"，但没有真值、只能看 FPR。**两者必须同时报告**。

## ② 背景原理

### 2.1 计算基准的设计

| 方法 | 实现 | 数据形态 | 备注 |
|---|---|---|---|
| **dreamlet** | `aggregateToPseudoBulk()`（beachmat/DelayedArray） | on-disk H5AD | 分块、按 (cluster, sample) 求和 |
| **Matrix.utils** | `aggregate.Matrix()` | in-memory sparse | 需要先把数据读进内存 |
| **muscat** | `aggregateData()` → `scuttle::summarizeAssayByGroup()` | in-memory | 常用基线 |
| **pegasus** | `pegasus.pseudobulk()`（Python） | in-memory/磁盘 | 原文说 <500 donors 时略快，但内存增长快 |
| **naive** | 手写：逐 donor × 逐 cell type 读 H5AD，求和 | on-disk | 8000 次低效读取（1000 donors × 8 类） |

**测量口径**（原文）：

- 每个条件跑 **10 次**，取**平均** CPU 时间与**峰值内存**。
- 机器 **512 GB** 内存；**只用一个线程**（`SerialParam()`）。
- 受试者**有放回抽样**（sampling with replacement）构造 25→1000 donors 的规模序列。
- 数据：8 个细胞类型、35k 基因、最多 4.1 M 细胞。

> ⚠️ **导师批注**：R 的峰值内存受 GC 时机影响，波动很大。原文也承认这一点（"peak memory usage of native R code can vary dramatically"）。复现时**至少 5 次取中位数**，并报告范围；不要用单次结果下结论。

### 2.2 统计基准（模拟）的设计

原文跟随 Cromwell 等（muscat, Nat Commun 2020）的流程：

1. 从**真实数据**估计每个细胞类型的基因均值、离散度、文库大小分布。
2. 按估计的参数**模拟** counts；在部分基因中注入真实 logFC（如 0.5、1）。
3. 对每个模拟数据集跑 9 种 DE 方法。
4. 用真值计算：
   - **AUPR**（area under precision-recall curve）：把基因按 p 值排序，逐阈值算 precision/recall，积分。
   - **F1**：在 FDR<5% 处的调和平均。
   - **效应量误差**：`|logFC_hat − logFC_true|` 的中位数/RMSE。

原文对模拟的扩展：**每样本细胞数不再固定**，而是从 **Dirichlet-multinomial** 分布抽样，以更接近真实数据。

$$
(n_{s,1},\dots,n_{s,K}) \sim \text{DirichletMultinomial}(N_s, \boldsymbol\alpha),
$$
其中 $N_s$ 是该样本的总细胞数，$\boldsymbol\alpha$ 是各细胞类型的相对丰度。这样保留了"细胞类型组成"的样本间变异。

### 2.3 统计基准（真实数据置换）的设计

- 用 AD 的 snRNA-seq（**12 细胞类型**，与原文 Fig. 2E 一致；注意不是 Fig. 5–6 的 22 类），**随机置换每个受试者的 Dx 标签**。
- **约束**：在每个 sample pool 内保持 AD/Control 的比例（原文："retaining the same fraction of Alzheimer's disease cases and controls within each sample batch"）。
- 对每个方法、每个样本量（如 25/50/75/100/150 受试者）重复置换多次，计算**所有表达基因中 p<0.05 的比例**（即 empirical FPR）。
- 两栏：batch 作**固定效应** vs 作**随机效应**。

**为什么这个设计有说服力**：置换后疾病与表达**无关**，任何"显著"都是假阳性；而真实数据保留了基因间相关、批次结构、细胞类型组成——这正是模拟数据最难复现的部分。

### 2.4 方法清单与它们的"能力边界"

| 方法 | 层级 | 能建模随机效应？ | 能扩展到大数据？ |
|---|---|---|---|
| dreamlet | pseudobulk + LMM | ✅ | ✅ |
| limma-voom（muscat） | pseudobulk + 线性模型 | ❌（只能固定效应） | ✅ |
| edgeR | pseudobulk + NB | ❌ | ✅ |
| DESeq2 | pseudobulk + NB | ❌ | ✅ |
| glmer（NB GLMM） | 单细胞 + GLMM | ✅ | ❌（慢、不收敛） |
| MAST | 单细胞 + GLMM | ✅ | ❌ |
| 其他（如 Wilcoxon、NB 单细胞） | 单细胞 | ❌/部分 | 部分 |

> 原文的核心论点：**只有 dreamlet 同时满足"能建模随机效应"与"能扩展到大数据"**。这不是说其他方法不好，而是说它们在这个特定问题上不可用。

### 4.1 构造基准 H5AD（8 类 × 35k 基因，25–1000 donors）

**构造方式**：直接从 AD 的 h5ad 出发，在 **Python/anndata 的 backed 模式**下逐 donor 抽样、拼接、写回 H5AD。完整脚本见 §4.2 的 `code/08_00_make_bench_h5ad.py`（选择 8 个细胞类型、35k 高表达基因、受试者有放回抽样到 25–1000 个 donor）。这样构造出的文件与作者基准的输入同构，且整个过程不把 1.4 M 细胞一次性读入内存。

> ⚠️ 作者的 4.1 M 细胞是"1000 donors × 8 类"抽样后的总量；本项目的构造脚本按同样的抽样逻辑生成，实际细胞数会因供体细胞数分布而略有不同，需在 `results/benchmark_pseudobulk_meta.csv` 记录。

### 4.2 pseudobulk 基准：五种方法

```python
# code/08_00_make_bench_h5ad.py
# 目的：按"受试者有放回抽样"构造 25–1000 donors 的 H5AD（8 类 × 35k 基因）
# 用法：python code/08_00_make_bench_h5ad.py --src raw/psychad_ad/xxx.h5ad --out raw/benchmark/bench_8ct_35k.h5ad --donors 1000
import argparse, numpy as np, anndata as ad, scipy.sparse as sp

p = argparse.ArgumentParser()
p.add_argument("--src", required=True)
p.add_argument("--out", required=True)
p.add_argument("--donors", type=int, default=1000)
p.add_argument("--seed", type=int, default=20261018)
a = p.parse_args()
rng = np.random.default_rng(a.seed)

src = ad.read_h5ad(a.src, backed="r")
ct8 = ["Micro_PVM","Astro","Oligo","OPC","EN_L2_3_IT","IN_PVALB","Endo","VLMC"]
mask = src.obs["subclass"].isin(ct8).to_numpy()
sub = src[mask].to_memory()                    # 8 类细胞
# 取表达量最高的 35k 基因
gene_tot = np.asarray(sub.X.sum(axis=0)).ravel()
keep_g = np.sort(np.argsort(-gene_tot)[:35000])
sub = sub[:, keep_g]

subs = sub.obs["SubID"].astype(str).unique()
picked = rng.choice(subs, size=a.donors, replace=True)
blocks = []
for i, sid in enumerate(picked):
    idx = np.where(sub.obs["SubID"].astype(str).to_numpy() == sid)[0]
    blocks.append(sub[idx].copy())
new = ad.concat(blocks, axis=0, merge="same")
new.obs["SubID"] = np.repeat([f"D{i:04d}" for i in range(a.donors)],
                             [b.n_obs for b in blocks])
new.write_h5ad(a.out, compression="gzip")
print("written", a.out, new.shape)
```

```r
# code/08_01_bench_pseudobulk.R
# 用法：Rscript code/08_01_bench_pseudobulk.R --method dreamlet --donors 200 --rep 1
suppressPackageStartupMessages({
  library(SingleCellExperiment); library(dreamlet); library(muscat)
  library(Matrix.utils); library(BiocParallel); library(zellkonverter)
})

args <- commandArgs(trailingOnly = TRUE)
get_arg <- function(name, default = NULL) {
  i <- match(paste0("--", name), args)
  if (is.na(i)) default else args[i + 1]
}
method  <- get_arg("method", "dreamlet")
donors  <- as.integer(get_arg("donors", "200"))
rep_id  <- as.integer(get_arg("rep", "1"))
h5      <- get_arg("h5", "raw/benchmark/bench_8ct_35k.h5ad")

# on-disk 读取（DelayedArray），保证与原文的内存口径一致
sce <- readH5AD(h5, use_hdf5 = TRUE)
assayNames(sce)[1] <- "counts"
# 只取前 donors 个 donor（构造脚本已按 donors 生成文件时此步为空操作）
keep <- sce$SubID %in% unique(sce$SubID)[seq_len(min(donors, length(unique(sce$SubID))))]
sce <- sce[, keep]

t0 <- Sys.time()
pb <- switch(
  method,
  dreamlet = aggregateToPseudoBulk(sce, assay = "counts",
                                   cluster_id = "subclass", sample_id = "SubID",
                                   BPPARAM = SerialParam()),
  muscat   = muscat::aggregateData(sce, assay = "counts",
                                   by = c("subclass", "SubID"),
                                   BPPARAM = SerialParam()),
  matrixutils = {
    # groupings 直接传因子列表，避免构造 8×1000 列的 model.matrix
    t(Matrix.utils::aggregate.Matrix(t(counts(sce)),
                                     groupings = list(sce$subclass, sce$SubID),
                                     fun = "sum"))
  },
  naive = stop("naive 方法不走本脚本；请用 code/08_01b_naive.py")
)
dt <- as.numeric(difftime(Sys.time(), t0, units = "secs"))

# 结果落盘（供 08_05 汇总）
write.csv(data.frame(method = method, n_donors = donors, rep = rep_id,
                     seconds = dt, n_cells = ncol(sce)),
          sprintf("results/benchmark_pb_%s_%d_%d.csv", method, donors, rep_id),
          row.names = FALSE)
saveRDS(pb, sprintf("processed/bench_pb_%s_%d_%d.rds", method, donors, rep_id))
```

```python
# code/08_01b_naive.py
# naive 基准：逐 donor × 逐 cell type 读取 H5AD 并求和（模拟原文的 8000 次低效读取）
import argparse, time, anndata as ad, numpy as np, pandas as pd
p = argparse.ArgumentParser()
p.add_argument("--h5", required=True); p.add_argument("--donors", type=int, default=200)
p.add_argument("--out", required=True)
a = p.parse_args()
adata = ad.read_h5ad(a.h5, backed="r")
donors = list(pd.unique(adata.obs["SubID"].astype(str)))[:a.donors]
cts = list(pd.unique(adata.obs["subclass"].astype(str)))
t0 = time.time()
rows = {}
for d in donors:
    for ct in cts:
        idx = np.where((adata.obs["SubID"].astype(str).to_numpy() == d) &
                       (adata.obs["subclass"].astype(str).to_numpy() == ct))[0]
        if len(idx) == 0:
            continue
        x = adata[idx].to_memory().X
        rows[(ct, d)] = np.asarray(x.sum(axis=0)).ravel()
out = pd.DataFrame(rows, index=adata.var_names)
out.to_csv(a.out, sep="\t")
print("naive seconds:", time.time() - t0)
```

### 4.3 DE 基准：六种方法

```r
# code/08_02_bench_de.R
# 输入：pb（12 细胞类型 × 326 受试者）
# 输出：results/benchmark_de_time.csv
suppressPackageStartupMessages({
  library(dreamlet); library(muscat); library(edgeR); library(DESeq2)
  library(lme4); library(MAST); library(BiocParallel)
})

# 固定效应公式（limma/edgeR/DESeq2 不能处理 (1|...)）
form_fixed <- ~ Dx + Age + Sex

run_dreamlet <- function(pb, form) {
  proc <- processAssays(pb, form, min.cells = 5, min.count = 10, BPPARAM = SerialParam())
  dreamlet(proc, form, BPPARAM = SerialParam())
}

run_limma <- function(pb) {
  proc <- processAssays(pb, form_fixed, min.cells = 5, min.count = 10, BPPARAM = SerialParam())
  lapply(assayNames(proc), function(k) {
    ex <- proc[[k]]
    cd <- as.data.frame(colData(proc))[colnames(ex$E), , drop = FALSE]
    design <- model.matrix(form_fixed, data = cd)
    fit <- limma::lmFit(ex$E, design, weights = ex$weights)
    limma::eBayes(fit)
  })
}

run_edger <- function(pb) {
  cd <- as.data.frame(colData(pb))
  cd <- cd[complete.cases(cd[, c("Dx", "Age", "Sex")]), ]
  lapply(assayNames(pb), function(k) {
    y <- assay(pb, k)[, rownames(cd), drop = FALSE]
    dge <- edgeR::DGEList(y); dge <- edgeR::calcNormFactors(dge)
    design <- model.matrix(form_fixed, data = cd)
    edgeR::glmQLFit(dge, design)
  })
}

run_deseq2 <- function(pb) {
  cd <- as.data.frame(colData(pb))
  cd <- cd[complete.cases(cd[, c("Dx", "Age", "Sex")]), ]
  lapply(assayNames(pb), function(k) {
    y <- assay(pb, k)[, rownames(cd), drop = FALSE]
    dds <- DESeq2::DESeqDataSetFromMatrix(y, cd, form_fixed)
    DESeq2::DESeq(dds, quiet = TRUE)
  })
}

# 单细胞级 GLMM（只在小数据子集、少量基因上跑）
run_glmer <- function(sce, genes, n_cells_per_subject = 50) {
  suppressPackageStartupMessages(library(lme4))
  set.seed(20261018)
  cells <- unlist(lapply(split(seq_len(ncol(sce)), sce$SubID), function(i)
    head(i, n_cells_per_subject)))
  sce <- sce[, cells]
  lib <- colSums(counts(sce))
  lapply(genes, function(g) {
    df <- data.frame(y = as.numeric(counts(sce)[g, ]), lib = lib,
                     Dx = sce$Dx, SubID = sce$SubID)
    tryCatch(glmer(cbind(y, lib - y) ~ Dx + (1 | SubID), family = binomial, data = df),
             error = function(e) NULL)
  })
}
```

> `glmer`/MAST 必须在**单细胞级**跑（不是 pseudobulk），且只在小样本子集、少量基因上跑；否则会跑数天。原文也是这么做的。`run_glmer()` 给的是二项 GLMM 的近似基线（MAST 用的是 hurdle 模型），只用于**时间量级**对照，不用于复现 MAST 的 p 值。

### 4.4 模拟数据：AUPR/F1

```r
# code/08_03_simulation.R
# 以 muscat 的 simData 为骨架；真值来自 sim 对象的 gene_info
suppressPackageStartupMessages({ library(muscat); library(SingleCellExperiment) })

set.seed(20261018)
# 1) 从真实 pb 估计参数（muscat::estimateDisp 等）
# 2) 模拟：n_subj × n_rep，注入 DE 基因
# 3) 对每个方法取 topTable，按 p 排序，计算 AUPR
aupr <- function(p, truth) {
  ord <- order(p)
  truth <- truth[ord]
  tp <- cumsum(truth); fp <- cumsum(!truth)
  precision <- tp / (tp + fp); recall <- tp / sum(truth)
  # 梯形积分
  sum(diff(c(0, recall)) * (c(0, precision[-length(precision)]) + precision) / 2)
}
```

> 完整的 9 方法 harness 需要按作者仓库 `muscat-comparison_v2` 的接口适配；本项目把"模拟参数估计 + DE 调用 + 指标计算"三块解耦，便于替换方法。

### 4.5 置换 FPR

```r
# code/08_04_permutation_fpr.R
# 对每个受试者置换 Dx，保留 pool 内 AD/Control 比例
suppressPackageStartupMessages({ library(dplyr); library(dreamlet) })

permute_within_pool <- function(cd, n_perm = 20) {
  # ★ 原文："permuted the disease labels of each donor … within each sample batch"
  #   所以置换单位是 **受试者（SubID）**，不是样本（Channel）
  donor <- cd |> dplyr::distinct(SubID, poolID, Dx)
  stopifnot(!anyDuplicated(donor$SubID))   # 一个供体只属于一个 pool
  lapply(seq_len(n_perm), function(i) {
    donor$Dx_perm <- donor$Dx
    for (p in unique(donor$poolID)) {
      idx <- which(donor$poolID == p)
      donor$Dx_perm[idx] <- sample(donor$Dx[idx])   # 池内、受试者级置换
    }
    donor$Dx_perm <- factor(donor$Dx_perm, levels = c("Control", "AD"))
    cd$Dx_perm <- donor$Dx_perm[match(cd$SubID, donor$SubID)]
    cd
  })
}

fpr_one <- function(fit, coef = "Dx_permAD") {
  # 所有细胞类型、所有表达基因中 p<0.05 的比例
  ps <- unlist(lapply(assayNames(fit), function(k) {
    tt <- topTable(fit[[k]], coef = coef, number = Inf, sort.by = "none")
    tt$P.Value
  }))
  mean(ps < 0.05, na.rm = TRUE)
}
```

**关键对照**：batch 作固定效应 vs 随机效应。AD 的 batch 是 `poolID`（数量以实际列为准，D18），固定效应会消耗大量 df。

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 内存测量每次差 2 倍 | R GC 时机 | 多次取中位数；报告范围 |
| 基准跑不完 | 数据太大/方法太慢 | 先跑 ≤200 donors；GLMM 只跑子集 |
| pegasus 装不上 | Python 依赖/版本 | 用独立 conda 环境；记录版本 |
| `aggregate.Matrix` 爆内存 | 需要 in-memory | 这正是 dreamlet 的卖点；如实记录 OOM |
| 模拟的 AUPR 全都接近 1 | DE 信号太强 | 降低 logFC/DE 比例 |
| 置换 FPR 全都 0 | 置换后没重新拟合 | 每次置换都要重跑模型 |
| 并行导致 wall time 不可比 | 线程数不同 | 基准固定 1 线程；生产另报 |
| 不同方法用的基因集不同 | 过滤规则不一致 | 统一 `filterByExpr` 后再比 |
