
## ⑨ 批判性评述（审稿人 / 导师视角）

### 9.1 方法与证据等级

| 结论 | 证据等级 | 理由 |
|---|---|---|
| dreamlet 在 pseudobulk 上比 naive 快、省内存 | **A**（可直接复现） | 公开代码 + 可构造数据；硬件差异只影响绝对值 |
| 两级权重改善 AUPR | **B** | 模拟框架公开，但模拟本身的真实性有限（作者也承认） |
| 置换标签下 dreamlet FPR 受控 | **B** | 单一数据集（AD）验证；跨数据集外推未证 |
| COVID/前列腺癌/AD 的具体 DEG 数与通路 | **B–C** | 依赖数据版本、QC 阈值、FDR 口径、注释体系 |
| PTPRG 是 AD microglia 的强上调基因 | **B** | 统计上稳健（多队列一致）；**因果未知** |
| PTPRG 驱动 AD 病理 | **D（不成立）** | 原文自己写"role unclear"、"reactive"；无功能实验 |
| 细胞类型特异效应 = 该类型特有生物学 | **C** | 原文明确警告：也可能是该类型效力更低 |

### 9.2 方法学上的强项

1. **统计设计诚实**：明确承认 pseudobulk 丢失样本内异质性；明确区分"细胞类型特异"与"效力差异"。
2. **FPR 验证用真实数据置换**，而不是只靠模拟——这是很多方法论文缺的。
3. **工程与统计一体**：H5AD on-disk + beachmat + 并行，使 4.1 M 细胞在单机可跑。
4. **与 Bioconductor 生态无缝**：SCE、limma、variancePartition、zenith 复用，降低学习成本。
5. **代码与数据公开**（dreamlet_analysis、syn51188606）。

### 9.3 局限与可质疑之处

| # | 局限 | 影响 | 复现时的处理 |
|---|---|---|---|
| L1 | pseudobulk 丢失样本内分布（双峰、burst、梯度） | 无法检测"亚群比例变化"驱动的假阴性/假阳性 | 在讨论中声明；必要时补单细胞级敏感性分析 |
| L2 | LMM 的 df 近似只匹配一阶矩 | 小样本 p 值可能偏保守/偏激进 | 与 `n−p`、Satterthwaite 对比（D8 敏感性） |
| L3 | 两级权重的第一级依赖 Poisson 假设 | 过离散强时第一级只提供"排序"，第二级纠正 | 两级 vs 单级对照（D7） |
| L4 | FPR 验证只在 AD 数据 | 其他组织/平台的外推性未知 | 在 COVID/Kfoury 上重复置换（若样本量允许） |
| L5 | 高维批次（pool 数见 D18）随机效应假设 `b ~ N(0, τ²)` | 若批次效应非正态/异方差，收缩可能过度 | 与 Harmony 对照（13 号）；报告 pool 方差分数 |
| L6 | "study-wide FDR" 未定义 | DEG 数可差一个数量级 | D6 双口径并列 |
| L7 | 关键参数（QC 阈值、min.cells、Leiden 分辨率）未报告 | 复现者自由度大 | D4/D16；敏感性分析 |
| L8 | 计算基准的硬件依赖 | 绝对时间不可比 | D13 只报相对值 |
| L9 | PTPRG 的因果性 | 可能被过度解读 | 明确写"相关性，非因果"；不写"驱动" |
| L10 | 数据受控访问（Synapse/COMBAT） | 可重复性受限于数据获取 | 记录申请流程与版本；提供替代数据管线联调 |

### 9.5 可扩展方向

1. **单细胞级敏感性分析**：对同一数据跑 MAST/glmer，比较 pseudobulk 与单细胞级的效应方向（预期：大效应基因一致，小效应基因分歧）。
2. **跨组织外推**：在 COVID/Kfoury 上重复置换 FPR，检验"FPR 受控"是否只适用于 AD。
3. **权重消融**：系统比较"无权重 / 单级 voom / 两级 Poisson+voom"，量化每一级的贡献。
4. **df 近似比较**：`n−p` vs `n−tr(H)` vs Satterthwaite，在小样本下的 p 值校准。
5. **批次建模**：随机效应 vs Harmony vs 两者结合，在模拟批次结构下的 FPR/功效。
