## ② 背景原理

### 2.1 `dreamlet()` 的执行链

```text
dreamletProcessedData（每类一个 EList: E + weights）
   │  对每个 assay：
   │    1. 取该细胞类型的样本子集（min.cells 已在上游过滤）
   │    2. 构建 design matrix（固定效应）+ 随机效应项
   │    3. dream(): 逐基因 lmer(weights) → GLS β̂、Var(β̂)、残差方差、df
   │    4. eBayes(): squeezeVar → moderated t / F
   ▼
dreamletResult（list of MArrayLM2）
   │  topTable(coef=)
   ▼
data.frame: ID, logFC, AveExpr, t, P.Value, adj.P.Val, B, ...
```

`dreamlet()` 本身不做归一化、不做权重——它假定 `res.proc` 已经处理好。这一点是复现时"数值对不上"的头号原因：**不要**在 `dreamlet()` 里再传原始计数。

### 2.2 两个公式：权重公式 vs 检验公式

原文/作者代码里，**同一队列用了两个不同的 formula**：

| 队列 | `processAssays()` 的 formula（估权重） | `dreamlet()` 的 formula（做检验） |
|---|---|---|
| COVID | `~ Age + (1|sex) + (1|Source)` | `~ Source + Age + sex` |
| Kfoury | `~ (1|subject.id) + (1|Status) + (1|subject.status)` | `~ 0 + Status + (1|subject.id)` + contrasts |
| AD | `~ (1|SubID) + (1|poolID) + (1|Sex) + scale(Age) + (1|Dx)` | `~ (1|SubID) + (1|poolID) + (1|Sex) + scale(Age) + Dx` |

为什么可以不同？`processAssays()` 的文档写得很清楚：

> "The precision weights are estimated using the residuals fit from the specified formula. These weights are robust to changes in the formula as long as the major variables explaining the highest fraction of the variance are included."

翻译：**权重只需要"把主要方差来源扣掉"，不需要是正确的因果模型**。所以估权重时把 `Source`/`Dx` 当随机效应（吸收其全部方差），做检验时再把它当固定效应（估计并检验其系数）。这是两阶段设计的精髓，也是复现者最容易"统一成一个公式"而错的地方。

> ⚠️ **导师批注**：如果你把两个公式统一，数值不会崩，但权重会略有不同、p 值会偏移。原文没有在正文解释这一点；作者代码是唯一证据。**必须按作者代码的两套公式复现**（D5）。

### 2.3 系数命名与 contrasts

R 的 `model.matrix()` 用"处理对比"（treatment contrast）编码：

- 因子 `Dx` 水平 `c("Control","AD")` → 系数 `DxAD` = AD − Control。
- 因子 `Source` 水平含 `Healthy` 为参考 → `SourceCOVID_MILD`、`SourceCOVID_SEV`、`SourceCOVID_CRIT`、`SourceCOVID_HCW_MILD`、`SourceSepsis`。
- 无截距模型 `~ 0 + Status` → 每个水平一个系数；此时用 `contrasts` 构造任意两两差：

```r
contrasts <- c(
  Tumor_Involved  = "StatusTumor - StatusInvolved",
  Tumor_Distal    = "StatusTumor - StatusDistal",
  Involved_Distal = "StatusInvolved - StatusDistal"
)
```

`makeContrastsDream()` 会在每个细胞类型内求解线性组合，方差用 $\mathbf C^\top\operatorname{Var}(\hat\beta)\mathbf C$。

**系数名的可读性**：`coefNames(fit)` 返回全部可用系数；复现时先把它们打印出来、写进日志，再写死到下游脚本，避免"猜名字"。

### 2.4 FDR 的两层口径

原文 Fig. 6B 的图注写：

> "'*' indicates study-wide FDR < 5% in all panels."

"study-wide" 不是 R 默认的 `topTable()` 行为。`topTable()` 的 `adj.P.Val` 是**在当前细胞类型内**对全部基因做 BH。两种口径：

| 口径 | 定义 | 适用 |
|---|---|---|
| **细胞类型内 BH** | 对某细胞类型的 $G$ 个基因的 p 做 BH | 回答"这个细胞类型里哪些基因显著" |
| **study-wide BH** | 对同一 coef 下**全部细胞类型 × 全部基因**的 p 合并做 BH | 回答"跨 22 个细胞类型一起看，哪些基因显著"（原文主图） |

实现：

```r
tt_list <- lapply(assayNames(fit), function(k) {
  as.data.frame(topTable(fit[[k]], coef = coef, number = Inf, sort.by = "none")) |>
    tibble::rownames_to_column("ID") |>
    dplyr::mutate(assay = k)
})
tt_all <- dplyr::bind_rows(tt_list)
tt_all$adj.P.Val.studywide <- p.adjust(tt_all$P.Value, method = "BH")
```

> ⚠️ **导师批注**：study-wide BH 的检验数 = 22 × ~15,000 ≈ 330,000，比单细胞类型严格得多。原文报"1037 个 DEG"用的是哪一种？——从 Fig. 6B 的图注看是 study-wide。**如果不一致，DEG 数会差一个数量级**。这就是 D6 必须写进方法学的原因。

### 2.5 效应量、标准误与置信区间

- `logFC`：log2 尺度，等于两组 log2 CPM 之差。
- `SE = logFC / t`（`topTable` 不直接给 SE，但可由 t 反推；作者代码正是这么做的）。
- 95% CI：`logFC ± 1.96·SE`。
- 森林图（Fig. 3F、6C–D）画的就是这个 CI，颜色映射 FDR。

### 2.6 `pi0` / `pi1`：有多少基因是真的

作者代码用 `qvalue::pi0est(P.Value)$pi0` 估计零假设比例，$\pi_1=1-\pi_0$ 是"真实差异基因的比例"。它不依赖 FDR 阈值，是衡量"信号总量"的稳健指标。原文 Supplementary Fig. 5/8 的 y 轴之一就是 $\pi_1$。

### 2.7 火山图/森林图/热图的语义

| 图 | x 轴 | y 轴 | 颜色 | 读法 |
|---|---|---|---|---|
| 火山图 | `logFC` | `-log10(P)` | FDR<5% 红点 | 效应大且显著的在右上/左上 |
| 森林图 | `logFC`（点）+ 95% CI（线） | 基因/细胞类型 | FDR | 跨细胞类型比较同一基因 |
| 基因热图 | 细胞类型 | 基因 | z 统计量（`t`） | 灰色 = 未过表达过滤 |

## ④ 逐步可运行代码

### 4.1 主拟合

```r
# code/05_01_dreamlet_fit.R
# 用法：Rscript code/05_01_dreamlet_fit.R psychad
suppressPackageStartupMessages({
  library(dreamlet); library(SingleCellExperiment); library(BiocParallel)
})

args <- commandArgs(trailingOnly = TRUE)
dataset <- if (length(args) >= 1) args[1] else "psychad"
proc <- readRDS(sprintf("processed/proc_%s.rds", dataset))

# 检验公式（与 03 号的权重公式不同；见 §2.2）
form <- switch(
  dataset,
  psychad = ~ (1|SubID) + (1|poolID) + (1|Sex) + scale(Age) + Dx,
  kfoury  = ~ 0 + Status + (1|subject.id),
  covid   = ~ Source + Age + sex
)

contrasts <- switch(
  dataset,
  kfoury = c(
    Tumor_Involved  = "StatusTumor - StatusInvolved",
    Tumor_Distal    = "StatusTumor - StatusDistal",
    Involved_Distal = "StatusInvolved - StatusDistal"
  ),
  NULL
)

fit <- dreamlet(
  proc, form,
  contrasts = contrasts,
  BPPARAM   = SnowParam(16, progressbar = TRUE)
)

saveRDS(fit, sprintf("processed/fit_%s.rds", dataset))
writeLines(capture.output(sessionInfo()), sprintf("logs/05_sessionInfo_%s.txt", dataset))

# 打印可用系数（写进日志，下游不要猜）
writeLines(coefNames(fit), sprintf("logs/05_coefnames_%s.txt", dataset))
print(details(fit))
```

### 4.2 抽取结果：细胞类型内 + study-wide

```r
# code/05_02_topTable.R
# 输出：results/topTable_<dataset>_<coef>.tsv（study-wide 作为列，不单独出文件）
suppressPackageStartupMessages({ library(dreamlet); library(dplyr); library(tibble) })

args <- commandArgs(trailingOnly = TRUE)
dataset <- if (length(args) >= 1) args[1] else "psychad"
fit <- readRDS(sprintf("processed/fit_%s.rds", dataset))
coefs <- readLines(sprintf("logs/05_coefnames_%s.txt", dataset))   # 或手工指定

extract_one <- function(fit, coef) {
  bind_rows(lapply(assayNames(fit), function(k) {
    tt <- topTable(fit[[k]], coef = coef, number = Inf, sort.by = "none")
    if (is.null(tt) || nrow(tt) == 0) return(NULL)
    tt <- as.data.frame(tt)
    tt$SE <- tt$logFC / tt$t
    data.frame(
      ID = rownames(tt), tt, assay = k, coef = coef,
      row.names = NULL, check.names = FALSE
    )
  }))
}

for (cf in coefs) {
  df <- extract_one(fit, cf)
  if (is.null(df) || nrow(df) == 0) next
  # 细胞类型内 BH（topTable 已给 adj.P.Val）；这里再加 study-wide
  df$adj.P.Val.studywide <- p.adjust(df$P.Value, method = "BH")
  write.table(df, sprintf("results/topTable_%s_%s.tsv", dataset, cf),
              sep = "\t", quote = FALSE, row.names = FALSE)
}
```

### 4.3 DEG 计数与 `pi1`

```r
# code/05_03_summarize_de.R
suppressPackageStartupMessages({ library(qvalue); library(dplyr) })

summarize_de <- function(file) {
  df <- read.delim(file)
  df |>
    group_by(assay) |>
    summarize(
      n_genes      = dplyr::n(),
      nDE_within   = sum(adj.P.Val < 0.05, na.rm = TRUE),
      nDE_study    = sum(adj.P.Val.studywide < 0.05, na.rm = TRUE),
      pi1          = 1 - qvalue::pi0est(P.Value)$pi0,
      .groups = "drop"
    )
}
files <- list.files("results", "^topTable_", full.names = TRUE)
out <- bind_rows(lapply(files, function(f) {
  summarize_de(f) |> mutate(file = basename(f))
}))
write.csv(out, "results/05_de_summary.csv", row.names = FALSE)
print(out, n = 30)
```

## ⑤ 参数解释与调参空间

| 参数 | 本项目取值 | 可选 | 改变后果 |
|---|---|---|---|
| `formula`（DE） | §2.2 | 增删协变量 | 决定效应是否被混杂；把结局当随机效应 = 自杀 |
| `contrasts` | Kfoury 三个；其余 NULL | 任意线性组合 | 改变"比较的是谁减谁"；符号会翻转 |
| `coef` | 见 `coefNames()` | — | 写错会报 "coefficient not found" 或取错列 |
| FDR 口径 | 双口径输出，主图 study-wide | 细胞类型内 | DEG 数差一个数量级（D6） |
| `sort.by` | `"none"`（保留全基因） | `"P"` | 只影响行序，不影响值 |
| `number` | `Inf` | 10/100 | 截断会漏基因；复现必须 `Inf` |
| `BPPARAM` | `SnowParam(16)` | — | 只影响速度 |
| `plotVolcano` 的 `ncol` | 4 | — | 只影响排版 |

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| `topTable` 报 "coef not found" | 系数名与 `coefNames()` 不符（因子水平顺序变了） | 先 `coefNames(fit)`；用 `factor(..., levels=)` 固定参考组 |
| 所有 logFC 符号反了 | 参考水平不是对照 | 显式设 `levels = c("Control","AD")` |
| DEG 数远多于原文 | 用了细胞类型内 BH | 改用 study-wide（D6） |
| DEG 数远少于原文 | 用了 study-wide 但原文是 within | 两口径都算，报告差异 |
| 某细胞类型没有结果 | 该 assay 被 `processAssays` 丢弃 | `details(proc)` 查 `n_retain` 与 `n_genes` |
| 结果每次运行略有不同 | 并行/blas 浮点 | 声明；点估计应稳定到 1e-6 |
| `plotVolcano` 报错 | `assays=` 含不存在的名字 | `intersect(assays, assayNames(fit))` |
| 森林图的 CI 与手算不符 | 用了 `SE=logFC/t` 但 t 被截断 | 用全精度 `t`；或直接取 `fit$stdev.unscaled` |
