## ② 背景原理

### 2.1 Bag 级损失

二分类：

$$
\mathcal L_{\text{bag}}^{(j)}=-[y_j\log \hat y_j+(1-y_j)\log(1-\hat y_j)].
$$

多分类：

$$
\mathcal L_{\text{bag}}^{(j)}=-\sum_{c=1}^{C}y_{j,c}\log \hat y_{j,c}.
$$

- $y_j$ 是 bag 标签（tumor/normal 或癌种）。
- 只监督 bag，不监督细胞。

### 2.2 为什么需要 instance 级辅助损失

只用 bag loss 时，模型可以把全部注意力压在一个"容易"的阳性细胞上，忽略其他疾病相关细胞（原文 Introduction 对 bag-based MIL 的批评）。adaptive clustering loss 通过**伪标签**给极端 instance 施加约束：

1. 对 bag 内所有 tumor score $a_i$ 排序；
2. 取 **top-B** 作正伪标签、**bottom-B** 作负伪标签（$B=8$）；
3. 用一个线性 instance 分类器 $W_{\text{inst}}\in\mathbb R^{2\times256}$ 预测 $P^{(i)}=W_{\text{inst}}\mathbf h_i^{\text{gate}}$；
4. 对 2B 个 instance 计算 smooth SVM loss。

> 只取极端 2B 个，是为了避免中间"模糊"instance 的噪声标签污染训练。这是"高置信度伪标签"策略。

### 2.3 Smoothed SVM loss（正文 Eq.7）

$$
\mathcal L(P^{(i)},y^{(i)}_{\text{inst}})
=\tau\log\!\left[\sum_{k=0}^{1}\exp\!\left(\frac{1}{\tau}\left(\alpha\,\mathbb I(k\neq y^{(i)}_{\text{inst}})+p^{(i)}_k-p^{(i)}_{y^{(i)}_{\text{inst}}}\right)\right)\right],
$$

- $\tau=1.0$：温度，控制平滑程度；$\tau\to0$ 退化为 hinge。
- $\alpha=1.0$：margin。
- $\mathbb I$：指示函数。

**直觉**：对正确类别的概率比错误类别高出 margin $\alpha$ 的 instance，loss 接近 0；否则产生惩罚。log-sum-exp 是 max 的平滑版本，便于求导。

### 2.4 SmoothTop1SVM（代码实现）

作者代码用 `topk.svm.SmoothTop1SVM(n_classes=2)`：

- 它是 **top-1 multiclass SVM** 的平滑版本（Lapin et al. 2016, "Loss Functions for Top-k Error"）。
- 与正文 Eq.7 的"二分类 smoothed SVM"在形式上接近，但**不是逐项相同**：SmoothTop1SVM 对多类 logits 做 top-1 hinge 的 smooth 近似；正文 Eq.7 是对二类概率的 margin 形式。
- 复现时**以代码为准**（D3），并记录 `torch` 版本与 smooth-topk commit。

### 2.5 总损失

$$
\mathcal L^{(j)}=\beta\,\mathcal L_{\text{bag}}^{(j)}+(1-\beta)\,\mathcal L_{\text{ada}}^{(j)},
\qquad \beta=0.7.
$$

- $\beta$ 偏向 bag loss（0.7），instance loss 是辅助。
- 若 $\beta=1$：退化为纯 bag MIL；若 $\beta=0$：只有伪标签聚类。

## ④ 逐步可运行代码

### 4.1 损失实现

```python
# code/04_01_losses.py
import torch, torch.nn as nn, torch.nn.functional as F
from topk.svm import SmoothTop1SVM   # pip install git+https://github.com/oval-group/smooth-topk.git（包名 topk）

class AdaptiveClusteringLoss(nn.Module):
    """正文 Eq.6-8：按 tumor score 取 top-B/bottom-B，做 smooth SVM。"""
    def __init__(self, embed_dim=256, B=8, tau=1.0, alpha=1.0):
        super().__init__()
        self.B = B
        self.tau = tau
        self.alpha = alpha
        self.inst_cls = nn.Linear(embed_dim, 2)
        self.criterion = SmoothTop1SVM(n_classes=2)

    def forward(self, h_gate, scores):
        # h_gate: (N,d), scores: (N,) 未归一化 tumor score
        N = scores.numel()
        k = min(self.B, N // 2)
        if k == 0:
            return scores.new_zeros(())
        top_idx = torch.topk(scores, k).indices
        bot_idx = torch.topk(-scores, k).indices
        idx = torch.cat([top_idx, bot_idx])
        logits = self.inst_cls(h_gate[idx])
        targets = torch.cat([torch.ones(k, dtype=torch.long, device=scores.device),
                             torch.zeros(k, dtype=torch.long, device=scores.device)])
        return self.criterion(logits, targets)
```

> 正确导入是 `from topk.svm import SmoothTop1SVM`（作者 `core_utils.py:151` 同款）。正文 Eq.7 在 `P=logits` 时**就是** `Top1_Smooth_SVM` 的二分类形式；差别只在论文把 P 写成概率。

### 4.2 正文 Eq.7 的显式实现（对照）

```python
# code/04_02_eq7.py
import torch, torch.nn.functional as F

def smoothed_svm_loss(P, y, tau=1.0, alpha=1.0):
    """P: (n,2) **logits**（不是 softmax 概率）；y: (n,) 0/1。
    与 topk.svm.SmoothTop1SVM 的二分类形式一致；log-sum-exp 减 max 保证数值稳定。"""
    p_y = P.gather(1, y.view(-1, 1)).squeeze(1)
    terms = []
    for k in (0, 1):
        margin = alpha * (k != y).float()
        terms.append((margin + P[:, k] - p_y) / tau)
    terms = torch.stack(terms, 1)
    return tau * (torch.logsumexp(terms, dim=1)).mean()
```

### 4.3 训练循环（CLAM 风格）

```python
# code/04_03_train.py
import torch, torch.nn as nn
from torch.utils.data import DataLoader, WeightedRandomSampler
# 03 号的模型请另存为 code/model_scTransMIL.py（文件名不能以数字开头，无法直接 import）
from model_scTransMIL import ScTransMILCode

def train_one_epoch(model, loader, optimizer, criterion_bag, criterion_ada, beta=0.7):
    model.train()
    total = 0.0
    for ids, mask, label, _ in loader:
        ids, mask, label = ids.cuda(), mask.cuda(), label.cuda()
        logits, A_raw, A, h, M = model(ids, mask, return_attn=True)
        bag_loss = criterion_bag(logits, label)
        # adaptive loss 用 softmax 前的 a_i（D22；cell AUC 另用 softmax 后权重）
        scores = A_raw.squeeze(0)
        # 自适应聚类损失需要 per-instance gated embedding（h），不是 bag embedding（M）
        ada_loss = criterion_ada(h, scores)
        loss = beta * bag_loss + (1 - beta) * ada_loss
        optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0)
        optimizer.step()
        total += loss.item()
    return total / len(loader)
```

### 4.4 类别平衡采样

```python
# code/04_04_sampler.py
import numpy as np
from torch.utils.data import WeightedRandomSampler

def make_sampler(labels):
    labels = np.asarray(labels)
    cls, counts = np.unique(labels, return_counts=True)
    freq = dict(zip(cls, counts))
    w = np.array([1.0 / freq[y] for y in labels])
    return WeightedRandomSampler(weights=torch.DoubleTensor(w),
                                 num_samples=len(w), replacement=True)
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| loss 变 NaN | lr 太大 / smooth SVM 数值不稳 | 降 lr；梯度裁剪；检查 log-sum-exp |
| 模型只预测多数类 | 未做类别平衡 | 开 weighted sampler |
| ada loss 为 0 | bag 内 instance <2B | `k=min(B,N//2)` |
| 早停过早 | patience 太小 | 10（原文） |
| 训练 acc 高、测试低 | 过拟合 | dropout/weight decay/早停 |
| 多分类不收敛 | 类别极不平衡 | 类别加权 CE + 采样 |
| `SmoothTop1SVM` 报错 | CUDA 扩展未编译 | 用 CUDA 版本；或 CE 替代（声明） |
