## ② 背景原理

### 2.1 训练量实验

原文从 80% 训练 donor 池中再抽 50%、75%、100%，保持测试集固定：

- 训练集变小 → 过拟合风险↑、类别覆盖↓；
- 期望：scTransMIL 的性能随数据量单调上升，且在小数据时相对优势更明显（或至少不崩）。

### 2.2 推理时间口径

- 测量"处理一个 bag"的时间（一个 sample 的所有 sub-sample？还是一个 sub-sample？原文写 "processing a single bag"）。
- 对 PCA/FM 变体，时间**包含** PCA 拟合/scGPT 前向的开销；
- 对 DEGAS，时间包含 MMD 对齐；
- 硬件固定：10 cores / 2.5 GHz / V100；
- 报告 log 尺度（Fig. 2b）。

### 2.3 三个消融

| 消融 | 改动 | 验证的组件 |
|---|---|---|
| Ablation1 | 去掉 adaptive clustering loss（β=1，只用 bag loss） | instance 级辅助监督 |
| Ablation2 | 去掉 gating（`Attn_Net` 代替 `Attn_Net_Gated`） | 门控对噪声的过滤 |
| Ablation3 | attention pooling → **max pooling** | 注意力聚合 vs 硬选最大 |

### 2.4 Gating 的监督聚类指标

在**有细胞类型标签**的泛癌细胞上，比较 gated embedding 前后的：

- **NMI**（normalized mutual information）
- **ARI**（adjusted Rand index）
- **AMI**（adjusted mutual information）
- **HOM**（homogeneity）

期望：gated 后更高 → 门控保留了"与 bag 标签相关"的结构（但也要注意：这四者衡量的是与细胞类型标签的一致性，不是与 bag 标签）。

### 2.5 Donor setting 的标签噪声

- Sample setting：bag 标签来自 bag 内 CNV（低噪声）。
- Donor setting：donor 是癌症患者 → 其所有 bag（包括 paratumor/normal adjacent）都标 tumor（高噪声）。
- 期望：所有方法下降，MIL 类（尤其 scTransMIL）更稳。

## ④ 逐步可运行代码

### 4.1 训练量子采样

```python
# code/07_01_subsample_train.py
# 从 80% 训练 donor 中再抽 50/75/100%，保持  val/test 不变
import pandas as pd, numpy as np
split = pd.read_csv("processed/splits/splits_bicls_0.csv")
train = split[split.split == "train"].case_id.values
idx = pd.read_csv("processed/bag_index_pancancer.csv")
donor_label = idx.groupby("case_id").label.agg(lambda s: s.mode()[0])
for frac in (0.5, 0.75, 1.0):
    rng = np.random.default_rng(20261018)
    # ★ 按 donor 抽样（不是 sample），并按癌种分层
    sub = []
    for lab, grp in pd.Series(train).groupby(donor_label.loc[train].values):
        grp = np.array(grp); rng.shuffle(grp)
        sub += list(grp[:max(1, int(round(len(grp)*frac)))])
    sub = np.array(sub)
    out = split.copy()
    out.loc[out.case_id.isin(train) & ~out.case_id.isin(sub), "split"] = "unused"
    out.to_csv(f"processed/splits/splits_bicls_0_frac{int(frac*100)}.csv", index=False)
```

### 4.2 计时

```python
# code/07_02_time.py
import time, torch
def time_one_bag(model, ids, mask, n_repeat=10):
    model.eval(); torch.cuda.synchronize()
    t0 = time.time()
    with torch.no_grad():
        for _ in range(n_repeat):
            model(ids.cuda(), mask.cuda())
    torch.cuda.synchronize()
    return (time.time() - t0) / n_repeat
```

> 计时前先跑 3 次 warm-up；报告 mean±s.d.；PCA/FM 变体把预处理时间计入。

### 4.3 三个消融

```python
# code/07_03_ablation.py
# Ablation1: beta=1.0（只用 bag loss）
# Ablation2: gate=False（Attn_Net 代替 Attn_Net_Gated）
# Ablation3: pooling="max"（max pooling 代替 attention）
from models.model_clam import CLAM_SB
kw = dict(size_arg="small", dropout=0.25, k_sample=8, n_classes=2, embed_dim=256)

class MaxPoolCLAM(CLAM_SB):
    """Ablation3：把 attention pooling 换成 max pooling。"""
    def forward(self, features, label=None):
        ids, mask = features
        h = self.bert_encoder(input_ids=ids, attention_mask=mask).pooler_output
        M = h.max(dim=0, keepdim=True).values
        logits = self.classifiers(M)
        return logits

m1 = CLAM_SB(gate=True, **kw)     # Ablation1：训练时 bag_weight=1.0（criterion_ada 置零）
m2 = CLAM_SB(gate=False, **kw)    # Ablation2：去掉门控
m3 = MaxPoolCLAM(gate=True, **kw) # Ablation3：max pooling
```

> Ablation3 的"max pooling"实现：`M = h.max(dim=0).values`，分类头不变；训练时也用 max。

### 4.4 Gating 的聚类指标

```python
# code/07_04_gating_metrics.py
from sklearn.metrics import normalized_mutual_info_score, adjusted_rand_score, adjusted_mutual_info_score, homogeneity_score
from sklearn.cluster import KMeans
def cluster_metrics(emb, cell_type, n_types=None):
    # ★ 先聚类（KMeans，k=细胞类型数），再与真实标签比较；不要把连续嵌入直接当标签
    n_types = n_types or len(set(cell_type))
    pred = KMeans(n_clusters=n_types, random_state=20261018, n_init=10).fit_predict(emb)
    return dict(NMI=normalized_mutual_info_score(cell_type, pred),
                ARI=adjusted_rand_score(cell_type, pred),
                AMI=adjusted_mutual_info_score(cell_type, pred),
                HOM=homogeneity_score(cell_type, pred))
```

> 这里的 `emb` 应该是**聚类结果**（如 KMeans）而不是原始嵌入；原文的"supervised clustering metrics"需要先对嵌入做 KMeans（k=细胞类型数），再算指标。复现时明确这一点。

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 训练量曲线不单调 | 子采样未分层 | 按癌种分层抽样 |
| 计时差异巨大 | 未 warm-up / 未同步 | `torch.cuda.synchronize()` |
| 消融没下降 | 消融实现不彻底（如仍算 ada loss） | 检查 loss 项与模型开关 |
| gating 指标反了 | 聚类前未标准化 | 标准化后再 KMeans |
| Donor setting 全崩 | 标签噪声过大 | 这是预期；报告相对排序 |
