## ② 背景原理

### 2.1 KIDA（pseudo-bulk aggregation）

- 把一个 sample 的所有细胞表达**平均**成 bulk 向量；
- 用生物通路注释初始化网络参数；
- 自注意力学习通路间交互；
- 输出 sample 级预测。

**局限**：平均会稀释稀有恶性细胞（甲状腺 Patient 5 的 0.64 vs KIDA <0.5 正是这个原因）。

### 2.2 DEGAS（joint latent space learning）

- 同时编码 patient/sample 与 single cell；
- 用 **MMD**（最大均值差异）最小化两个分布的差距；
- 在联合空间里把 patient 标签"迁移"给细胞。

**局限**：分布对齐会**过度平滑**，掩盖肿瘤异质性；R 实现，计算慢（720 s/bag）。

### 2.3 scIDST（instance-based MIL）

- 直接把 bag 标签赋给 bag 内所有细胞作伪标签；
- 用全连接网络学习"细胞 → 伪标签"；
- 引入概率标签策略缓解噪声。

**局限**：正常组织里混入的少量恶性细胞会被"多数正常"淹没；标签噪声大。

### 2.4 scVI + MIL（bag-based MIL）

- 先用 **scVI**（变分自编码器）无监督学习细胞嵌入；
- 再用 **MultiMIL** 的 attention pooling 做 bag 级分类。

**局限**：scVI 嵌入不是为"癌变"任务优化的；attention pooling 仍可能在少阳性细胞时过拟合。

### 2.5 两个变体

| 变体 | 替代什么 | 目的 |
|---|---|---|
| scTransMIL(PCA) | 用 512 维 PCA 嵌入替代 Transformer 细胞嵌入 | 验证"rank + Transformer"的贡献 |
| scTransMIL(FM) | 用 scGPT whole-human 的 512 维嵌入 | 验证"从头训练的 rank Transformer" vs "基础模型" |

> 这两个变体共享同一套 gated encoder / aggregator / 损失，只换 instance encoder —— 是**受控消融**。

### 2.6 公平性四原则

1. **同一 splits**：所有方法用同一份 donor 划分（同一 `splits_*.csv`）。
2. **同一 bag**：同一批 `input_ids` / h5ad；baseline 若需要不同输入（如 scVI 嵌入），在 pipeline 内生成，但 bag 边界不变。
3. **同一指标**：样本级 Acc/AUC/macro-F1；单细胞 AUC 用同一 CNV 参照。
4. **同一调参预算**：每个基线在验证集上早停；报告最优。

## ④ 逐步可运行代码

### 4.1 统一接口

```python
# code/06_00_base.py
from abc import ABC, abstractmethod
import torch, torch.nn as nn

class BagModel(ABC):
    """所有基线/变体的统一接口：输入 (ids, mask) 或预计算嵌入，输出 logits。"""
    @abstractmethod
    def forward(self, batch) -> torch.Tensor: ...

class EmbeddingMIL(BagModel):
    """scVI / PCA / scGPT 变体共用：固定嵌入 + 门控注意力 MIL。"""
    def __init__(self, embed_dim, n_classes=2, gate_dim=64):
        super().__init__()
        self.gate_a = nn.Sequential(nn.Linear(embed_dim, gate_dim), nn.Tanh())
        self.gate_b = nn.Sequential(nn.Linear(embed_dim, gate_dim), nn.Sigmoid())
        self.score = nn.Linear(gate_dim, 1)
        self.cls = nn.Linear(embed_dim, n_classes)

    def forward(self, h, return_attn=False):
        A = self.score(self.gate_a(h) * self.gate_b(h)).transpose(1, 0)
        A = torch.softmax(A, dim=1)
        M = torch.mm(A, h)
        logits = self.cls(M)
        return (logits, A) if return_attn else logits
```

### 4.2 scTransMIL(PCA)

```python
# code/06_01_pca_variant.py
import scanpy as sc, numpy as np
from sklearn.decomposition import PCA

def fit_pca_on_train(train_h5ads, n_pc=512):
    """★ 在训练集全部细胞上拟合一次，再 transform 每个 bag（不要逐 bag 拟合）。"""
    import anndata as ad
    Xs = []
    for f in train_h5ads:
        a = sc.read_h5ad(f)
        sc.pp.normalize_total(a, target_sum=1e4); sc.pp.log1p(a)
        Xs.append(a.X.toarray() if hasattr(a.X, "toarray") else a.X)
    X = np.vstack(Xs)
    pca = PCA(n_components=n_pc, random_state=20261018).fit(X)
    return pca

def transform_bag(pca, bag_h5ad):
    a = sc.read_h5ad(bag_h5ad)
    sc.pp.normalize_total(a, target_sum=1e4); sc.pp.log1p(a)
    X = a.X.toarray() if hasattr(a.X, "toarray") else a.X
    return pca.transform(X).astype("float32")
```

> PCA 在**每个 bag 内**拟合会引入 bag 间不一致；更合理的做法是在训练集全局拟合，再 transform 每个 bag。原文未说明；本项目采用**全局拟合**并在 D 表记录。

### 4.4 scVI + MIL

```python
# code/06_03_scvi_mil.py
import scvi, scanpy as sc, anndata as ad
def train_scvi(adata, n_latent=512, max_epochs=100):
    # ★ 先确认 X 是原始整数 counts；若不是，改用 raw/layers["counts"]
    import numpy as np
    X = adata.X[:50].toarray() if hasattr(adata.X, "toarray") else adata.X[:50]
    assert np.allclose(X, np.round(X)) and X.min() >= 0, "X 不是原始 counts"
    adata.layers["counts"] = adata.X.copy()
    scvi.model.SCVI.setup_anndata(adata, layer="counts", batch_key=None)
    m = scvi.model.SCVI(adata, n_latent=n_latent)
    m.train(max_epochs=max_epochs)
    return m.get_latent_representation()
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 基线用了不同 splits | 接口未统一 | 强制同一 `splits_*.csv` |
| scVI 嵌入泄漏标签 | 用了带标签的 batch key | 无监督、只用量 |
| DEGAS 跑不动 | R 依赖/内存 | 降样本；记录 |
| KIDA 输出维度不符 | 通路集版本 | 用官方通路文件 |
| PCA 每 bag 拟合 | 实现错误 | 全局拟合 |
| scGPT 维度不符 | 权重/池化层 | 取 512 维输出 |
