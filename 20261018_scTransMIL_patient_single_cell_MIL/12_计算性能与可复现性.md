## ② 背景原理

### 2.1 计时口径

原文：

> "we measured the inference time … required for processing a single bag on an identical hardware server (CPU: 10 cores, 2.5 GHz/core, GPU: NVIDIA TESLA V100)."

- 单位：秒/bag；
- 对 PCA/FM 变体，**含** PCA 拟合/scGPT 前向；
- 对 DEGAS，含 MMD 对齐；
- 报告 log 尺度（Fig. 2b）。

**正确的计时**：

1. warm-up 3–5 次（CUDA kernel 编译、缓存）；
2. `torch.cuda.synchronize()`；
3. 重复 10 次取均值；
4. 固定 batch=1 bag；
5. 记录 GPU 型号/驱动/CUDA。

### 2.2 显存的来源

一个 bag：$m\le256$ cells × $L=1024$ tokens。

- Transformer 自注意力：每个 head 每层 $m\times L\times L$ 的分数矩阵，单 head 约 $256\times1024^2\times4$ B ≈ 1 GB；4 heads × 6 层 ≈ 26 GB（eager）。SDPA/FlashAttention 或 gradient checkpointing 可把峰值压到数 GB；
- BERT 6 层 + 反向传播 → 训练显存 > 前向；
- ~10 M 参数本身的梯度/优化器状态约 0.12 GB。

**降显存手段**：`max_len` 1024→512；bag 256→128；gradient checkpointing；混合精度（AMP）。

### 2.3 7 次重复的统计

- 每次 split 独立训练/测试；
- 报告 mean ± s.d.；
- 不报告"最好一次"；
- 若某次训练失败（NaN/不收敛），**保留失败记录**，不能静默丢弃（L0 §12.5）。

### 2.4 可复现性的四个层次

| 层次 | 要求 |
|---|---|
| 代码 | commit/Zenodo 版本固定 |
| 数据 | 版本 + md5 + 划分文件 |
| 环境 | `pip freeze` + CUDA/cuDNN 版本 |
| 随机性 | 种子 + `torch.backends.cudnn.deterministic` |

> GPU 上的非确定性算子（如 `atomicAdd`）即使设种子也可能有微小差异；报告中声明。

## ④ 逐步可运行代码

### 4.1 计时脚本

```python
# code/12_01_time.py
import time, torch, numpy as np

def benchmark(model, ids, mask, n_warmup=3, n_repeat=10):
    model.eval().cuda()
    for _ in range(n_warmup):
        with torch.no_grad(): model(ids.cuda(), mask.cuda())
    torch.cuda.synchronize()
    ts = []
    for _ in range(n_repeat):
        torch.cuda.synchronize(); t0 = time.time()
        with torch.no_grad(): model(ids.cuda(), mask.cuda())
        torch.cuda.synchronize(); ts.append(time.time() - t0)
    return float(np.mean(ts)), float(np.std(ts))
```

### 4.3 7 次重复汇总

```python
# code/12_03_aggregate.py
import pandas as pd, numpy as np
from sklearn.metrics import accuracy_score, roc_auc_score, f1_score
rows = []
for i in range(7):
    df = pd.read_csv(f"results/metrics_bicls_scTransMIL_fold{i}.csv")
    rows.append(dict(fold=i,
                     acc=accuracy_score(df.Y, df.Y_hat),
                     auc=roc_auc_score(df.Y, df.Y_prob),
                     f1=f1_score(df.Y, df.Y_hat, average="macro", zero_division=1)))
out = pd.DataFrame(rows)
print(out.agg(["mean", "std"]))
out.to_csv("results/12_summary_7folds.csv", index=False)
```

### 4.4 确定性设置

```python
# code/12_04_determinism.py
import torch, numpy as np, random, os
def seed_all(seed):
    random.seed(seed); np.random.seed(seed); torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    os.environ["PYTHONHASHSEED"] = str(seed)
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False
```

> 注意：`cudnn.deterministic=True` 会降低速度；只在需要严格复现时开。

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 计时波动大 | 无 warm-up/同步 | 按 4.1 |
| 显存 OOM | 1024 tokens | 降 max_len/AMP/checkpoint |
| 7 次结果差异大 | 数据划分/初始化 | 固定种子；报告 s.d. |
| 复现不了某次 | 非确定性算子 | 声明；固定 cudnn |
| 只报最好一次 | 选择偏差 | 报全部 7 次 |
