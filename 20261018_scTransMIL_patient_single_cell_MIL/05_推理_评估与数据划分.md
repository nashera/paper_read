## ② 背景原理

### 2.1 数据划分：按 donor 分层

若按 sample 随机划分，同一 donor 的不同 tissue/sample 可能同时出现在训练与测试 → **信息泄漏**（模型记住的是"这个人的表达特征"，不是"癌变特征"）。

原文：

> "randomly splitting the dataset into 80% training, 10% validation, and 10% test sets based on donors, ensuring that donors in the test and validation sets were completely unseen during training."

实现：`patient_strat=True`（按 donor 分层，保持各癌种比例），`n=7` 次独立随机划分。

### 2.2 从 sub-sample 到 sample

对一个测试 sample：

1. 取出它所有的 sub-sample（bag）；
2. 每个 bag 独立前向，得到 $\hat y_{\text{bag}}\in\{0,1\}$；
3. **二分类聚合**：只要有一个 bag 预测 tumor → 整个 sample 为 tumor（近似 MIL 的 OR）；
4. **多分类聚合**：对预测为 tumor 的 bag 的癌种概率**投票**（或概率平均），得 sample 癌种。

> 为什么用"任一阳性"而不是"多数投票"：MIL 假设是 OR —— 一个 sample 里只要有一小撮恶性细胞，就该判阳性。多数投票会被大量正常细胞稀释（原文对 pseudo-bulk 的批评正是这一点）。

### 2.3 指标

| 层级 | 指标 | 定义 |
|---|---|---|
| 样本级二分类 | Accuracy | 正确样本 / 总样本 |
| | AUC | ROC 曲线下面积（用 `Y_prob`） |
| | macro-F1 | 两类 F1 的宏平均 |
| 样本级多分类 | Accuracy / macro-F1 | 29/30 类 |
| 单细胞级 | AUC / Acc / F1 | 以 CNV status 为参照，tumor score 排序 |

> ⚠️ **导师批注**：`2-bag_eval.py` 里二分类的 `roc_auc_score(true_label, pred_label)` 用的是**硬标签** `Y_hat`，不是概率——这会让 AUC 退化为 balanced accuracy 的线性变换。复现时应使用 `Y_prob` 计算 AUC，并在方法学声明（D20）。

### 2.4 单细胞评估的"参照"问题

CNV status 是计算推断，不是金标准：

- 对 CNV 阴性但转录组异常的肿瘤（如低级别胶质瘤、HHD-ALL），CNV 参照会漏标；
- 因此 scTransMIL 在这些样本上"与参照不一致"不一定是错（09 号 HHD 例子）。
- 报告 cell-level AUC 时，必须同时给出"参照的局限性"。

## ④ 逐步可运行代码

### 4.1 生成 donor 级划分

```python
# code/05_01_make_splits.py
# 用法：python code/05_01_make_splits.py --task bicls --n_splits 7
import argparse, numpy as np, pandas as pd
from sklearn.model_selection import StratifiedGroupKFold

ap = argparse.ArgumentParser()
ap.add_argument("--task", choices=["bicls", "multicls"], default="bicls")
ap.add_argument("--n_splits", type=int, default=7)
ap.add_argument("--seed", type=int, default=20261018)
a = ap.parse_args()

csv = ("processed/bag_index_pancancer.csv" if a.task == "bicls"
       else "processed/bag_index_pancancer_multicls.csv")
df = pd.read_csv(csv)
# case_id = donor；同一 donor 的所有 bag 必须进同一侧
groups = df["case_id"].values
y = df["label"].astype("category").cat.codes.values

for i in range(a.n_splits):
    rng = np.random.default_rng(a.seed + i)
    donors = np.array(sorted(df["case_id"].unique()))
    # 按 donor 的癌种分层（每个 donor 取众数标签）
    donor_label = df.groupby("case_id")["label"].agg(lambda s: s.mode()[0])
    rng.shuffle(donors)
    # 简化：按标签分层后 80/10/10
    train, val, test = [], [], []
    for lab, grp in pd.Series(donors).groupby(donor_label.loc[donors].values):
        grp = np.array(grp)
        rng.shuffle(grp)
        n = len(grp)
        if n <= 3:                      # 极稀有癌种：全部进训练，val/test 为空会报错
            train += list(grp); continue
        n_test = max(1, int(round(0.1*n))); n_val = max(1, int(round(0.1*n)))
        test += list(grp[:n_test]); val += list(grp[n_test:n_test+n_val]); train += list(grp[n_test+n_val:])
    donor2split = {d: "train" for d in train}
    donor2split.update({d: "val" for d in val})
    donor2split.update({d: "test" for d in test})
    # 长表：审计用
    assign = pd.DataFrame({"case_id": list(donor2split),
                           "split": list(donor2split.values())})
    assign.to_csv(f"processed/splits/split_assignments_{a.task}_{i}.csv", index=False)
    # ★ 宽表：与作者 save_splits 格式一致（train/val/test 三列，每列 slide_id）
    assign["slide_id"] = assign.case_id.map(
        lambda d: df.loc[df.case_id == d, "slide_id"].tolist())
    wide = pd.DataFrame({
        k: [s for lst in assign.loc[assign.split == k, "slide_id"] for s in lst]
        for k in ["train", "val", "test"]})
    wide.to_csv(f"processed/splits/splits_{a.task}_{i}.csv", index=False)
    print(i, assign.split.value_counts().to_dict())
```

> 作者的 `Generic_WSI_Classification_Dataset(patient_strat=True)` 是 CLAM 自带的按 patient 分层划分；上面的实现给出等价逻辑（按 donor 分组、按癌种分层）。**注意**：n=7 是正文；作者代码默认 `k=10`（D7）。

### 4.2 评估：bag → sample 聚合

```python
# code/05_02_eval.py
import os, numpy as np, pandas as pd, torch
from torch.utils.data import Dataset, DataLoader
from sklearn.metrics import accuracy_score, roc_auc_score, f1_score

class BagDataset(Dataset):
    """统一接口：返回 (ids, mask, label, slide_id)。"""
    def __init__(self, index_csv, token_dir, label2id):
        self.df = pd.read_csv(index_csv)
        self.token_dir = token_dir
        self.label2id = label2id
    def __len__(self): return len(self.df)
    def __getitem__(self, i):
        r = self.df.iloc[i]
        d = torch.load(os.path.join(self.token_dir, r.slide_id + ".pt"))
        return (d["input_ids"], d["attention_mask"],
                torch.tensor(self.label2id[r.label]), d["slide_id"])

@torch.no_grad()
def predict_bags(model, loader):
    """BagDataset.__getitem__ 返回 (ids, mask, label, slide_id)。"""
    rows = []
    for ids, mask, label, slide_id in loader:
        logits = model(ids.cuda(), mask.cuda())
        prob = torch.softmax(logits, 1).cpu().numpy()[0]
        rows.append(dict(slide_id=slide_id[0], prob=prob))
    return rows

def aggregate_binary(rows):
    df = pd.DataFrame(rows)
    # 每个 sample 的 slide_id = {patient}_{tissue}_{idx}；取 patient_tissue 前缀
    df["sample_id"] = df.slide_id.str.rsplit("_", n=1).str[0]
    agg = df.groupby("sample_id").agg(
        y_prob=("prob", lambda ps: 1 - np.prod([p[0] for p in ps])),  # 任一阳性的概率
        y_hat=("prob", lambda ps: int(any(p[1] >= 0.5 for p in ps)))
    ).reset_index()
    return agg

def aggregate_multiclass(rows):
    df = pd.DataFrame(rows)
    df["sample_id"] = df.slide_id.str.rsplit("_", n=1).str[0]
    def vote(ps):
        # ★ 正文用 voting：每个 bag 投一票（argmax），取众数
        votes = [int(np.argmax(p)) for p in ps]
        return int(pd.Series(votes).mode().iloc[0])
    agg = df.groupby("sample_id").agg(y_hat=("prob", vote)).reset_index()
    # 备选：概率和 argmax（作为敏感性分析，与 vote 结果对照）
    agg["y_hat_probsum"] = df.groupby("sample_id")["prob"].apply(
        lambda ps: int(np.argmax(np.stack(ps).sum(0)))).values
    return agg
```

> 二分类的 `1 - Π(1-p_i)` 是"至少一个 bag 阳性"的概率（假设 bag 独立），比硬投票更平滑；硬 `any(p>=0.5)` 与原文"任一阳性"一致。两者都输出，主表用硬规则（与原文一致），AUC 用软概率。

### 4.3 指标汇总

```python
# code/05_03_summarize.py
import pandas as pd, numpy as np
from sklearn.metrics import accuracy_score, roc_auc_score, f1_score

def summarize(pred, truth, task="bicls"):
    out = dict(n=len(truth),
               acc=accuracy_score(truth, pred.y_hat),
               f1=f1_score(truth, pred.y_hat, average="macro", zero_division=1))
    if task == "bicls":
        out["auc"] = roc_auc_score(truth, pred.y_prob)
    return out
```

### 4.4 单细胞评分

```python
# code/05_04_infer_cells.py
import torch, numpy as np, pandas as pd, anndata as ad
@torch.no_grad()
def cell_scores(model, bag_h5ad, token_pt):
    d = torch.load(token_pt)
    ids, mask = d["input_ids"].cuda(), d["attention_mask"].cuda()
    logits, A_raw, A, h, M = model(ids, mask, return_attn=True)
    # ★ D22：单细胞 AUC/UMAP 用作者 eval_utils 保存的 softmax 后 attention weight
    scores = A.squeeze(0).cpu().numpy()
    adata = ad.read_h5ad(bag_h5ad)
    return pd.DataFrame({"cell_id": adata.obs_names, "tumor_score": scores,
                         "cnv_status": adata.obs["cnv_status"].values,
                         "cell_type": adata.obs.get("Celltype", "NA")})
```

## ⑤ 参数解释与调参空间

| 参数 | 本项目取值 | 可选 | 改变后果 |
|---|---|---|---|
| 训练/验证/测试 | 80/10/10 by donor | 70/15/15 | 训练量/方差 |
| `n_splits` | 7（正文） | 10（代码） | 均值稳定性（D7） |
| 二分类聚合 | 任一 bag ≥0.5 | 概率平均/多数投票 | 灵敏度 vs 特异度 |
| 多分类聚合 | 概率和 argmax | 多数投票 | 类别不平衡时不同 |
| AUC 输入 | `Y_prob`（软） | `Y_hat`（硬） | 硬标签 AUC 失真（D20） |
| 单细胞阈值 | tumor score 排序（AUC 不依赖阈值） | 0.2/0.5 | 影响 Acc/F1 |

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| 测试集性能异常高 | donor 泄漏 | 检查 split 是否按 donor |
| 聚合后 sample 数不对 | `slide_id` 命名不符 | 用 `{patient}_{tissue}_{idx}` |
| AUC 与 Acc 完全一致 | 用了硬标签 | 用 `Y_prob` |
| 某癌种全错 | 训练样本极少 | 类别加权/报告混淆矩阵 |
| 多分类投票平票 | 概率和相同 | 加随机种子或取概率平均 |
| 单细胞分数全 0 | `A_raw` 取错层 | 用 attention 的 pre-softmax |
