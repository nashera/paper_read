## ② 背景原理

### 2.1 tumor score 的来源

- 代码里有两个量（D22）：
  - `a_i = attention_c(tanh(W_a h) ⊙ sigmoid(W_b h))`：softmax **前**的实例级标量（正文 Eq.2），用于 adaptive loss 排序；
  - `attention_weight = softmax(a)`：bag 内归一化权重，用于聚合；作者 `eval_utils.py:87-91` 保存的 `instance_results` 是这个量，**单细胞 AUC/UMAP 用的是它**。
- `attention_weight` 依赖**同 bag 的其他细胞**，因此：
  - 不同 bag 的 score 不可直接比较绝对值；
  - 但**排序**（bag 内）是稳定的；
  - 单细胞 ROC 用排序，不需要跨 bag 可比。

> ⚠️ **导师批注**：原文把 tumor score 当作"细胞恶性程度"，严格说它是"该细胞在同 bag 内驱动 bag 阳性的相对权重"。一个正常细胞在"全 normal 的 bag"里也可能拿到较高 softmax 权重（矮子里拔将军）。解释时要加限定。

### 2.2 CNV 参照的循环性

- bag 标签本身来自 CNV（Sample setting）；
- 用 CNV 评估 cell score → **部分循环**：模型被训练去拟合 CNV，当然与 CNV 相关。
- 真正的外部验证是：① 甲状腺 paratumor（病理正常、分子异常）；② AML 的 seq-well ground truth（独立技术）；③ HHD-ALL（CNV 漏标但临床恶性）。
- 复现时必须在讨论里指出这一点（13 号批判）。

### 2.3 甲状腺 GSE184362

- 原研究：乳头状甲状腺癌（PTC）的肿瘤生态系统；
- Patient 5 的 paratumor 样本：病理切片正常，但单细胞发现 cluster c02（thyrocytes）已表达癌相关基因；
- scTransMIL 给该样本 0.64；原文只说其他方法把它判为 negative（未给具体分数）。
- 高 tumor score 应集中在 epithelial（thyrocyte）群体，而不是免疫/基质。

### 2.4 ALL 的 B 细胞

- ALL 样本在泛癌 bag embedding 中形成独立簇；
- tumor B 细胞：CNV 阳性；
- HHD（high hyperdiploid）样本：CNV 推断可能把 B 细胞标为 normal（全局拷贝数变化干扰基线），但临床是恶性；scTransMIL 仍给高分；
- attention top-100：CD79A、PIM1、BLK；BLK 是常规 DEA 漏掉的标志物（表达无差异，但"上下文"异常）。

### 2.5 基因 attention 的提取

作者：

1. 取 instance encoder **最后一层 Transformer** 的 attention；
2. 对**所有 head 取平均**；
3. 对目标细胞组内所有 instance 的 attention 再平均；
4. 按 attention 排序，取 top-100。

注意：attention 的维度是 `(N_tokens, N_tokens)`；"基因的 attention"通常取 **CLS token 对基因 token 的注意力**（或对该基因 token 列求和）。作者代码的具体归约方式需在 `eval.py`/可视化脚本中核对（D21）。复现时要明确"取哪一行/列"。

### 4.3 Attention 提取

```python
# code/09_03_attention.py
import torch

@torch.no_grad()
def gene_attention(model, ids, mask):
    """返回 (N_cells, L) 的基因 attention；取最后一层、所有 head 平均。
    前提：tokenizer 使用 special_token=True（位置 0 是 <cls>，D10/D21）。"""
    out = model.encoder(input_ids=ids, attention_mask=mask,
                        output_attentions=True)
    attn = out.attentions[-1].mean(dim=1)      # (N, L, L)
    cls_attn = attn[:, 0, :]                   # (N, L)  CLS -> token
    return cls_attn
```

> 若作者用的是"基因 token 对 CLS 的注意力"或"列求和"，结果会不同；以作者可视化脚本为准，并在 `logs/09_attention_reduction.txt` 记录。**不要**把不同归约方式的结果混在一起比较。

### 4.4 目标细胞组的 attention

```python
# code/09_04_group_attention.py
import numpy as np, pandas as pd, torch
def group_attention(model, bags, cell_mask, token_dict):
    """bags: list of (ids, mask)；cell_mask: 每个 bag 内的布尔向量。"""
    acc = []
    for (ids, mask), sel in zip(bags, cell_mask):
        if not sel.any():
            continue
        a = gene_attention(model, ids.cuda(), mask.cuda())[sel]  # (n_sel, L)
        # ★ 用该 bag 的 input_ids 作为每个位置的 token（不是位置下标！）
        tokens = ids[0, :a.shape[1]].cpu().numpy()
        acc.append((a.mean(0).cpu().numpy(), tokens))
    mean_attn = np.mean([x[0] for x in acc], axis=0)
    tokens = acc[0][1]
    inv = {v: k for k, v in token_dict.items()}
    df = pd.DataFrame({"token": tokens, "attention_mean": mean_attn})
    df = df[df.token != token_dict.get("<pad>", 0)]
    df["gene"] = df.token.map(inv)
    df = df.dropna().sort_values("attention_mean", ascending=False)
    return df
```

## ⑦ 常见陷阱与排错表

| 现象 | 根因 | 解决 |
|---|---|---|
| AUC 虚高 | bag 标签来自 CNV，循环 | 报告外部验证（甲状腺/AML） |
| score 跨 bag 不可比 | softmax 归一化 | 只用 bag 内排序 |
| attention 维度错 | 没取 CLS 行 | 打印 `attn.shape` |
| top-100 全是高表达基因 | 未做 median scaling | 检查 tokenizer |
| 富集无结果 | 基因是 Ensembl | 转 SYMBOL 再富集 |
| BLK 不在 top-100 | attention 归约/层数不同 | 对照作者脚本；记录差异 |
