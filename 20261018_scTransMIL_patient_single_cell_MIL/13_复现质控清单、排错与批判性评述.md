## ⑨ 批判性评述（审稿人 / 导师视角）

### 9.1 证据等级

| 结论 | 等级 | 理由 |
|---|---|---|
| scTransMIL 在泛癌样本级诊断上优于四类基线 | **B（仅 100% 训练量；50% 时作者 CSV 显示部分指标被 KIDA/PCA/scVI 反超）** | 公开数据+代码；需大规模重训；作者 `metrics_plot/data/*.csv` 可核验 |
| 单细胞 tumor score 与 CNV 一致（AUC 0.71） | **B–C** | CNV 既是训练标签又作评估参照，存在循环性 |
| 甲状腺 Patient 5 早癌可被 flagged | **B** | 单个样本的案例，需外部重复 |
| 30 类癌种/转移灶可分类 | **B** | 泛癌内部测试 + 单类 BRCA 外部验证 |
| attention top-100 含 BLK 等标志物 | **B–C** | attention 是相关性，不是因果；依赖归约方式 |
| AML 6 亚型与生存差异 | **C** | 小样本微调 + 人为分组阈值 + 单 bulk 队列 |
| 模型可用于临床筛查 | **D（未证）** | 无前瞻性验证、无校准、无决策曲线 |

### 9.2 方法学强项

1. **弱监督定位准确**：MIL 的 OR 假设与"样本级诊断、细胞级未知"的临床现实高度契合。
2. **rank 编码的鲁棒性**：用排序替代绝对值，天然抗批次；与 scIB 的 Batch 分数一致。
3. **端到端可解释**：attention 同时给出细胞分数与基因重要性，不需要事后 surrogate。
4. **核心工程可运行**：训练/推理/评估有开源代码与预训练权重；**AML 微调入口、基因 attention 提取、4 个基线训练脚本需自行补写**（仓库未提供完整入口）。
5. **多尺度验证**：样本级、细胞级、基因级、外部数据集、新病种，证据链较完整。

### 9.3 局限与可质疑之处

| # | 局限 | 影响 | 复现处理 |
|---|---|---|---|
| L1 | **CNV 循环性**：训练标签与细胞级评估都来自 CNV | AUC 0.71 不能证明"独立于 CNV 的恶性识别" | 用甲状腺/AML seq-well 做外部验证；讨论中声明 |
| L2 | tumor score 是 softmax 权重，非校准概率 | 跨 bag/跨样本绝对值不可比；0.2/0.5 阈值是启发式 | 只用 bag 内排序；报告阈值敏感性 |
| L3 | rank 编码丢弃表达幅度 | 对"表达量变化但名次不变"的基因不敏感 | 与 DEA 互补；BLK 例子说明 |
| L4 | "full transcriptome" 实际截断 1024 tokens | 长尾基因可能被丢弃 | 记录截断率；2048 敏感性 |
| L5 | 尾部回绕复制细胞 | 最后一块的细胞权重被放大 | 记录；丢弃最后一块做敏感性 |
| L6 | 29 vs 30 类不一致 | 影响多分类指标 | D16；报告缺类 |
| L7 | n=7 vs 代码 k=10、lr 默认不一致 | 直接跑脚本≠复现论文 | 显式覆盖超参 |
| L8 | 正文公式与代码实现不一致（pooling/聚合） | "复现的是代码还是论文"必须声明 | D3；两版都跑 |
| L9 | BRCA 外部验证是单类 | 不能算多分类泛化 | 只报"判为 BRCA 的比例" |
| L10 | AML 生存分组阈值人为 | 选择偏差 | 敏感性分析 |
| L11 | dbGaP 受控 | 生存分析可能无法复现 | D12；标"未复现" |
| L12 | 临床风险 | 假阴性延误诊断、假阳性过度检查 | 原文 Discussion 已承认；报告中强调 |

### 9.4 与原文不同的地方（必须声明）

1. **实现口径**：以作者代码为准（D3），并另跑正文公式版对照。
2. **序列长度**：1024（D4），非无限"全转录组"。
3. **类别数**：29（D16），与正文 30 的差异要说明。
4. **划分**：n=7（D7），代码默认 10 折需覆盖。

### 9.5 可扩展方向

1. **去掉 CNV 依赖**：用病理/CNV-free 的恶性标签（如 AML seq-well、甲状腺病理）重训，检验 AUC 是否仍成立。

5. **前瞻性验证**：与医院合作，用未参与训练的新队列做锁定验证。
6. **不确定性**：MC dropout / conformal prediction，给"不确定"样本。
